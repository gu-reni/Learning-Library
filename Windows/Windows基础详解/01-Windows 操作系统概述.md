# 第一章 Windows 操作系统概述

---

## 1.1 发展简史

| 版本 | 发布年份 | 里程碑意义 |
|------|----------|------------|
| MS-DOS | 1981 | 命令行操作系统基础 |
| Windows 1.0 | 1985 | 首个图形界面版本 |
| Windows 3.x | 1990-1992 | 流行度大幅提升 |
| Windows 95 | 1995 | 开始菜单、任务栏诞生 |
| Windows 98 | 1998 | USB 支持、FAT32 |
| Windows XP | 2001 | 最经典版本，NT 内核普及 |
| Windows Vista | 2007 | Aero 界面、UAC 引入 |
| Windows 7 | 2009 | 性能优化，广受好评 |
| Windows 8/8.1 | 2012-2013 | 触控优化、开始屏幕 |
| Windows 10 | 2015 | 统一平台、Cortana、WSL |
| Windows 11 | 2021 | 新 UI、Android 应用支持 |

---

## 1.2 版本差异

| 版本 | 适用场景 | 核心功能差异 |
|------|----------|--------------|
| **家庭版** | 个人用户 | 基础功能，无组策略、BitLocker、远程桌面 |
| **专业版** | 高级用户/小企业 | 组策略、BitLocker、远程桌面、Hyper-V |
| **企业版** | 大型企业 | AppLocker、BranchCache、长期服务支持 |
| **教育版** | 学校机构 | 类似企业版，针对教育场景优化 |

**选择建议：**
- 普通用户：家庭版足够
- 技术爱好者/开发者：专业版（需要组策略、Hyper-V）
- 企业部署：企业版（需要集中管理）

## 1.3 系统架构

```
┌─────────────────────────────────────┐
│         应用程序 (User Mode)         │
│         Win32 API / .NET            │
├─────────────────────────────────────┤
│         执行体 (Executive)           │
│  进程/内存/I/O/对象/安全管理         │
├─────────────────────────────────────┤
│           内核 (Kernel)              │
│    线程调度、中断、同步对象          │
├─────────────────────────────────────┤
│      硬件抽象层 HAL (Kernel)         │
├─────────────────────────────────────┤
│           硬件层                     │
└─────────────────────────────────────┘
```

### 核心组件说明

| 组件 | 功能 |
|------|------|
| **进程与线程管理** | 进程是资源分配单位，线程是 CPU 调度单位 |
| **内存管理** | 虚拟内存、页面文件 (pagefile.sys)、内存映射 |
| **I/O 系统** | 设备驱动、I/O 请求包 (IRP) |
| **对象管理器** | 统一管理文件、进程、线程等对象 |
| **安全引用监视器 (SRM)** | 访问控制、权限验证 |

### 用户模式 vs 内核模式

| 特性 | 用户模式 | 内核模式 |
|------|----------|----------|
| 权限 | 受限 | 完全访问硬件 |
| 运行代码 | 应用程序 | 内核、驱动 |
| 崩溃影响 | 仅应用崩溃 | 系统蓝屏 |
| API 访问 | Win32 API | 原生 API |

## 1.4 关键概念

### 进程 (Process)
- 资源分配的基本单位
- 拥有独立的虚拟地址空间
- 包含一个或多个线程

### 线程 (Thread)
- CPU 调度的基本单位
- 共享进程的内存和资源
- 每个线程有独立的栈和寄存器

### 虚拟内存
- 每个进程拥有独立的虚拟地址空间
- 32 位系统：4GB（用户 2GB/内核 2GB）
- 64 位系统：8TB~128TB
- 页面文件扩展物理内存

### 句柄 (Handle)
- 内核对象的引用标识符
- 类似文件描述符
- 进程通过句柄访问对象

## 1.5 系统启动流程

```
1. BIOS/UEFI 自检
2. 加载引导管理器 (Boot Manager)
3. 加载 Windows 启动加载器 (bootmgr)
4. 加载内核 (ntoskrnl.exe) 和 HAL
5. 初始化内核模式驱动
6. 启动会话管理器 (smss.exe)
7. 启动 Winlogon 和用户登录
8. 加载用户配置文件
9. 启动 Explorer 和自启动程序
```
