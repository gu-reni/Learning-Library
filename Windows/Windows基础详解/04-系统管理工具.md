## 4.1 任务管理器 (Task Manager)

### 打开方式
| 方法 | 操作 |
|------|------|
| 快捷键 | `Ctrl + Shift + Esc`（最快） |
| 安全屏幕 | `Ctrl + Alt + Del` → 任务管理器 |
| 运行 | `Win + R` → `taskmgr` |
| 右键菜单 | 右键任务栏 → 任务管理器 |
| 开始菜单 | 右键开始 → 任务管理器 |

### 界面布局

#### 进程选项卡
| 列 | 含义 |
|----|------|
| 应用 | 前台运行的程序 |
| 后台进程 | 后台运行的服务 |
| Windows 进程 | 系统核心进程 |
| CPU | 处理器使用百分比 |
| 内存 | RAM 使用量 |
| 磁盘 | 磁盘活动百分比 |
| 网络 | 网络使用量 |
| GPU | 显卡使用百分比 |

#### 性能选项卡
实时监控硬件使用率

**关键数值解读：**

| 指标 | 正常范围 | 异常阈值 | 排查方法 |
|------|----------|----------|----------|
| **CPU 使用率** | 空闲 1-5%，负载 30-80% | 持续>90% | 按 CPU 排序进程 |
| **内存使用率** | 40-70% | >85% | 检查内存泄漏 |
| **磁盘活动时间** | <20% | 持续 100% | 资源监视器分析 |
| **网络使用率** | 视应用而定 | 未知占用 | 检查可疑连接 |
| **GPU 使用率** | 桌面<5% | 桌面>30% | 检查后台渲染 |

### 常用操作

**结束进程**
```
1. 选中进程
2. 右键 → 结束任务
3. 或点击"结束任务"按钮
```

**设置优先级**
```
详细信息选项卡 → 右键进程 → 设置优先级
- 实时（不建议）
- 高
- 高于正常
- 正常（默认）
- 低于正常
- 低
```

**设置相关性（CPU 亲和性）**
```
详细信息 → 右键进程 → 设置相关性
选择进程可以使用的 CPU 核心
```

**分析等待链**
```
进程 → 右键 → 分析等待链
查看进程在等待什么资源
```

**创建转储文件**
```
详细信息 → 右键进程 → 创建转储文件
用于调试和分析崩溃
```

## 4.2 资源监视器 (Resource Monitor)

### 打开方式
```
方法 1: Win + R → resmon
方法 2: 任务管理器 → 性能 → 打开资源监视器
方法 3: 搜索 "资源监视器"
```

### 界面布局

| 选项卡 | 监控内容 |
|--------|----------|
| 概览 | 四维度汇总图表 |
| CPU | 进程、服务、关联句柄 |
| 内存 | 物理内存、硬错误 |
| 磁盘 | 读写活动、队列长度 |
| 网络 | 连接、监听端口、流量 |

### 关键数值解读

| 指标 | 含义 | 正常范围 | 异常判断 |
|------|------|----------|----------|
| **硬错误/秒** | 页面文件访问次数 | <10 | >50 内存不足 |
| **平均响应时间** | 磁盘响应延迟 | SSD<10ms, HDD<20ms | >100ms 严重延迟 |
| **磁盘队列长度** | 等待的 I/O 请求 | <2 | >5 性能瓶颈 |
| **TCP 连接数** | 活跃网络连接 | 视应用而定 | 异常多可能中毒 |

### 故障诊断示例

**磁盘 100% 排查：**
```
1. 打开资源监视器 → 磁盘选项卡
2. 按"总计 (B/ 秒)"排序
3. 查看哪个进程占用最高
4. 检查"磁盘活动"详细列表
5. 根据进程名判断是否异常
```

**内存不足排查：**
```
1. 内存选项卡
2. 查看"硬错误/秒"
3. >50 表示频繁页面交换
4. 按"提交 (KB)"排序进程
5. 结束内存泄漏进程
```

## 4.3 性能监视器 (Performance Monitor)

### 打开方式
```
Win + R → perfmon
```

### 创建数据收集器集

```
1. 数据收集器集 → 用户定义 → 右键新建
2. 选择"手动创建"或"从模板创建"
3. 添加计数器：
   - Processor → % Processor Time
   - Memory → Available MBytes
   - PhysicalDisk → Avg. Disk Queue Length
4. 设置采样间隔（建议 15 秒）
5. 设置日志保存位置
6. 完成
```

### 常用计数器

| 计数器 | 对象 | 含义 | 正常值 |
|--------|------|------|--------|
| % Processor Time | Processor | CPU 使用率 | <80% |
| Available MBytes | Memory | 可用内存 | >500MB |
| Avg. Disk Queue Length | PhysicalDisk | 磁盘队列 | <2 |
| Pages/sec | Memory | 页面交换 | <20 |
| % Free Space | LogicalDisk | 磁盘剩余 | >15% |

### 生成报告
```
性能 → 数据收集器集 → 用户定义
右键已创建的收集器 → 启动
运行一段时间后 → 停止
查看生成的报告
```

## 4.4 事件查看器 (Event Viewer)

### 打开方式
```
方法 1: Win + R → eventvwr
方法 2: 右键开始 → 事件查看器
方法 3: 搜索 "事件查看器"
```

### 日志分类

| 日志类型 | 内容 | 常用事件 ID |
|----------|------|-------------|
| 系统 | 驱动、服务、系统组件 | 7000(服务失败)、6008(意外关机) |
| 应用程序 | 软件运行日志 | 1000(应用崩溃)、1001(错误报告) |
| 安全 | 登录、权限审计 | 4624(登录成功)、4625(登录失败) |
| Setup | 安装日志 | 视安装程序而定 |

### 筛选事件

```
1. 展开 Windows 日志 → 选择类型
2. 右侧"筛选当前日志"
3. 输入事件 ID（如：1000,4624）
4. 或选择事件级别（错误、警告）
5. 确定 → 查看筛选结果
```

### 常用事件 ID 速查

| ID | 级别 | 含义 |
|----|------|------|
| 1000 | 错误 | 应用程序崩溃 |
| 1001 | 错误 | Windows 错误报告 |
| 4624 | 信息 | 登录成功 |
| 4625 | 警告 | 登录失败 |
| 6005 | 信息 | 事件日志服务启动（开机） |
| 6006 | 信息 | 事件日志服务停止（关机） |
| 6008 | 错误 | 意外关机 |
| 7000 | 错误 | 服务启动失败 |
| 7031 | 错误 | 服务意外终止 |
| 7036 | 信息 | 服务状态改变 |

## 4.5 设备管理器 (Device Manager)

### 打开方式
```
方法 1: Win + X → 设备管理器
方法 2: Win + R → devmgmt.msc
方法 3: 搜索 "设备管理器"
```

### 界面说明

**状态图标：**
- ✅ 正常设备
- ⚠️ 黄色感叹号 = 驱动问题
- ❌ 红色叉号 = 设备禁用
- 🔽 向下箭头 = 设备禁用

### 常用操作

**更新驱动**
```
1. 右键设备 → 更新驱动程序
2. 自动搜索驱动
3. 或浏览计算机查找驱动
```

**回滚驱动**
```
1. 双击设备 → 驱动程序选项卡
2. 回滚驱动程序
3. 选择原因 → 确定
```

**卸载设备**
```
1. 右键设备 → 卸载设备
2. 勾选"删除此设备的驱动程序软件"（可选）
3. 确定 → 重启后自动重装
```

**查看隐藏设备**
```
查看 → 显示隐藏的设备
可看到已断开但未卸载的设备
```

**查看资源**
```
查看 → 依连接排序资源
查看 IRQ、内存地址分配
```

## 4.6 DirectX 诊断工具

### 打开方式
```
Win + R → dxdiag
```

### 选项卡说明

| 选项卡 | 信息 |
|--------|------|
| 系统 | 操作系统、BIOS、处理器、内存 |
| 显示 | 显卡型号、驱动、显存、DirectX 版本 |
| 声音 | 音频设备信息 |
| 输入 | 键盘、鼠标、游戏控制器 |

### 游戏故障排查
```
1. 检查 DirectX 版本（系统选项卡）
2. 验证显卡驱动日期（显示选项卡）
3. 查看显存是否足够
4. 保存所有信息 → 分析日志
```

## 4.7 系统信息 (msinfo32)

### 打开方式
```
Win + R → msinfo32
```

### 信息分类

| 类别 | 内容 |
|------|------|
| 系统摘要 | 操作系统、BIOS、处理器、内存 |
| 硬件资源 | IRQ、DMA、内存地址 |
| 组件 | 显示、存储、网络、输入 |
| 软件环境 | 驱动、服务、启动项 |

### 导出信息
```
文件 → 导出
保存为 .nfo 文件
可用于技术支持和故障分析
```

## 4.8 磁盘管理 (diskmgmt.msc)

### 打开方式
```
方法 1: Win + X → 磁盘管理
方法 2: Win + R → diskmgmt.msc
```

### 常用操作

| 操作 | 步骤 |
|------|------|
| 新建分区 | 右键未分配 → 新建简单卷 |
| 格式化 | 右键分区 → 格式化 |
| 改盘符 | 右键分区 → 更改驱动器号 |
| 扩展卷 | 右键分区 → 扩展卷 |
| 压缩卷 | 右键分区 → 压缩卷 |
| 初始化磁盘 | 右键磁盘 → 初始化 |

### 注意事项
- 扩展卷需要相邻未分配空间
- 系统盘不能删除
- 操作前备份重要数据

## 4.9 服务管理器 (services.msc)

### 打开方式
```
Win + R → services.msc
```

### 启动类型

| 类型 | 说明 |
|------|------|
| 自动 | 系统启动时运行 |
| 自动 (延迟) | 启动后延迟运行 |
| 手动 | 按需启动 |
| 禁用 | 无法启动 |

### 服务管理
```
启动/停止：右键 → 启动/停止
属性：双击 → 设置启动类型、恢复操作
依存关系：查看依赖的服务
```

### 可安全禁用的服务（按需）
| 服务 | 说明 |
|------|------|
| Print Spooler | 无打印机可禁用 |
| Bluetooth Support | 无蓝牙设备 |
| Windows Search | 不使用搜索可禁用 |
| SysMain | SSD 用户可禁用 |
