## 4.1 任务管理器 (Task Manager)

### 打开方式
| 方法 | 操作 |
|------|------|
| 快捷键 | `Ctrl + Shift + Esc`（最快） |
| 安全屏幕 | `Ctrl + Alt + Del` → 任务管理器 |
| 运行 | `Win + R` → `taskmgr` |
| 右键菜单 | 右键任务栏 → 任务管理器 |
| 开始菜单 | 右键开始 → 任务管理器 |

### 界面布局

#### 进程选项卡
| 列 | 含义 |
|----|------|
| 应用 | 前台运行的程序 |
| 后台进程 | 后台运行的服务 |
| Windows 进程 | 系统核心进程 |
| CPU | 处理器使用百分比 |
| 内存 | RAM 使用量 |
| 磁盘 | 磁盘活动百分比 |
| 网络 | 网络使用量 |
| GPU | 显卡使用百分比 |

#### 性能选项卡
实时监控硬件使用率

**关键数值解读：**

| 指标 | 正常范围 | 异常阈值 | 排查方法 |
|------|----------|----------|----------|
| **CPU 使用率** | 空闲 1-5%，负载 30-80% | 持续>90% | 按 CPU 排序进程 |
| **内存使用率** | 40-70% | >85% | 检查内存泄漏 |
| **磁盘活动时间** | <20% | 持续 100% | 资源监视器分析 |
| **网络使用率** | 视应用而定 | 未知占用 | 检查可疑连接 |
| **GPU 使用率** | 桌面<5% | 桌面>30% | 检查后台渲染 |

### 常用操作

**结束进程**
```
1. 选中进程
2. 右键 → 结束任务
3. 或点击"结束任务"按钮
```

**设置优先级**
```
详细信息选项卡 → 右键进程 → 设置优先级
- 实时（不建议）
- 高
- 高于正常
- 正常（默认）
- 低于正常
- 低
```

**设置相关性（CPU 亲和性）**
```
详细信息 → 右键进程 → 设置相关性
选择进程可以使用的 CPU 核心
```

**分析等待链**
```
进程 → 右键 → 分析等待链
查看进程在等待什么资源
```

**创建转储文件**
```
详细信息 → 右键进程 → 创建转储文件
用于调试和分析崩溃
```

## 4.2 资源监视器 (Resource Monitor)

### 打开方式
```
方法 1: Win + R → resmon
方法 2: 任务管理器 → 性能 → 打开资源监视器
方法 3: 搜索 "资源监视器"
```

### 界面布局

| 选项卡 | 监控内容 |
|--------|----------|
| 概览 | 四维度汇总图表 |
| CPU | 进程、服务、关联句柄 |
| 内存 | 物理内存、硬错误 |
| 磁盘 | 读写活动、队列长度 |
| 网络 | 连接、监听端口、流量 |

### 关键数值解读

| 指标 | 含义 | 正常范围 | 异常判断 |
|------|------|----------|----------|
| **硬错误/秒** | 页面文件访问次数 | <10 | >50 内存不足 |
| **平均响应时间** | 磁盘响应延迟 | SSD<10ms, HDD<20ms | >100ms 严重延迟 |
| **磁盘队列长度** | 等待的 I/O 请求 | <2 | >5 性能瓶颈 |
| **TCP 连接数** | 活跃网络连接 | 视应用而定 | 异常多可能中毒 |

### 故障诊断示例

**磁盘 100% 排查：**
```
1. 打开资源监视器 → 磁盘选项卡
2. 按"总计 (B/ 秒)"排序
3. 查看哪个进程占用最高
4. 检查"磁盘活动"详细列表
5. 根据进程名判断是否异常
```

**内存不足排查：**
```
1. 内存选项卡
2. 查看"硬错误/秒"
3. >50 表示频繁页面交换
4. 按"提交 (KB)"排序进程
5. 结束内存泄漏进程
```

## 4.3 性能监视器 (Performance Monitor)

### 打开方式
```
Win + R → perfmon
```

### 创建数据收集器集

```
1. 数据收集器集 → 用户定义 → 右键新建
2. 选择"手动创建"或"从模板创建"
3. 添加计数器：
   - Processor → % Processor Time
   - Memory → Available MBytes
   - PhysicalDisk → Avg. Disk Queue Length
4. 设置采样间隔（建议 15 秒）
5. 设置日志保存位置
6. 完成
```

### 常用计数器

| 计数器 | 对象 | 含义 | 正常值 |
|--------|------|------|--------|
| % Processor Time | Processor | CPU 使用率 | <80% |
| Available MBytes | Memory | 可用内存 | >500MB |
| Avg. Disk Queue Length | PhysicalDisk | 磁盘队列 | <2 |
| Pages/sec | Memory | 页面交换 | <20 |
| % Free Space | LogicalDisk | 磁盘剩余 | >15% |

### 生成报告
```
性能 → 数据收集器集 → 用户定义
右键已创建的收集器 → 启动
运行一段时间后 → 停止
查看生成的报告
```

## 4.4 事件查看器 (Event Viewer)

### 打开方式
```
方法 1: Win + R → eventvwr
方法 2: 右键开始 → 事件查看器
方法 3: 搜索 "事件查看器"
```

### 日志分类

| 日志类型 | 内容 | 常用事件 ID |
|----------|------|-------------|
| 系统 | 驱动、服务、系统组件 | 7000(服务失败)、6008(意外关机) |
| 应用程序 | 软件运行日志 | 1000(应用崩溃)、1001(错误报告) |
| 安全 | 登录、权限审计 | 4624(登录成功)、4625(登录失败) |
| Setup | 安装日志 | 视安装程序而定 |

### 筛选事件

```
1. 展开 Windows 日志 → 选择类型
2. 右侧"筛选当前日志"
3. 输入事件 ID（如：1000,4624）
4. 或选择事件级别（错误、警告）
5. 确定 → 查看筛选结果
```

### 常用事件 ID 速查

| ID | 级别 | 含义 |
|----|------|------|
| 1000 | 错误 | 应用程序崩溃 |
| 1001 | 错误 | Windows 错误报告 |
| 4624 | 信息 | 登录成功 |
| 4625 | 警告 | 登录失败 |
| 6005 | 信息 | 事件日志服务启动（开机） |
| 6006 | 信息 | 事件日志服务停止（关机） |
| 6008 | 错误 | 意外关机 |
| 7000 | 错误 | 服务启动失败 |
| 7031 | 错误 | 服务意外终止 |
| 7036 | 信息 | 服务状态改变 |

## 4.5 设备管理器 (Device Manager)

### 打开方式
```
方法 1: Win + X → 设备管理器
方法 2: Win + R → devmgmt.msc
方法 3: 搜索 "设备管理器"
```

### 界面说明

**状态图标：**
- ✅ 正常设备
- ⚠️ 黄色感叹号 = 驱动问题
- ❌ 红色叉号 = 设备禁用
- 🔽 向下箭头 = 设备禁用

### 常用操作

**更新驱动**
```
1. 右键设备 → 更新驱动程序
2. 自动搜索驱动

```

**回滚驱动**
```
1. 双击设备 → 驱动程序选项卡
2. 回滚驱动程序
3. 选择原因 → 确定
```

**卸载设备**
```
1. 右键设备 → 卸载设备
2. 勾选"删除此设备的驱动程序软件"（可选）
3. 确定 → 重启后自动重装
```

**查看隐藏设备**
```
查看 → 显示隐藏的设备
可看到已断开但未卸载的设备
```

**查看资源**
```
查看 → 依连接排序资源
查看 IRQ、内存地址分配
```

### ping

```cmd
ping www.baidu.com          # 测试连通性
ping 192.168.1.1 -t         # 持续 ping（Ctrl+C 停止）
ping 192.168.1.1 -l 1000    # 发送 1000 字节包
ping 192.168.1.1 -n 10      # 发送 10 次
ping 192.168.1.1 -4         # 强制 IPv4
ping 192.168.1.1 -6         # 强制 IPv6
```

**结果解读：**
| 指标 | 含义 | 正常值 |
|------|------|--------|
| 时间 (ms) | 往返延迟 | 内网<1ms，外网<50ms |
| 丢失率 | 丢包百分比 | 0% |
| TTL | 生存时间 | 64/128/255 |

### tracert / pathping

```cmd
tracert www.baidu.com       # 追踪路由
pathping www.baidu.com      # 更详细的路径分析（较慢）
```

**输出解读：**
- 每一跳是一个路由器
- `* * *` 表示该节点不响应
- 延迟突然增加的位置可能是瓶颈

### netstat

```cmd
netstat -an                 # 显示所有连接和端口
netstat -ano                # 显示进程 PID
netstat -rn                 # 显示路由表
netstat -e                  # 显示以太网统计
netstat -s                  # 显示协议统计
```

**常用排查：**
```cmd
# 查看占用 80 端口的进程
netstat -ano | findstr :80

# 查看 ESTABLISHED 连接
netstat -an | findstr ESTABLISHED

# 查看监听端口
netstat -an | findstr LISTENING
```

**状态说明：**
| 状态 | 含义 |
|------|------|
| LISTENING | 监听端口 |
| ESTABLISHED | 已建立连接 |
| TIME_WAIT | 等待关闭 |
| CLOSE_WAIT | 远程已关闭 |

## 4.18 DISM (部署映像服务和管理)

### 常用命令

## 4.19 Windows 恢复环境 (WinRE)

### 进入方式
```
设置 → 更新和安全 → 恢复 → 高级启动 → 立即重新启动
或 开机时强制关机 3 次
```

### 高级启动选项
| 选项 | 功能 |
|------|------|
| 继续 | 退出并继续启动 Windows |
| 疑难解答 | 进入恢复选项 |
| 关闭电脑 | 关机 |

### 疑难解答选项
- **系统还原**：还原到还原点
- **系统映像恢复**：从备份恢复
- **启动修复**：自动修复启动问题
- **命令提示符**：高级修复
- **启动设置**：安全模式等
