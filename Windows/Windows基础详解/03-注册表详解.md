# 第三章 注册表详解

---

## 3.1 注册表概述

**作用：** 系统、硬件、软件、用户配置的层次化数据库

**物理文件位置：** `C:\Windows\System32\config\`

| 配置单元 | 对应根键 | 文件 |
|----------|----------|------|
| 默认 | HKCR | 合并自 HKLM\Classes 和 HKCU\Classes |
| 当前用户 | HKCU | NTUSER.DAT (用户目录) |
| 本地机器 | HKLM | SYSTEM, SOFTWARE, SAM, SECURITY |
| 所有用户 | HKU | 所有加载用户的 NTUSER.DAT |
| 当前配置 | HKCC | 当前硬件配置 |

---

## 3.2 五大根键详解

### HKEY_CLASSES_ROOT (HKCR)
- **含义：** 文件关联和 COM 对象注册
- **实际存储：** HKLM\Software\Classes + HKCU\Software\Classes
- **常见用途：** 文件类型关联、右键菜单

### HKEY_CURRENT_USER (HKCU)
- **含义：** 当前登录用户的配置
- **文件位置：** `C:\Users\用户名\NTUSER.DAT`
- **常见用途：** 用户偏好、应用设置、桌面配置

### HKEY_LOCAL_MACHINE (HKLM)
- **含义：** 本地计算机的硬件和软件配置
- **文件位置：** `C:\Windows\System32\config\`
- **常见用途：** 系统设置、驱动配置、服务

### HKEY_USERS (HKU)
- **含义：** 所有加载的用户配置
- **内容：** 包含 HKCU 和其他用户配置

### HKEY_CURRENT_CONFIG (HKCC)
- **含义：** 当前硬件配置
- **实际存储：** HKLM\System\CurrentControlSet\Hardware Profiles\Current

## 3.3 常用子项路径

### 开机启动项
```
HKCU\Software\Microsoft\Windows\CurrentVersion\Run
HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Run
```

### 服务配置
```
HKLM\SYSTEM\CurrentControlSet\Services
```

### 文件关联
```
HKCR\.扩展名          # 文件类型
HKCR\文件类型\shell   # 右键菜单
```

### 环境变量
```
HKLM\SYSTEM\CurrentControlSet\Control\Session Manager\Environment
```

### 自启动服务
```
HKLM\SYSTEM\CurrentControlSet\Services\服务名
Start 值：2=自动，3=手动，4=禁用
```

## 3.4 注册表编辑器使用

### 打开方式
```
方法 1: Win + R → regedit
方法 2: 搜索 "注册表编辑器"
方法 3: CMD → regedit
```

### 界面布局
```
左侧：树状结构（根键 → 子项）
右侧：键值列表
底部：状态栏（显示选中项路径）
```

### 键值类型

| 类型 | 说明 | 示例 |
|------|------|------|
| REG_SZ | 字符串 | "Hello" |
| REG_EXPAND_SZ | 可扩展字符串 | "%PATH%" |
| REG_BINARY | 二进制数据 | 00 01 02 03 |
| REG_DWORD | 32 位整数 | 12345678 |
| REG_QWORD | 64 位整数 | 大数字 |
| REG_MULTI_SZ | 多字符串 | 字符串数组 |

## 3.5 安全操作注册表

### ⚠️ 重要警告
> 错误的注册表修改可能导致系统无法启动！
> **修改前务必备份！**

### 备份注册表

**方法 1：导出整个注册表**
```
1. 文件 → 导出
2. 选择"全部"
3. 保存为 .reg 文件
4. 命名如：registry-backup-20260315.reg
```

**方法 2：导出特定分支**
```
1. 选中要备份的项
2. 文件 → 导出
3. 选择"所选分支"
4. 保存
```

**方法 3：创建系统还原点**
```
1. 搜索"创建还原点"
2. 系统保护选项卡 → 创建
3. 输入描述 → 创建
```

### 恢复注册表

**方法 1：导入 .reg 文件**
```
1. 双击 .reg 文件
2. 确认提示
3. 重启（如果需要）
```

**方法 2：注册表编辑器导入**
```
1. 文件 → 导入
2. 选择 .reg 文件
3. 确认
```

**方法 3：系统还原**
```
1. 搜索"系统还原"
2. 选择还原点
3. 按向导完成
```

## 3.6 常用注册表修改

### 禁用 UAC（不推荐）
```
路径：HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System
键名：EnableLUA
值：0 = 禁用，1 = 启用
```

### 显示文件扩展名
```
路径：HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced
键名：HideFileExt
值：0 = 显示，1 = 隐藏
```

### 加快菜单显示速度
```
路径：HKCU\Control Panel\Desktop
键名：MenuShowDelay
值：0-2000（毫秒，默认 400）
```

### 禁用 Windows Defender（临时）
```
路径：HKLM\SOFTWARE\Policies\Microsoft\Windows Defender
键名：DisableAntiSpyware
值：1 = 禁用，0 = 启用
```

## 3.7 命令行操作注册表

### reg 命令

```cmd
# 查询注册表
reg query HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion

# 查询特定值
reg query HKCU\Software\Microsoft\Windows\CurrentVersion\Run /v 值名

# 添加项
reg add HKCU\Software\MyApp /v Setting /t REG_SZ /d "Value" /f

# 删除项
reg delete HKCU\Software\MyApp /v Setting /f

# 导出注册表
reg export HKCU\Software\MyApp C:\backup.reg

# 导入注册表
reg import C:\backup.reg
```

### 参数说明
| 参数 | 含义 |
|------|------|
| `/v` | 值名称 |
| `/t` | 类型（REG_SZ、REG_DWORD 等） |
| `/d` | 数据 |
| `/f` | 强制，不提示 |
| `/s` | 递归查询子项 |

## 3.8 故障排查

### 注册表损坏症状
- 系统启动失败
- 应用无法打开
- 设置无法保存
- 蓝屏错误

### 修复方法
1. 使用系统还原
2. 从备份恢复
3. 运行 `sfc /scannow`
4. 使用 Windows 恢复环境
