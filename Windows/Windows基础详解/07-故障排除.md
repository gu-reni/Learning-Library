## 7.1 蓝屏 (BSOD) 分析

### 常见故障代码

| 代码 | 含义 | 可能原因 |
|------|------|----------|
| CRITICAL_PROCESS_DIED | 关键进程终止 | 驱动/系统文件损坏 |
| IRQL_NOT_LESS_OR_EQUAL | 内存访问违规 | 驱动冲突 |
| PAGE_FAULT_IN_NONPAGED_AREA | 内存页面错误 | 硬件/驱动问题 |
| SYSTEM_SERVICE_EXCEPTION | 系统服务异常 | 驱动/软件冲突 |
| MEMORY_MANAGEMENT | 内存管理错误 | 内存条故障 |
| KERNEL_SECURITY_CHECK_FAILURE | 内核安全检查失败 | 驱动/恶意软件 |
| WHEA_UNCORRECTABLE_ERROR | 硬件错误 | CPU/内存/主板故障 |
| DPC_WATCHDOG_VIOLATION | 驱动超时 | SSD 驱动/显卡驱动 |
| SYSTEM_THREAD_EXCEPTION_NOT_HANDLED | 系统线程异常 | 显卡驱动常见 |
| VIDEO_TDR_FAILURE | 显卡超时 | 显卡驱动/硬件 |

### 分析 Minidump

**步骤：**
```
1. 下载 WinDbg (Microsoft Store 搜索 "WinDbg Preview")
2. 文件 → 启动转储文件
3. 选择 C:\Windows\Minidump\*.dmp
4. 运行命令：!analyze -v
5. 查看输出：
   - FAILURE_BUCKET_ID: 故障分类
   - MODULE_NAME: 问题模块
   - IMAGE_NAME: 问题文件
   - STACK_TEXT: 调用堆栈
```

**在线分析工具：**
- https://www.osronline.com/page.cfm?name=analyze
- BlueScreenView (NirSoft)

### 蓝屏排查步骤

```
1. 记录错误代码和文件名
   - 拍照或记下 STOP 代码
   - 注意提到的驱动文件名

2. 回忆最近变更
   - 是否安装新硬件？
   - 是否更新驱动？
   - 是否安装新软件？

3. 进入安全模式
   - 开机时强制关机 3 次进入 WinRE
   - 疑难解答 → 高级选项 → 启动设置 → 重启
   - 按 4 进入安全模式

4. 卸载可疑项目
   - 设备管理器 → 回滚/卸载驱动
   - 控制面板 → 卸载最近安装的软件

5. 运行诊断工具
   - sfc /scannow
   - chkdsk C: /f /r
   - 内存诊断工具

6. 更新系统
   - Windows Update
   - 硬件厂商驱动

7. 检查硬件
   - 重新插拔内存
   - 检查散热
   - 测试电源
```

### 内存诊断

**Windows 内存诊断：**
```
1. 搜索 "Windows 内存诊断"
2. 立即重新启动并检查问题
3. 等待测试完成
4. 查看结果（事件查看器 → Windows 日志 → 系统）
```

**MemTest86（更彻底）：**
```
1. 下载 MemTest86
2. 制作启动 U 盘
3. 从 U 盘启动
4. 运行完整测试（建议 4 轮以上）
```

## 7.2 系统卡顿排查

### 排查流程

```
第 1 步：打开任务管理器 (Ctrl+Shift+Esc)

第 2 步：查看性能选项卡，确定瓶颈类型

┌─────────────────────────────────────────┐
│  CPU 100%   →  进程选项卡按 CPU 排序    │
│  内存>90%   →  检查内存泄漏             │
│  磁盘 100%  →  资源监视器分析           │
│  网络占用高 →  检查可疑连接             │
└─────────────────────────────────────────┘

第 3 步：使用资源监视器深入分析
        Win + R → resmon

第 4 步：检查事件查看器中的错误
        Win + R → eventvwr

第 5 步：运行系统文件检查
        sfc /scannow

第 6 步：检查磁盘健康
        chkdsk C: /f
        或使用 CrystalDiskInfo
```

### CPU 占用高

**常见原因：**
- Windows Update 后台下载
- 杀毒软件扫描
- 恶意软件
- 驱动问题

**排查：**
```
1. 任务管理器 → 进程 → 按 CPU 排序
2. 识别占用高的进程
3. 搜索进程名确认是否系统进程
4. 结束异常进程或卸载相关软件
5. 检查启动项
```

### 内存占用高

**常见原因：**
- 内存泄漏（驱动/软件 bug）
- 浏览器标签过多
- 后台程序过多

**排查：**
```
1. 任务管理器 → 进程 → 按内存排序
2. 资源监视器 → 内存 → 查看硬错误/秒
3. >50 表示频繁页面交换
4. 关闭占用高的程序
5. 考虑增加物理内存
```

### 磁盘 100%

**常见原因：**
- Windows Search 索引
- SysMain 服务
- 磁盘故障
- 杀毒软件扫描

**排查：**
```
1. 资源监视器 → 磁盘
2. 按"总计 (B/ 秒)"排序
3. 识别占用高的进程
4. 检查磁盘健康（CrystalDiskInfo）
5. 运行 chkdsk

临时解决：
- 禁用 Windows Search 服务
- 禁用 SysMain 服务
- 关闭 Windows Defender 实时保护（临时）
```

## 7.3 网络无法连接

### 分层排查法

```
物理层
├─ 网线是否插好？
├─ WiFi 是否开启？
├─ 路由器/调制解调器指示灯正常？
└─ 尝试重启路由器

链路层
├─ ipconfig 查看是否获取到 IP
├─ 169.254.x.x = DHCP 失败
└─ 尝试 ipconfig /release && ipconfig /renew

网络层
├─ ping 127.0.0.1（本地环回）
├─ ping 网关 IP
├─ ping 8.8.8.8（外网）
└─ 失败则检查路由/防火墙

传输层
├─ telnet 目标端口（测试端口连通性）
├─ netstat 查看连接状态
└─ 检查防火墙规则

应用层
├─ nslookup 测试 DNS
├─ 浏览器访问测试
└─ 检查代理设置
```

### 快速修复命令

```cmd
# 以管理员身份运行 CMD

# 释放并更新 IP
ipconfig /release
ipconfig /renew

# 刷新 DNS
ipconfig /flushdns

# 重置网络堆栈
netsh winsock reset
netsh int ip reset

# 重置防火墙
netsh advfirewall reset

# 重启电脑
shutdown /r /t 0
```

### WiFi 问题排查

```
1. 忘记网络重新连接
   设置 → 网络和 Internet → WiFi
   → 管理已知网络 → 忘记

2. 更新无线网卡驱动
   设备管理器 → 网络适配器
   → 右键无线网卡 → 更新驱动

3. 使用 netsh 查看 WiFi 配置
   netsh wlan show profiles
   netsh wlan show profile name=名称 key=clear

4. 重置网络
   设置 → 网络和 Internet → 状态
   → 网络重置
```

## 7.4 软件兼容性问题

### 兼容模式运行

```
1. 右键程序 → 属性
2. 兼容性选项卡
3. 勾选"以兼容模式运行这个程序"
4. 选择 Windows 版本（XP/7/8）
5. 可选设置：
   □ 以管理员身份运行
   □ 禁用全屏优化
   □ 高 DPI 设置替代
6. 应用 → 确定
```

### 安装运行库

**必备运行库：**
- Visual C++ Redistributable (2005-2022)
- .NET Framework 3.5/4.8
- DirectX End-User Runtime

**下载位置：**
- Microsoft 官网
- https://aka.ms/vs/17/release/vc_redist.x64.exe

### 应用无法打开

**排查步骤：**
```
1. 检查事件查看器
   Win + R → eventvwr
   → Windows 日志 → 应用程序
   → 查找错误事件

2. 运行应用兼容性疑难解答
   设置 → 更新和安全 → 疑难解答
   → 程序兼容性疑难解答

3. 重新安装应用

4. 检查依赖项
   使用 Dependency Walker 分析
```

## 7.5 启动问题

### 无法进入系统

**进入 WinRE：**
```
方法 1: 设置 → 更新和安全 → 恢复 → 高级启动
方法 2: 开机时强制关机 3 次
方法 3: 安装介质启动
```

**修复选项：**
| 选项 | 用途 |
|------|------|
| 启动修复 | 自动修复启动问题 |
| 系统还原 | 还原到还原点 |
| 系统映像恢复 | 从备份恢复 |
| 命令提示符 | 手动修复 |

### 命令提示符修复

```cmd
# 修复引导记录
bootrec /fixmbr
bootrec /fixboot
bootrec /scanos
bootrec /rebuildbcd

# 修复系统文件
sfc /scannow /offbootdir=C:\ /offwindir=C:\Windows

# 检查磁盘
chkdsk C: /f /r
```

### 启动慢

**排查：**
```
1. 任务管理器 → 启动 → 禁用不必要项
2. msconfig → 服务 → 隐藏 Microsoft 服务 → 禁用全部
3. 检查启动驱动
   设备管理器 → 查看 → 显示隐藏设备
4. 运行性能诊断
   设置 → 更新和安全 → 疑难解答
```

## 7.6 音频问题

### 无声排查

```
1. 检查音量设置
   点击任务栏喇叭图标
   确保未静音，音量合适

2. 检查播放设备
   右键喇叭 → 打开声音设置
   → 选择正确的输出设备

3. 更新音频驱动
   设备管理器 → 声音、视频和游戏控制器
   → 右键声卡 → 更新驱动

4. 运行音频疑难解答
   设置 → 更新和安全 → 疑难解答
   → 播放音频

5. 检查音频服务
   Win + R → services.msc
   → Windows Audio → 确保正在运行
```

## 7.8 更新问题

### 更新失败

**常见错误代码：**
| 代码 | 含义 |
|------|------|
| 0x80070002 | 文件找不到 |
| 0x80070003 | 路径找不到 |
| 0x80070020 | 进程占用 |
| 0x80070422 | 服务禁用 |
| 0x800f081f | 源文件找不到 |

**解决方法：**
```
1. 运行 Windows 更新疑难解答
   设置 → 更新和安全 → 疑难解答

2. 手动重置更新组件
   以管理员 CMD 运行：
   net stop wuauserv
   net stop cryptSvc
   net stop bits
   net stop msiserver
   ren C:\Windows\SoftwareDistribution SoftwareDistribution.old
   ren C:\Windows\System32\catroot2 catroot2.old
   net start wuauserv
   net start cryptSvc
   net start bits
   net start msiserver

3. 手动下载更新
   Microsoft Update Catalog
   https://www.catalog.update.microsoft.com/

4. 使用更新助手
   https://www.microsoft.com/zh-cn/software-download/windows10
```

## 7.10 高级故障排查

### 使用 WinDbg 分析内核转储

1. 安装 WinDbg Preview（Microsoft Store）。
2. 打开转储文件：`File` → `Open dump file`。
3. 设置符号路径：`.sympath srv*https://msdl.microsoft.com/download/symbols`。
4. 运行 `!analyze -v` 获取详细分析。
5. 关注 `MODULE_NAME` 和 `IMAGE_NAME` 字段，定位问题驱动。

### 使用 Performance Recorder 分析性能问题

1. 下载 Windows Performance Toolkit（ADK 的一部分）。
2. 以管理员身份运行 `wpr -start CPU -start DiskIO`。
3. 重现问题，运行 `wpr -stop C:\trace.etl`。
4. 使用 `wpa.exe`（Windows Performance Analyzer）打开 `.etl` 文件，分析 CPU、磁盘等。

### 修复启动的高级命令

- 重建 BCD：
```cmd
bootrec /fixmbr
bootrec /fixboot
bootrec /rebuildbcd
```

- 备份和恢复 BCD：
```cmd
bcdedit /export C:\bcd_backup
bcdedit /import C:\bcd_backup
```

- 使用 `bcdedit` 设置启动参数（如禁用驱动签名）：
```cmd
bcdedit /set {current} testsigning on
```

### 使用 Process Monitor 诊断应用崩溃

1. 启动 ProcMon，设置过滤器：`Process Name` → `is` → `崩溃程序名.exe`。
2. 运行程序，观察 ProcMon 捕获的文件、注册表、进程等操作。
3. 寻找 `ACCESS DENIED`、`NAME NOT FOUND` 等错误。
