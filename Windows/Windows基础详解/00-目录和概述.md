## 阅读建议

**初学者：** 按顺序阅读前七章及附录，先建立整体认知，后续可深入补充章节。

**快速查阅：** 使用附录的命令速查表及补充章节中的高级脚本示例。

## 工具打开方式速查

| 工具 | 运行命令 | 快捷键 |
|------|----------|--------|
| 任务管理器 | `taskmgr` | `Ctrl+Shift+Esc` |
| 注册表编辑器 | `regedit` | - |
| 设备管理器 | `devmgmt.msc` | `Win+X` → 设备管理器 |
| 磁盘管理 | `diskmgmt.msc` | `Win+X` → 磁盘管理 |
| 服务 | `services.msc` | - |
| 事件查看器 | `eventvwr` | - |
| 系统配置 | `msconfig` | - |
| 组策略 | `gpedit.msc` | - |
| 命令提示符 | `cmd` | `Win+R` → `cmd` |
| PowerShell | `powershell` | `Win+X` → PowerShell |
