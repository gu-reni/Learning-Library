## 6.2 性能优化技巧

### 调整电源计划

```
控制面板 → 电源选项
```

| 计划 | 适用场景 |
|------|----------|
| 节能 | 笔记本电池供电 |
| 平衡 | 日常使用（推荐） |
| 高性能 | 游戏、渲染 |
| 卓越性能 | Win10/11 专业工作站 |

**启用卓越性能模式：**
```powershell
powercfg -duplicatescheme e9a42b02-d5df-448d-aa00-03f14749eb61
```

### 关闭视觉效果

```
1. 系统 → 高级系统设置
2. 高级 → 性能 → 设置
3. 选择：
   - 调整为最佳性能（全部关闭）
   - 自定义（推荐保留：平滑屏幕字体、显示缩略图）
```

### 管理开机启动项

```
任务管理器 → 启动
```

**可禁用的常见启动项：**
| 程序 | 说明 |
|------|------|
| OneDrive | 不使用时禁用 |
| Skype | 需要时手动启动 |
| Steam/Epic | 游戏平台 |
| Adobe Creative Cloud | Adobe 套件 |
| 各类更新程序 | 手动检查更新 |

### 虚拟内存设置

```
1. 系统 → 高级系统设置
2. 高级 → 性能 → 高级 → 虚拟内存 → 更改
3. 取消"自动管理"
4. 自定义大小：
   - 初始大小 = 物理内存 × 1.5
   - 最大值 = 物理内存 × 3
5. 设置 → 确定 → 重启
```

**建议：** SSD 用户可让系统自动管理

### 禁用不必要的服务

```
Win + R → services.msc
```

| 服务 | 可禁用场景 |
|------|------------|
| Windows Search | 不使用文件搜索 |
| SysMain (Superfetch) | SSD 用户 |
| Print Spooler | 无打印机 |
| Bluetooth Support | 无蓝牙设备 |
| Xbox 相关服务 | 不玩游戏 |
| Windows Insider Service | 不参与测试 |

### 关闭后台应用

```
设置 → 隐私 → 后台应用
→ 关闭不必要的应用
```

### 存储感知

```
设置 → 系统 → 存储 → 存储感知
→ 启用自动清理
```

**配置：**
- 删除临时文件：每周
- 回收站：30 天后
- 下载文件夹：可选

## 6.3 磁盘空间管理

### 查看磁盘使用
```
设置 → 系统 → 存储
→ 点击磁盘查看详细内容
```

### 清理大文件

**使用 TreeSize 或 WinDirStat：**
- 可视化查看磁盘占用
- 找出占用空间最大的文件

**手动清理位置：**
| 路径 | 内容 | 可清理 |
|------|------|--------|
| `C:\Windows\Temp` | 系统临时文件 | ✅ |
| `C:\Users\用户名\AppData\Local\Temp` | 用户临时文件 | ✅ |
| `C:\Windows\SoftwareDistribution\Download` | 更新缓存 | ✅ |
| `C:\Windows\Installer` | 安装缓存 | ❌ 不要动 |

### 压缩旧文件
```
右键文件夹 → 属性 → 高级 → 压缩内容
适合：文档、日志等不常访问的文件
```

### 移动应用到其他盘
```
设置 → 应用 → 应用和功能
→ 选择应用 → 移动
```

## 6.4 备份与还原

### 系统还原点

**创建还原点：**
```
1. 搜索"创建还原点"
2. 系统保护选项卡 → 创建
3. 输入描述 → 创建
```

**配置还原点设置：**
```
1. 系统保护 → 配置
2. 启用系统保护
3. 设置磁盘空间使用量（建议 5-10%）
4. 确定
```

**还原系统：**
```
1. 搜索"系统还原"
2. 选择还原点
3. 按向导完成
```

### 文件历史记录

**设置：**
```
1. 设置 → 更新和安全 → 备份
2. 添加驱动器（外接硬盘）
3. 启用自动备份
```

**恢复文件：**
```
1. 备份 → 更多选项
2. 从当前备份还原文件
3. 选择文件版本 → 还原
```

### 系统映像备份

**创建：**
```
1. 控制面板 → 备份和还原 (Windows 7)
2. 创建系统映像
3. 选择保存位置（外接硬盘/网络）
4. 选择要备份的驱动器
5. 开始备份
```

**恢复：**
```
1. WinRE → 疑难解答 → 高级选项
2. 系统映像恢复
3. 选择映像 → 恢复
```

### 创建恢复驱动器

**需要：** 16GB+ U 盘

**步骤：**
```
1. 搜索"创建恢复驱动器"
2. 勾选"将系统文件备份到恢复驱动器"
3. 插入 U 盘 → 下一步
4. 等待完成
```

**使用：**
```
1. 从恢复驱动器启动
2. 选择疑难解答
3. 重置此电脑/高级选项
```

```

→ 回滚驱动程序
```

```
2. 进入安全模式
3. 运行 DDU
4. 选择完全清理
```

## 6.9 高级备份与部署

### 使用 wbadmin 命令行备份

```cmd
# 备份 C: 和系统状态到 E:\Backup
wbadmin start backup -backupTarget:E: -include:C: -allCritical -systemState -quiet

# 恢复系统状态
wbadmin start systemstaterecovery -version:01/01/2025-00:00

# 查看可用备份
wbadmin get versions
```

### 差异备份与增量备份

- 差异备份：`wbadmin start backup -backupTarget:E: -include:C: -allCritical -systemState -quiet -vssFull`
- 增量备份（默认）：不加 `-vssFull` 则执行增量备份。

### 系统准备 (sysprep)

- 用于部署 Windows 镜像，重置系统唯一标识符 (SID)。
- 运行：`C:\Windows\System32\sysprep\sysprep.exe /generalize /oobe /shutdown`
- 常用选项：
  - `/generalize`：删除系统特定信息
  - `/oobe`：下次启动进入 OOBE
  - `/shutdown`：完成后关机

### 使用 DISM 捕获和应用映像

```cmd
# 捕获 C 盘为 WIM
dism /Capture-Image /ImageFile:D:\backup.wim /CaptureDir:C:\ /Name:"WindowsBackup"

# 应用映像到新硬盘
dism /Apply-Image /ImageFile:D:\backup.wim /Index:1 /ApplyDir:C:\
```

### 无人值守安装应答文件

- 创建 `autounattend.xml`，放置于 USB 根目录。
- 可自动跳过 OOBE、分区、产品密钥等步骤。
