# 第二章 文件系统与存储

---

## 2.1 文件系统对比

| 文件系统 | 最大分区 | 最大文件 | 适用场景 | 优缺点 |
|----------|----------|----------|----------|--------|
| **FAT32** | 32GB | 4GB | U 盘、兼容旧设备 | ✅ 兼容性好 ❌ 不支持大文件 |
| **NTFS** | 256TB | 16TB | 系统盘、数据盘 | ✅ 权限/加密/压缩 ❌ Mac 只读 |
| **ReFS** | 35PB | 16EB | 服务器、存储池 | ✅ 数据完整性 ❌ 不支持启动 |

---

## 2.2 NTFS 详解

### 核心结构

| 结构 | 说明 |
|------|------|
| **MFT (主文件表)** | 每个文件一条记录，包含属性信息 |
| **$LogFile** | 日志文件，记录元数据变更 |
| **$Bitmap** | 记录簇的使用状态 |
| **$Boot** | 引导扇区 |
| **$Secure** | 安全描述符数据库 |

### NTFS 特性

**权限 (ACL)**
```
右键文件/文件夹 → 属性 → 安全
- 完全控制
- 修改
- 读取和执行
- 读取
- 写入
```

**EFS 加密**
```
右键文件 → 属性 → 高级 → 加密内容以保护数据
⚠️ 务必备份 EFS 证书！
```

**压缩**
```
右键文件/文件夹 → 属性 → 高级 → 压缩内容
适合：文档、日志等不常访问的文件
不适合：已压缩文件（视频、图片）
```

**硬链接 vs 符号链接**
| 类型 | 特点 | 命令 |
|------|------|------|
| 硬链接 | 同一文件的多个入口，删除一个不影响 | `mklink /H` |
| 符号链接 | 类似快捷方式，可跨卷 | `mklink` |
| 目录联接 | 目录级别的符号链接 | `mklink /J` |

## 2.3 磁盘管理

### 分区样式

| 样式 | 最大分区 | 分区数 | 兼容性 |
|------|----------|--------|--------|
| **MBR** | 2TB | 4 个主分区 | 所有系统 |
| **GPT** | 18EB | 128 个分区 | UEFI 必需 |

### 卷类型

| 类型 | 说明 | 最少磁盘 | 冗余 |
|------|------|----------|------|
| 简单卷 | 单磁盘分区 | 1 | ❌ |
| 跨区卷 | 多磁盘顺序写入 | 2 | ❌ |
| 带区卷 (RAID 0) | 并行读写，性能最佳 | 2 | ❌ |
| 镜像卷 (RAID 1) | 数据冗余 | 2 | ✅ |
| RAID-5 卷 | 分布式奇偶校验 | 3 | ✅ |

## 2.4 磁盘管理工具

### 打开磁盘管理
```
方法 1: Win + X → 磁盘管理
方法 2: Win + R → diskmgmt.msc
方法 3: 控制面板 → 管理工具 → 计算机管理
```

### 常用操作

**新建分区**
```
1. 右键未分配空间 → 新建简单卷
2. 指定大小
3. 分配盘符
4. 格式化（NTFS，分配单元大小默认）
```

**扩展卷**
```
条件：必须有相邻的未分配空间
右键分区 → 扩展卷 → 按向导操作
```

**压缩卷**
```
右键分区 → 压缩卷
系统会计算最大可压缩空间
```

**更改盘符**
```
右键分区 → 更改驱动器号和路径
→ 更改 → 选择新盘符
```

## 2.5 磁盘清理

### 打开方式
```
方法 1: 右键磁盘 → 属性 → 磁盘清理
```

## 2.7 Check Disk (chkdsk)

### 打开方式
```
管理员 CMD 或 PowerShell
```

### 常用命令

```cmd
# 检查并修复 C 盘
chkdsk C: /f

# 完全扫描并修复（耗时较长）
chkdsk C: /f /r

# 下次启动时检查（系统盘需要）
chkdsk C: /f /r
# 提示时按 Y，重启后自动执行

# 仅检查不修复
chkdsk C:
```

### 参数说明
| 参数 | 功能 |
|------|------|
| `/f` | 修复错误 |
| `/r` | 查找坏扇区并恢复 |
| `/x` | 强制卸载卷 |
| `/b` | 重新分配坏簇（NTFS） |

## 2.8 存储空间 (Storage Spaces)

### 什么是存储空间
软件定义的 RAID 解决方案，可将多个物理磁盘组合成存储池

### 创建存储池
```
1. 控制面板 → 存储空间
2. 创建新池
3. 选择磁盘
4. 选择弹性类型：
   - 简单（无冗余）
   - 双向镜像
   - 三向镜像
   - 奇偶校验
```

## 2.9 动态磁盘与 diskpart 脚本

### 动态磁盘卷类型

| 卷类型 | 说明 | diskpart 命令 |
|--------|------|----------------|
| 简单卷 | 单磁盘 | `create volume simple size=10000 disk=1` |
| 镜像卷 | RAID 1 | `create volume mirror disk=1,2` |
| RAID-5 卷 | 带奇偶校验 | `create volume raid disk=1,2,3` |

### diskpart 脚本示例

创建 `diskpart_script.txt`：
```txt
select disk 0
clean
convert gpt
create partition efi size=100
format quick fs=fat32 label="System"
assign letter="S"
create partition msr size=16
create partition primary
format quick fs=ntfs label="Windows"
assign letter="C"
exit
```

执行：`diskpart /s diskpart_script.txt`

### 存储空间高级管理

使用 PowerShell 管理存储池：

```powershell
New-StoragePool -FriendlyName "MyPool" -PhysicalDisks (Get-PhysicalDisk | Where-Object CanPool -eq $true)
New-VirtualDisk -StoragePoolName "MyPool" -FriendlyName "MyDisk" -Size 1TB -ResiliencySettingName Mirror
Initialize-Disk -VirtualDisk (Get-VirtualDisk -FriendlyName "MyDisk")
New-Partition -DiskNumber 5 -UseMaximumSize -DriveLetter D
Format-Volume -DriveLetter D -FileSystem NTFS
```
