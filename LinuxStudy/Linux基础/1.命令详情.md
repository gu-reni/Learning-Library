## 1.文件与目录操作
### ls：查看目录内容
- **-l**：长格式显示（详细信息）
- **-a**：显示所有文件（包括隐藏文件）
- **-h**：人类可读的文件大小（配合-l使用）
- **-t**：按修改时间新旧排序
- **-r**：反向排序
- **-S**：按文件大小排序
- **-R**：递归显示子目录
- **-d**：显示目录本身
- **-F**：添加文件类型标识符
- **-i**：显示inode编号
- **-1**：每行只显示一个文件
- **--color**：彩色显示（默认打开状态)
```
ls -l /home/user  # 显示目录详细列表，包含权限、所有者、大小和修改时间
ls -a ~  # 显示家目录所有文件，包括隐藏文件(以.开头的)
ls -lh /var/log  # 显示日志目录文件，大小以K/M/G格式显示
ls -lt /tmp  # 按修改时间排序，最新修改的文件在最前面
ls -ltr /tmp  # 按修改时间反向排序，最旧的文件在最前面
ls -lS /var/log  # 按文件大小降序排列，最大的在最前面
ls -R project/  # 递归显示project目录及其所有子目录内容
ls -ld /etc  # 显示/etc目录本身的详细信息，而不是其内容
```
### cd：切换目录
- **~**：家目录
- **..**：上级目录
- **-**：返回上一次目录
- **目录名/**：相对路径
- **/目录名/子目录名/文件名**：绝对路径
```

cd ~  # 切换到当前用户的家目录
cd ..  # 切换到当前目录的上级目录
cd /var/log && cd /home/user && cd -  # 先到日志目录，再到家目录，然后返回日志目录
cd Documents/  # 切换到当前目录下的Documents子目录
cd /usr/local/bin  # 切换到绝对路径指定的目录
```
###  pwd：显示当前目录
- **-p**：物理路径
- **-L**：逻辑路径
- ```
cd /usr/share && pwd  # 显示当前所在目录的完整路径：/usr/share
cd /usr/bin && pwd -P  # 显示真实的物理路径(解析符号链接)，例如/usr/bin可能是链接到/usr/bin
cd /usr/bin && pwd -L  # 显示逻辑路径，包含符号链接
  ```
  
### cp:复制文件
  - **-r**：递归复制目录
  - **-i**：交互模式
  - **-v**:显示详细信息
  - **-p**：保留属性
  - **-u**：仅复制新文件
  - **-a**：归档模式
```
cp file.txt backup/  # 将file.txt复制到backup目录
cp -r source_dir/ backup_dir/  # 递归复制整个目录及其内容
cp -i important.txt backup/  # 复制文件前询问是否覆盖已存在的文件
cp -rv source/ dest/  # 递归复制并显示每个复制的文件
cp -p config.conf backup/  # 复制文件并保留权限、时间戳等属性
cp -u *.jpg images/  # 只复制比目标目录中更新的jpg文件
cp -a project/ backup/  # 归档复制，保留所有文件属性和目录结构
```
### mv：移动/重命名文件
  - **-i**：交互模式
  - **-v**：显示详细信息
  - **-n**：不覆盖
  - **-b**：创建备份
```
mv old_name.txt new_name.txt  # 将文件重命名为new_name.txt
mv file.txt /tmp/  # 将文件移动到/tmp目录
mv -i important.txt /tmp/  # 移动前询问是否覆盖目标文件
mv -v *.log /var/log/archive/  # 移动所有日志文件并显示每个操作
mv -n new_file.txt /tmp/  # 移动文件，如果目标存在则不覆盖
mv -b config.conf backup/  # 移动文件，如果目标存在则创建备份
```
### rm：删除文件
- **-r**：递归删除
- **-i**：交互模式
- **-f**：强制删除
- **-v**：显示详情
- **-d**：删除空目录
```
rm temp.txt  # 删除temp.txt文件
rm -r old_dir/  # 递归删除目录及其所有内容
rm -i *.tmp  # 删除所有tmp文件，每个文件删除前都询问
rm -f lock.file  # 强制删除文件，不提示，即使文件不存在也不报错
rm -v *.log  # 删除所有日志文件并显示每个删除的文件名
rm -d empty_dir/  # 删除空目录
# 警告：这个命令非常危险，会强制递归删除目录
rm -rf /tmp/old_data/  # 强制递归删除/tmp/old_data/目录及其所有内容
```
### mkdir：创建目录
- **-p**：递归创建目录（如果父目录不存在也一并创建）
- **-v**：显示创建目录的详细信息
- **-m**：设置目录权限（类似chmod）
```

mkdir dir1                     # 创建名为dir1的目录
mkdir -p project/{src,docs,test}  # 创建project目录及其三个子目录
mkdir -v backup                # 创建backup目录并显示操作信息
mkdir -m 755 secure_dir        # 创建目录并设置权限为755
mkdir -p /tmp/data/{2023,2024}/{Q1,Q2,Q3,Q4}  # 创建多层目录结构
```
### rmdir：删除空目录
- **-p**：递归删除空目录（删除指定目录后，如果其父目录也变为空，则一并删除）
- **-v**：显示删除目录的详细信息
```

rmdir empty_dir                # 删除名为empty_dir的空目录
rmdir -v temp                  # 删除temp目录并显示操作信息
rmdir -p a/b/c                 # 递归删除目录c，如果b变为空则删除b，如果a变为空则删除a
rmdir dir1 dir2 dir3           # 同时删除多个空目录
rmdir --ignore-fail-on-non-empty dir  # 仅在目录为空时删除（默认行为）
```
### touch：创建空文件或更新时间戳
- **-a**：仅更改访问时间（access time）
- **-m**：仅更改修改时间（modification time）
- **-c**：不创建新文件（如果文件不存在）
- **-t**：使用指定时间戳（格式：[[CC]YY]MMDDhhmm[.ss]）
- **-d**：使用字符串表示的时间
```

touch newfile.txt              # 创建名为newfile.txt的空文件（如果不存在则创建）
touch file1.txt file2.txt file3.txt  # 同时创建多个文件
touch -c existing.txt          # 仅更新时间戳，如果文件不存在则不创建
touch -m important.txt         # 更新文件的修改时间为当前时间
touch -a config.conf           # 更新文件的访问时间为当前时间
touch -t 202312251200.00 file  # 将文件时间设置为2023年12月25日12:00
touch -d "2024-01-01" log.txt  # 将文件时间设置为2024年1月1日
touch -r reference.txt target.txt  # 将target.txt的时间设为与reference.txt相同
touch --date="2 days ago" oldfile  # 将文件时间设置为2天前
```

### chattr：更改文件属性（ext2/3/4文件系统专用）

**作用**：修改文件或目录的扩展属性（不可变、追加只写等），提供比标准权限更底层的保护
- **+**：添加属性
- **-**：移除属性
- **=**：设置属性（覆盖原有属性）
- **-R**：递理目录及其内容
- **-V**：显示详细执行过程
- **-f**：抑制大多数错误消息
- **-v**：设置文件版本/世代编号（仅限支持版本的文件系统）
**常用属性**：
- **a**：append only（只能追加内容，不能删除或修改）
- **i**：immutable（不可修改：不能删除、重命名、修改、创建硬链接）
- **c**：compress（自动压缩文件）
- **d**：no dump（dump备份时忽略此文件）
- **s**：secure deletion（安全删除：文件被删除时用0填充磁盘空间）
- **u**：undeletable（文件删除后内容可恢复）
- **A**：no atime updates（不更新访问时间）
- **S**：synchronous updates（同步更新：文件修改立即写入磁盘）
- **j**：data journalling（数据日志：ext3/4文件系统上的数据日志）
- **t**：no tail-merging（禁用尾部合并）
- **D**：synchronous directory updates（目录同步更新）
- **e**：extent format（使用extents映射磁盘块）
```
# 基本格式
chattr [选项] [+-=属性] 文件/目录

# 使文件不可变（连root用户也无法修改）
chattr +i important_file.txt

# 移除不可变属性
chattr -i important_file.txt

# 使文件只能追加内容（常用于日志文件）
chattr +a /var/log/syslog

# 移除追加属性
chattr -a /var/log/syslog

# 递归设置目录及其内容为不可变
chattr -R +i /etc/important_configs/

# 设置多个属性
chattr +aAi file.txt

# 查看文件属性（使用lsattr）
lsattr file.txt

# 设置文件同步写入（每次修改立即写磁盘）
chattr +S transaction.log

# 设置文件不更新访问时间
chattr +A database.db

# 设置文件自动压缩
chattr +c large_file.bin

# 设置安全删除
chattr +s secret_file.txt

# 设置文件可恢复
chattr +u important_document.txt

# 设置dump备份忽略
chattr +d temp_cache.db

# 查看并设置属性（显示过程）
chattr -V +i /etc/resolv.conf

# 递归设置目录属性但不包括目录本身
chattr -R +a /var/log/app/*

# 批量设置多个文件的属性
chattr +i file1.txt file2.txt file3.txt

# 设置并检查结果
chattr +i critical.conf && lsattr critical.conf

# 使用=号设置确切属性（覆盖原有属性）
chattr =i file.txt  # 只设置i属性，移除其他所有属性

# 组合属性：不可变且同步更新
chattr +iS system_config.conf

# 针对日志目录的特殊保护
chattr +a /var/log/apache2/*.log

# 保护系统关键文件
chattr +i /etc/passwd
chattr +i /etc/shadow
chattr +i /etc/group
chattr +i /etc/sudoers

# 保护脚本不被修改
chattr +i /usr/local/bin/custom_script.sh

# 递归保护整个目录结构
chattr -R +i /root/backups/

# 保护SSH密钥文件
chattr +i ~/.ssh/authorized_keys
chattr +i ~/.ssh/config

# 移除目录递归属性
chattr -R -i /etc/  # 小心使用！

# 设置文件版本号（需要文件系统支持）
chattr -v 10 versioned_file.txt

# 抑制错误消息
chattr -f +i non_existent_file.txt 2>/dev/null

# 使用find命令批量设置属性
find /home/user/docs -type f -name "*.pdf" -exec chattr +i {} \;

# 保护内核参数文件
chattr +i /etc/sysctl.conf

# 保护系统服务文件
chattr +i /etc/systemd/system/*.service

# 保护Web配置文件
chattr +i /etc/nginx/nginx.conf
chattr +i /etc/apache2/apache2.conf

# 保护数据库配置文件
chattr +i /etc/mysql/my.cnf

# 保护cron配置文件
chattr +i /etc/crontab
chattr +i /etc/cron.*/*
```

### lsattr：查看文件扩展属性

- **-a**：显示所有文件的属性（包括隐藏文件）
- **-d**：显示目录本身的属性（而非内容）
- **-R**：递归显示子目录中文件的属性
- **-v**：显示文件版本/生成号（ext文件系统）
- **-p**：显示项目编号（用于版本控制的ext文件系统）
```
lsattr file.txt          # 查看单个文件的扩展属性
lsattr -a ~              # 查看家目录所有文件（包括隐藏文件）的扩展属性
lsattr -d Documents/     # 查看Documents目录本身的扩展属性
lsattr -R project/       # 递归查看project目录下所有文件的扩展属性
lsattr -v important.pdf  # 查看文件的版本信息
```

### file：检测文件类型
- **-b**：简洁模式，不显示文件名
- **-i**：显示MIME类型
- **-L**：跟随符号链接
- **-z**：查看压缩文件内部
- **-k**：不停止在第一个匹配类型
- **--mime-type**：仅显示MIME类型
- **--mime-encoding**：显示MIME编码
```
file document.pdf      # 检测PDF文件类型
file -i image.jpg      # 显示文件的MIME类型
file -L /usr/bin/ls    # 显示符号链接指向的文件类型
file -z backup.tar.gz  # 查看压缩文件的内部类型
file -b /bin/bash      # 简洁显示文件类型，不显示文件名
file script.sh         # 检测shell脚本文件类型
file -k unknown.bin    # 尝试多种匹配来确定文件类型
file --mime-type data.txt  # 仅显示文件的MIME类型
```

### find：查找文件和目录
- **-name**：按文件名查找（支持通配符）
- **-type**：按文件类型查找（f：普通文件，d：目录，l：符号链接）
- **-size**：按文件大小查找（+：大于，-：小于）
- **-mtime**：按修改时间查找（+n：n天前修改，-n：n天内修改）
- **-user**：按文件所有者查找
- **-perm**：按文件权限查找
- **-exec**：对查找到的文件执行命令
- **-maxdepth**：最大搜索深度
- **-mindepth**：最小搜索深度
- **-iname**：不区分大小写的文件名查找
- **-delete**：删除查找到的文件
```

find . -name "*.txt"           # 在当前目录查找所有.txt文件
find /home -type f -name "*.conf"  # 在/home目录查找所有.conf文件
find /var/log -type f -size +10M   # 查找/var/log中大于10MB的文件
find . -type d -name "cache"   # 查找所有名为cache的目录
find . -mtime -7              # 查找7天内修改过的文件
find . -mtime +30             # 查找30天前修改过的文件
find /home -user alice        # 查找属于用户alice的所有文件
find . -perm 644             # 查找权限为644的文件
find . -name "*.tmp" -exec rm {} \;  # 查找所有.tmp文件并删除
find . -maxdepth 1 -name "*.sh"      # 仅在当前目录查找.sh文件（不进入子目录）
find . -name "*.jpg" -o -name "*.png"  # 查找jpg或png文件
find . -type f -empty         # 查找所有空文件
find . -name "temp*" -delete  # 查找并删除所有以temp开头的文件
find . -type f -exec chmod 644 {} \;  # 查找所有文件并将权限改为644
```
#### 高级find示例：
```

# 查找并显示文件详细信息
find ~/Documents -name "*.pdf" -ls

# 查找并复制到备份目录
find . -name "*.bak" -exec cp {} /backup/ \;

# 查找特定大小的文件并排序
find . -type f -size +100k -exec ls -lh {} \; | sort -k5,5hr

# 查找最近修改的10个文件
find . -type f -printf '%T+ %p\n' | sort -r | head -10

# 查找并统计文件数量
find . -type f -name "*.py" | wc -l

# 查找并压缩文件
find . -name "*.log" -mtime +30 -exec gzip {} \;

# 查找并更改所有权
find /var/www -type f -exec chown www-data:www-data {} \;
```

### mknod：创建特殊文件（块设备、字符设备、命名管道）
- **-m**：设置文件权限模式（八进制）
- **-Z**：设置SELinux安全上下文
- **--help**：显示帮助信息
- **--version**：显示版本信息
```
mknod /dev/sdb1 b 8 17   # 创建块设备文件，主设备号8，次设备号17
mknod /dev/random c 1 8  # 创建字符设备文件，主设备号1，次设备号8
mknod mypipe p           # 创建FIFO（命名管道）
mknod -m 644 myfifo p    # 创建FIFO，并设置权限为644
mknod /dev/null c 1 3    # 创建空设备文件（字符设备）
```

### ln：创建硬链接或符号链接
- **-s**：创建符号链接（软链接）
- **-f**：强制覆盖已存在的目标文件
- **-n**：把符号链接视为普通文件处理（避免覆盖目录）
- **-v**：显示详细执行过程
- **-i**：交互模式，覆盖前询问
- **-b**：覆盖前备份目标文件
- **-t**：指定目标目录
- **-L**：将符号链接转换为硬链接
- **-P**：创建符号链接时保留原链接（默认行为）
```
ln source.txt link.txt       # 创建硬链接link.txt指向source.txt
ln -s /usr/bin/python3 py    # 创建符号链接py指向/usr/bin/python3
ln -f source.txt link.txt    # 强制创建硬链接，覆盖已存在的link.txt
ln -sv /etc/passwd passwd    # 创建符号链接并显示过程
ln -i file1.txt file2.txt    # 创建硬链接，若file2.txt存在则询问是否覆盖
ln -s -t dir/ /path/to/file  # 在dir目录下创建指向/path/to/file的符号链接
ln -b target.txt link.txt    # 创建链接，若link.txt存在则备份原文件
```

**设备类型**：
- **b**：块设备（如磁盘分区）
- **c**：字符设备（如终端、串口）
- **p**：FIFO（命名管道）
**主设备号**：标识设备驱动程序  
**次设备号**：标识该驱动程序管理的具体设备实例

### rsync：远程/本地文件同步工具
- **-a, --archive**：归档模式（递归并保留属性：权限、所有者、组、时间、符号链接、设备等）
- **-v, --verbose**：显示详细信息
- **-z, --compress**：传输时压缩数据
- **-r, --recursive**：递归目录
- **-u, --update**：跳过目标目录中较新的文件
- **-n, --dry-run**：模拟运行，不实际传输文件
- **-P**：等同 `--partial --progress`（支持断点续传并显示进度）
- **--delete**：删除目标目录中源目录不存在的文件
- **--exclude=PATTERN**：排除匹配模式的文件
- **--include=PATTERN**：包含匹配模式的文件
- **-e, --rsh=COMMAND**：指定远程 shell（如 `ssh`）
- **--bwlimit=RATE**：限制 I/O 带宽（KB/s）
- **--max-size=SIZE**：不传输大于指定大小的文件
- **--min-size=SIZE**：不传输小于指定大小的文件
- **--progress**：显示传输进度
- **--stats**：显示传输统计信息
- **-h, --human-readable**：以人类可读格式输出数字
- **--partial**：保留部分传输的文件（用于断点续传）
- **-l**：保持符号链接
- **-p**：保持权限
- **-t**：保持修改时间
- **-g**：保持组
- **-o**：保持所有者（需要超级用户）
- **-D**：保持设备文件（需要超级用户）
```
rsync -av /source/ /destination/                     # 本地同步目录
rsync -av /home/user/ /backup/user/                   # 备份本地用户目录
rsync -avz /local/ user@remote:/remote/                # 通过 SSH 推送本地到远程
rsync -av user@remote:/remote/ /local/                 # 从远程拉取到本地
rsync -av --delete /src/ /dest/                         # 同步并删除目标多余文件
rsync -av --exclude='*.log' /var/log/ /backup/logs/     # 排除 .log 文件
rsync -avP bigfile.iso user@remote:/tmp/                # 带进度和断点续传传输大文件
rsync -av --bwlimit=500 /data/ /backup/                  # 限制带宽 500 KB/s
rsync -avn /etc/ /backup/etc/                            # 模拟运行，预览将要同步的文件
rsync -av --max-size='50M' /photos/ /backup/photos/      # 跳过大于 50MB 的文件
```

### split：将文件分割成多个小文件
- **-l, --lines=N**：按行数分割，每个输出文件包含 N 行（默认值 1000）
- **-b, --bytes=N**：按字节数分割，每个输出文件大小为 N 字节（支持 K, M, G 等单位）
- **-d, --numeric-suffixes**：使用数字后缀（00, 01, 02...）而非字母后缀（aa, ab, ac...）
- **-a, --suffix-length=N**：指定后缀长度（默认 2）
- **--additional-suffix=STRING**：为每个输出文件添加额外后缀（如 `.txt`）
- **-n, --number=CHUNKS**：将文件分割成指定数量的文件（如 `-n l/3` 按行数均分，`-n k/3` 按大小均分）
- **-e, --elide-empty-files**：与 `-n` 配合，避免生成空文件
- **-t, --separator=CHAR**：使用指定字符作为行分隔符（默认换行符）
- **-C, --line-bytes=N**：每个输出文件最多包含 N 字节，但尽量保持行的完整性
- **--verbose**：显示分割进度
```
split largefile.txt                         # 分割为 xaa, xab, xac... 每文件1000行
split -l 500 largefile.txt                    # 每文件500行
split -b 10M largefile.bin                     # 每文件10MB
split -d -a 3 largefile.txt part_                # 生成 part_000, part_001... 数字后缀
split -b 1K --additional-suffix=.txt data.txt chunk   # 生成 chunk00.txt, chunk01.txt...
split -n l/5 largefile.txt                     # 将文件均分成5份（按行数）
split -n 3 largefile.txt                        # 按大小均分成3份
split -t ',' data.csv                            # 使用逗号作为分隔符
split -C 1024 log.txt                            # 每个文件最大1KB，但保持行的完整
split -e -n 10 emptyfile.txt                      # 若文件为空，避免生成空文件
```

### od：以八进制、十六进制等格式显示文件内容

    - **-t u**：无符号十进制

- **-j**：跳过指定字节数开始显示
- **-N**：限制显示的总字节数
- **-v**：显示所有数据（不省略重复行）
- **-w**：指定每行显示的字节数
- **-s**：显示十进制有符号偏移量

### diff：比较文件差异
- **-u, -U NUM, --unified[=NUM]**：生成统一格式的输出（包含上下文，默认3行）
- **-c, -C NUM, --context[=NUM]**：生成上下文格式的输出
- **-i, --ignore-case**：忽略大小写差异
- **-w, --ignore-all-space**：忽略所有空白差异
- **-b, --ignore-space-change**：忽略空白数量的变化
- **-B, --ignore-blank-lines**：忽略空行的差异
- **-q, --brief**：仅报告文件是否不同，不输出具体差异
- **-r, --recursive**：递归比较子目录
- **-N, --new-file**：将缺失文件视为空文件
- **-a, --text**：将所有文件视为文本（即使包含二进制数据）
- **-s, --report-identical-files**：报告文件相同的信息
- **-y, --side-by-side**：并排显示差异
- **-W, --width=NUM**：指定并排显示时的列宽
- **-d, --minimal**：尝试找出最小的差异集合
- **-x, --exclude=PAT**：排除匹配模式的文件
- **-X, --exclude-from=FILE**：从文件读取排除模式
- **--brief**：同 -q
- **--help**：显示帮助信息
```

### patch：应用补丁文件
- **-pNUM, --strip=NUM**：剥离路径名中的前 NUM 个斜杠（用于调整补丁文件中的路径）
- **-i FILE, --input=FILE**：从指定文件读取补丁（而非标准输入）
- **-R, --reverse**：反向应用补丁（撤销已应用的补丁）
- **-N, --forward**：忽略已应用的补丁（不询问直接跳过）
- **-E, --remove-empty-files**：如果应用补丁后文件变为空，则删除该文件
- **-d DIR, --directory=DIR**：在应用补丁前切换到指定目录
- **-s, --quiet, --silent**：静默模式，只输出错误信息
- **--dry-run**：模拟应用补丁，不实际修改文件
- **-b, --backup**：备份原始文件（通常生成 .orig 后缀）
- **-V STYLE, --version-control=STYLE**：指定备份版本控制风格（如 numbered, existing, simple）
- **-r FILE, --reject-file=FILE**：将无法应用的块（rejects）保存到指定文件
- **-o FILE, --output=FILE**：将输出写入指定文件，而不直接修改原文件
- **-t, --batch**：自动跳过询问，直接应用（非交互模式）
- **-f, --force**：强制应用，假设所有问题都回答“是”
- **-e, --ed**：将补丁文件视为 ed 脚本
- **-n, --normal**：将补丁文件视为普通 diff 输出
- **-u, --unified**：将补丁文件视为 unified diff 格式（通常自动检测）
- **--help**：显示帮助信息并退出
```
patch < file.diff                         # 从标准输入应用补丁到当前目录文件
patch -i patch.diff                         # 从 patch.diff 文件应用补丁
patch -p1 < patchfile                        # 剥离一级路径（如 a/ 和 b/ 前缀）
patch -R -i patch.diff                        # 反向应用补丁（撤销）
patch -N -i patch.diff                         # 忽略已应用的块
patch -d /src -i patch.diff                    # 切换到 /src 目录后应用补丁
patch --dry-run -i patch.diff                   # 模拟应用，预览更改
patch -b -i patch.diff                           # 应用补丁并备份原文件（.orig）
patch -r rejects.txt -i patch.diff               # 将拒绝的块保存到 rejects.txt
patch -o output.txt -i patch.diff                 # 将补丁结果输出到 output.txt
patch -p1 < ~/patch-1.diff                         # 从用户主目录读取补丁
```

### cmp：比较两个文件
- **-b, --print-bytes**：打印不同的字节
- **-i, --ignore-initial=SKIP**：忽略每个文件开头的 SKIP 个字节
- **-i SKIP1:SKIP2**：忽略文件1开头的 SKIP1 个字节和文件2开头的 SKIP2 个字节
- **-l, --verbose**：输出所有不同字节的编号和值
- **-n, --bytes=LIMIT**：最多比较 LIMIT 个字节
- **-s, --quiet, --silent**：静默模式，不输出任何信息，仅通过退出码指示结果
- **--help**：显示帮助信息
- **--version**：显示版本信息
```
cmp file1.txt file2.txt                 # 比较两个文件，输出第一个不同的位置
cmp -l file1.bin file2.bin               # 列出所有不同的字节（带偏移量和值）
cmp -s file1.txt file2.txt                # 静默比较，仅通过 $? 判断是否相同
cmp -i 10 file1.txt file2.txt              # 跳过每个文件前10个字节再比较
cmp -i 20:30 a.txt b.txt                   # 跳过a.txt前20字节，b.txt前30字节
cmp -n 100 file1.txt file2.txt              # 只比较前100个字节
cmp -b file1.txt file2.txt                  # 显示第一个不同字节的详细信息
```

### iconv：转换文件编码

- **-t, --to-code=NAME**：指定目标编码
- **-l, --list**：列出所有支持的编码
- **-o, --output=FILE**：指定输出文件（默认为标准输出）
- **-c**：忽略输出中无法转换的字符
- **-s, --silent**：关闭警告信息
- **--verbose**：显示详细信息

### tr：转换或删除字符
- **-c, -C, --complement**：使用字符集的补集（即除指定字符外的所有字符）
- **-d, --delete**：删除指定字符，不进行转换
- **-s, --squeeze-repeats**：压缩连续重复的字符为单个字符
- **-t, --truncate-set1**：先将 SET1 截断为与 SET2 等长，再进行转换
- **--help**：显示帮助信息并退出
- **--version**：显示版本信息并退出

tr -c 'a-zA-Z' '\n' < file.txt               # 将非字母字符替换为换行（分割单词）

### col：过滤反向换行符和控制字符

### join：连接两个文件中的共同字段
- **-a FILENUM**：显示文件1或文件2中不匹配的行（FILENUM=1或2）
- **-v FILENUM**：仅显示文件1或文件2中不匹配的行
- **-e STRING**：用指定字符串替换缺失的输入字段
- **-o FORMAT**：自定义输出格式（如`1.2,2.1`表示文件1的字段2和文件2的字段1）
- **-t CHAR**：指定字段分隔符（默认空格或制表符）
- **-1 FIELD**：指定文件1中用于连接的字段（默认第1字段）
- **-2 FIELD**：指定文件2中用于连接的字段（默认第1字段）
- **-i**：忽略大小写比较
- **--check-order**：检查输入文件是否已按连接字段排序（若未排序则报错）
- **--nocheck-order**：不检查输入排序（默认）
- **--header**：将每个文件的第一行视为标题行，不参与比较
```
# 假设 file1.txt 内容：
# 1 apple
# 2 banana
# file2.txt 内容：
# 1 red
# 2 yellow
join file1.txt file2.txt                # 按第一字段连接，输出：1 apple red，2 banana yellow
join -t',' file1.csv file2.csv           # 指定逗号为分隔符
join -1 2 -2 1 file1.txt file2.txt       # 用文件1的第2字段与文件2的第1字段连接
join -a 1 file1.txt file2.txt            # 显示文件1所有行（包括不匹配的）
join -v 2 file1.txt file2.txt            # 仅显示文件2中不匹配的行
join -e "NULL" -o 1.1,2.2 file1.txt file2.txt  # 缺失字段用NULL替换，输出字段1.1和2.2
join -i file1.txt file2.txt              # 忽略大小写连接
```

### paste：合并文件行

### printf：格式化并输出数据

### pr：将文本文件转换成适合打印的格式

- **-n, --number-lines[=DELIMITER]**：显示行号，可选分隔符（默认为制表符）

- **-d, --double-space**：双倍行距
- **-F, --form-feed**：使用换页符分页（而非连续的换行）
- **-m, --merge**：同时打印多个文件，每个文件占一列
- **-s[CHAR]**：使用单个字符分隔列（默认制表符）
- **-J**：合并整行，不截断行

### chown：修改文件所有者
- **user:group**：修改所有者和组
- **-R**：递归修改
- **-v**：显示详细信息
- **-c**：只有发生更改时才显示
```
chown user:group file.txt  # 修改文件所有者和组
chown -R user:group dir/  # 递归修改目录所有者和组
chown user file.txt  # 只修改所有者
chown :group file.txt  # 只修改组
```

### chgrp：更改文件或目录的所属组
- **-R**：递归更改目录及其所有内容的所属组
- **-v**：显示详细信息（verbose）
- **-c**：只在发生更改时显示信息
- **-f**：不显示错误信息（silent）
- **-h**：修改符号链接本身而非其指向的目标文件
```
chgrp developers file.txt        # 将file.txt的所属组更改为developers组
chgrp -R www-data /var/www/      # 递归将/var/www/目录及其所有内容的所属组更改为www-data
chgrp -v staff document.pdf      # 将document.pdf的组更改为staff并显示操作信息
chgrp -c users *.txt             # 将当前目录下所有txt文件的组更改为users，只在更改时显示信息
chgrp -h mygroup symlink         # 更改符号链接本身的所属组，而不是它指向的文件
chgrp --reference=ref.txt file.txt  # 将file.txt的组设置为与ref.txt相同
```

### umask：设置文件创建默认权限掩码

- **-S**：以符号方式显示当前umask值
- **-p**：输出可重用的格式（当与-S一起使用时)
```
umask             # 显示当前umask值（数字形式）
umask -S          # 以符号形式显示当前umask值（如u=rwx,g=rx,o=rx）
umask 022         # 设置umask值为022（常用值）
umask 002         # 设置umask值为002（组用户有写权限）
umask 077         # 设置umask值为077（其他用户无任何权限）
umask u=rwx,g=rx,o=rx  # 设置符号形式的umask值
```
**umask值说明**：
- **默认权限**：目录777(rwxrwxrwx)，文件666(rw-rw-rw-)
- **实际权限** = 默认权限 - umask值
- **常见umask值**：
    - **022**：目录权限755(rwxr-xr-x)，文件权限644(rw-r--r--)
    - **027**：目录权限750(rwxr-x---)，文件权限640(rw-r-----)
    - **002**：目录权限775(rwxrwxr-x)，文件权限664(rw-rw-r--)
    - **077**：目录权限700(rwx------)，文件权限600(rw-------)

## 6.压缩与归档
### tar：打包/解包文件
- **-c**：创建归档文件
- **-x**：解压归档文件
- **-z**：使用gzip压缩/解压
- **-j**：使用bzip2压缩/解压
- **-J**：使用xz压缩/解压
- **-v**：显示详细信息
- **-f**：指定归档文件名
- **-t**：列出归档内容
- **-C**：指定解压目录

tar -xvf archive.tar -C /tmp/  # 解压到指定目录
tar -tf archive.tar.gz  # 列出归档文件内容
```

### gzip/gunzip：压缩/解压文件
- **-d**：解压缩
- **-r**：递归处理目录
- **-k**：保留原始文件
- **-l**：列出压缩文件信息
- **-v**：显示详细信息
- **-1到-9**：压缩级别（1最快，9最好）
```
gzip file.txt  # 压缩文件（生成file.txt.gz）
gzip -d file.txt.gz  # 解压缩
gzip -r dir/  # 递归压缩目录下所有文件
gzip -9 file.txt  # 最高级别压缩
gunzip file.txt.gz  # 解压缩（等同于gzip -d）
```

### zip：压缩文件（zip格式）
- **-r**：递归处理目录
- **-q**：安静模式
- **-e**：加密压缩
- **-9**：最大压缩
- **-d**：从压缩文件中删除文件
```
zip archive.zip file1.txt file2.txt  # 压缩多个文件
zip -r archive.zip dir/  # 递归压缩目录
zip -e secure.zip file.txt  # 加密压缩
zip -d archive.zip file.txt  # 从压缩文件中删除文件
```

### unzip：解压zip文件
- **-l**：列出压缩文件内容
- **-d**：指定解压目录
- **-o**：覆盖已存在文件（不询问）
- **-q**：安静模式
- **-P**：指定密码
```
unzip archive.zip  # 解压zip文件
unzip -l archive.zip  # 列出压缩文件内容
unzip archive.zip -d /tmp/  # 解压到指定目录
unzip -P password secure.zip  # 使用密码解压
```

### bzip2/bunzip2：压缩/解压文件（bzip2格式）
- **-d**：解压缩
- **-k**：保留原始文件
- **-v**：显示详细信息
- **-z**：压缩（bzip2默认）
```
bzip2 file.txt  # 压缩文件（生成file.txt.bz2）
bzip2 -d file.txt.bz2  # 解压缩
bzip2 -k file.txt  # 压缩但保留原始文件
bunzip2 file.txt.bz2  # 解压缩（等同于bzip2 -d）
```

### xz/unxz：压缩/解压文件（xz格式）
- **-d**：解压缩
- **-k**：保留原始文件
- **-z**：压缩（xz默认）
- **-v**：显示详细信息
- **-l**：列出压缩文件信息
```
xz file.txt  # 压缩文件（生成file.txt.xz）
xz -d file.txt.xz  # 解压缩
xz -k file.txt  # 压缩但保留原始文件
unxz file.txt.xz  # 解压缩（等同于xz -d）
```

### cpio：归档文件复制工具
- **-o, --create**：创建归档（输出模式）
- **-i, --extract**：提取归档（输入模式）
- **-p, --pass-through**：复制模式（不创建归档，直接复制到目标目录）
- **-v, --verbose**：显示处理过程
- **-d, --make-directories**：根据需要创建目录
- **-u, --unconditional**：无条件覆盖现有文件
- **-m, --preserve-modification-time**：保留文件的修改时间
- **-F, --file=FILE**：指定归档文件名（替代标准输入/输出）
- **-H, --format=FORMAT**：指定归档格式（bin, odc, newc, crc, tar, ustar, hpbin, hpodc）
- **-t, --list**：列出归档内容（需与 -i 配合）
- **-c**：使用旧的 ASCII 格式（等价于 -H odc）
- **-B**：设置 I/O 块大小为 5120 字节（默认 512）
- **-0, --null**：处理以 null 结尾的文件名（常与 find -print0 配合）
- **--quiet**：不打印版本信息
```
find . -name "*.txt" -print | cpio -ov > text.cpio       # 创建包含所有 .txt 文件的归档
cpio -idv < text.cpio                                     # 提取归档到当前目录
cpio -idv -F backup.cpio                                   # 从指定归档文件提取
find /etc -type f -print | cpio -pdm /backup/etc          # 复制 /etc 下所有文件到 /backup/etc
cpio -itvF archive.cpio                                    # 列出归档内容
find . -depth -print | cpio -pdm /target                   # 复制目录树，保留目录结构
find /home/user -type f -print0 | cpio -0ov > user.cpio    # 创建包含空格文件名的归档
cpio -iduv < incremental.cpio                               # 提取并覆盖已存在的文件
cpio -H tar -ovF files.tar /home/user                       # 创建 tar 格式的归档
find /usr/bin -size +100k -print | cpio -oc > largebin.cpio # 创建旧 ASCII 格式归档
```

## 8.磁盘管理

### xfsdump：XFS文件系统备份工具
- **-l, --level**：指定备份级别（0-9），0表示完全备份，1-9表示增量备份

- **-M, --media-label**：设置介质标签

- **-e, --exclude**：排除设置了"nodump"属性的文件
- **-J, --no-inventory**：不更新库存数据库
- **-I, --inventory**：显示库存信息
- **-R, --resume**：恢复中断的备份会话
- **-p, --progress**：指定进度报告间隔（秒）
- **-v, --verbose**：设置输出详细级别（silent/verbose/trace/debug）
- **-a, --dmf-offline**：跳过DMF完全离线文件
- **-z, --max-size**：指定跳过超过大小的文件（KB）
- **-b, --blocksize**：指定块大小（字节）
- **-d, --file-size**：指定媒体文件大小（MB）
- **-o, --overwrite**：强制覆盖磁带而不检查
```

xfsdump -e -f /backup/no_nodump.dump /data                # 跳过设置了nodump属性的文件

### xfsrestore：XFS文件系统恢复工具
- **-f, --file**：指定备份源文件或设备

- **-i, --interactive**：交互式恢复，允许选择文件
- **-I, --inventory**：显示备份库存信息
- **-t, --test**：测试备份文件内容（不实际恢复）

- **-v, --verbose**：设置详细级别（silent/verbose/trace/debug）
- **-x, --extract**：提取单个文件（需与-s连用）
- **-D, --destination**：指定恢复目标目录（默认为当前目录）
- **-a, --dmf-offline**：跳过DMF完全离线文件
- **-y, --yes**：对所有交互式问题自动回答“yes”
- **-R, --resume**：从中断处继续恢复
- **-o, --overwrite**：覆盖现有文件
```

**说明**：

- 可与磁带设备、普通文件或远程设备配合使用

### dd：转换和复制文件
- **if=FILE**：指定输入文件（默认为 stdin）
- **of=FILE**：指定输出文件（默认为 stdout）
- **bs=BYTES**：一次读写的字节数（可覆盖 ibs 和 obs）
- **ibs=BYTES**：一次读取的字节数
- **obs=BYTES**：一次写入的字节数
- **count=N**：仅复制 N 个输入块
- **skip=N**：跳过输入前 N 个块
- **seek=N**：跳过输出前 N 个块
- **conv=CONVS**：按逗号分隔的转换参数（如 notrunc, noerror, sync, fsync 等）
- **status=LEVEL**：输出信息级别（none, noxfer, progress）
- **iflag=FLAGS**：输入标志（如 fullblock, direct, nocache 等）
- **oflag=FLAGS**：输出标志（如 append, direct, sync 等）
```
dd if=/dev/zero of=file.img bs=1M count=10      # 创建 10MB 空文件
dd if=/dev/sda of=/backup/mbr.bin bs=512 count=1 # 备份主引导记录 (MBR)
dd if=/dev/sda of=/backup/disk.img bs=4M         # 克隆整个磁盘到镜像文件
dd if=/backup/disk.img of=/dev/sdb bs=4M         # 从镜像恢复到新磁盘
dd if=/dev/urandom of=/dev/sda bs=4M status=progress   # 用随机数据擦除磁盘（显示进度）
dd if=/dev/cdrom of=cd.iso bs=2048                # 将光盘复制为 ISO 镜像
dd if=/dev/sda2 | gzip > sda2.gz                  # 压缩备份分区
dd if=/dev/zero of=/swapfile bs=1M count=2048     # 创建 2GB swap 文件
dd if=/dev/sda of=/dev/null bs=1M                  # 测试读取速度（只读不写）
dd if=/dev/zero of=/tmp/test bs=1M count=100 conv=fsync # 测试写入速度并强制同步
dd if=/dev/sda of=/dev/sdb bs=4096 conv=noerror,sync  # 复制磁盘，忽略错误并填充同步
dd iflag=fullblock if=/dev/zero of=file bs=1M count=10  # 确保完整读取（用于管道）
dd if=/dev/sda of=mbr.bin bs=446 count=1            # 备份 MBR 的引导代码（不含分区表）
dd if=/dev/zero of=/dev/sda bs=512 seek=1 count=2047 # 擦除 MBR 之后的分区表区域
```

### echo：输出文本或变量值
- **-n**：不输出末尾的换行符

- **-E**：禁用转义字符的解释（默认选项）
- **--help**：显示帮助信息（仅限GNU版本）
- **--version**：显示版本信息（仅限GNU版本）
**常用转义序列**（需配合 `-e` 使用）：
- **\a**：警告声（响铃）
- **\b**：退格
- **\c**：不输出末尾换行（类似 `-n`）
- **\e**：转义字符（Escape）
- **\f**：换页
- **\n**：换行
- **\r**：回车
- **\t**：水平制表符
- **\v**：垂直制表符
- **\\**：反斜杠
- **\0NNN**：八进制值（NNN为八进制数）
- **\xHH**：十六进制值（HH为十六进制数）
```

echo -e "Line1\nLine2"             # 启用转义，输出两行

echo "The cost is \$10"             # 输出 The cost is $10（转义$）

echo -e "\0125"                      # 输出 U（八进制125）
```

- **-C, --chdir=DIR**：在执行命令前切换到指定目录（GNU 扩展）
- **-v, --verbose**：显示详细信息（GNU 扩展）
- **--help**：显示帮助信息并退出
- **--version**：显示版本信息并退出
```

### read：从标准输入读取一行
- **-p PROMPT**：在读取前输出提示符
- **-t TIMEOUT**：设置超时时间（秒）
- **-s**：静默模式，不回显输入（常用于密码）
- **-n N**：读取 N 个字符后返回
- **-d DELIM**：使用指定字符作为行结束符（默认为换行）
- **-a ARRAY**：将单词读入数组
- **-r**：禁止反斜杠转义（原样读取）
- **-e**：使用 Readline 获取行（支持行编辑）
- **-u FD**：从指定文件描述符读取
- **-N N**：严格读取 N 个字符（不处理分隔符）
```
read name                    # 从键盘读取一行并存入变量 name
read -p "请输入你的名字: " name  # 带提示符的读取
read -s -p "输入密码: " pass    # 静默读取密码
read -t 5 -p "5秒内输入: " input # 超时5秒
read -n 1 -p "按任意键继续" key   # 读取单个字符
read -d ":" field             # 以冒号为分隔符读取
read -a arr                   # 将输入的单词存入数组 arr
read -r rawline               # 原样读取包含反斜杠的行
echo "12345" | read number    # 从管道读取（子 shell 中有效）
echo "1 2 3" | while read a b c; do echo "$a - $b - $c"; done  # 读取并拆分
read -u 3 line                # 从文件描述符3读取
```

### declare：声明变量并设置属性
- **-a**：声明索引数组
- **-A**：声明关联数组
- **-i**：声明整数变量（算术运算时自动求值）
- **-r**：声明只读变量（不可修改）
- **-x**：声明导出变量（类似 export）
- **-p**：显示变量的属性和值
- **-l**：声明变量，值在赋值时转换为小写
- **-u**：声明变量，值在赋值时转换为大写
- **-c**：声明变量，值在赋值时首字母大写（GNU扩展）
- **-f**：仅显示函数名和定义（当配合 -p 时显示函数定义）
- **-F**：仅显示函数名
- **-g**：在函数内部创建全局变量（默认局部）
- **+**：取消属性（例如 `+r` 取消只读，但只读一旦设置无法取消）
```
declare -i num=5                # 声明整数变量
declare -r PI=3.14              # 声明只读变量
declare -x PATH="$PATH"         # 导出环境变量（等价 export PATH）
declare -p PATH                  # 显示 PATH 变量的属性和值
declare -a fruits=("apple" "banana")   # 声明索引数组
declare -A capitals=([CN]="Beijing" [US]="Washington")  # 声明关联数组
declare -l lower="HELLO"         # 赋值后自动转为小写：hello
declare -u upper="world"         # 赋值后自动转为大写：WORLD
declare -c capital="hello"       # 赋值后首字母大写：Hello（GNU扩展）
declare -f myfunc                # 显示 myfunc 函数的定义
declare -F                       # 列出所有函数名
myfunc() { declare -g global_var="全局"; }  # 函数内创建全局变量
declare +r var                   # 尝试取消只读属性（只读变量无法修改）
```

### typeset：设置变量属性（declare 的同义词）
- **-i**：声明整数变量
- **-r**：声明只读变量
- **-x**：导出变量（环境变量）
- **-a**：声明索引数组
- **-A**：声明关联数组
- **-p**：显示变量的属性和值
- **-l**：值转换为小写
- **-u**：值转换为大写
- **-f**：仅显示函数名
- **-g**：在函数内创建全局变量（Bash 中需配合其他选项）
```
typeset -i num=10                 # 声明整数变量
typeset -r PI=3.1415              # 声明只读变量
typeset -x PATH="$PATH"           # 导出环境变量
typeset -a fruits=(apple banana)  # 声明索引数组
typeset -A capitals=([CN]="Beijing")  # 声明关联数组
typeset -p num                    # 显示变量属性和值
typeset -l lower="ABC"            # 赋值后转为小写：abc
typeset -u upper="xyz"            # 赋值后转为大写：XYZ
```
**说明**：
- `typeset` 是 Korn shell 中的命令，在 Bash 中与 `declare` 完全相同，功能完全一致。
- 在 Bash 脚本中，`typeset` 和 `declare` 可互换使用，但 `declare` 更为常见。

### ulimit：获取或设置用户资源限制
- **-a**：显示所有当前资源限制
- **-c**：core 文件的最大大小（块）
- **-d**：数据段的最大大小（千字节）
- **-f**：可创建文件的最大大小（块）
- **-l**：可锁定内存的最大大小（千字节）
- **-m**：常驻内存的最大大小（千字节）
- **-n**：可打开文件描述符的最大数量
- **-p**：管道缓冲区的大小（512字节块）
- **-s**：堆栈的最大大小（千字节）
- **-t**：CPU 时间上限（秒）
- **-u**：用户可运行的最大进程数
- **-v**：虚拟内存的最大大小（千字节）
- **-H**：设置/显示硬限制（只有 root 可增加）
- **-S**：设置/显示软限制（可动态调整至硬限制）
```

ulimit -n 4096                   # 将打开文件数上限设为 4096
ulimit -u 100                     # 将用户进程数上限设为 100
ulimit -c unlimited               # 允许生成任意大小的 core 文件
ulimit -c 0                       # 禁止生成 core 文件
ulimit -s 8192                     # 设置堆栈大小为 8MB
ulimit -Hn                        # 显示打开文件数的硬限制
ulimit -Sn 1024                    # 设置打开文件数的软限制为 1024
ulimit -S -c unlimited            # 设置 core 文件软限制为无限制
```

### stty：设置或显示终端行设置
- **-a**：显示所有当前终端设置
- **-g**：以可恢复格式输出当前设置（常用于保存和恢复）
- **erase CHAR**：设置退格字符（如 `^H` 或 `^?`）
- **kill CHAR**：设置删除整行字符
- **intr CHAR**：设置中断字符（通常为 `^C`）
- **quit CHAR**：设置退出字符（通常为 `^\`）
- **start CHAR**：设置启动输出字符（通常为 `^Q`）
- **stop CHAR**：设置停止输出字符（通常为 `^S`）
- **eof CHAR**：设置文件结束字符（通常为 `^D`）
- **rows N**：设置终端行数
- **cols N**：设置终端列数
- **sane**：将终端重置为合理默认值
- **raw**：将终端设置为原始模式（无处理，常用于串口）
- **cooked**：恢复为处理模式（默认）
- **-echo**：关闭回显
- **echo**：打开回显
- **-icanon**：关闭规范模式（立即读取字符）
- **icanon**：开启规范模式（行缓冲）
```
stty -a                      # 显示所有终端设置
stty -g                      # 以可恢复格式显示当前设置
stty erase ^H                 # 设置退格键为 Ctrl+H
stty erase ^?                 # 设置退格键为 Del（常用）
stty kill ^U                  # 设置删除整行为 Ctrl+U
stty intr ^C                  # 设置中断字符为 Ctrl+C
stty rows 50 cols 132         # 设置终端为 50 行 132 列
stty sane                     # 将终端重置为合理默认值
stty raw                      # 启用原始模式（常用于串口通信）
stty cooked                   # 恢复为规范模式
stty -echo                    # 关闭回显（输入不可见）
stty echo                     # 开启回显
stty -icanon                  # 关闭规范模式（字符立即可用）
stty icanon                   # 开启规范模式
stty -a | grep intr           # 查找当前中断字符设置
```

### test：检查文件类型和比较值
- **文件判断**：
  - **-e FILE**：文件存在
  - **-f FILE**：文件存在且为普通文件
  - **-d FILE**：文件存在且为目录
  - **-r FILE**：文件存在且可读
  - **-w FILE**：文件存在且可写
  - **-x FILE**：文件存在且可执行
  - **-s FILE**：文件存在且大小大于0
  - **-L FILE**：文件存在且为符号链接
- **字符串比较**：
  - **-z STRING**：字符串长度为0
  - **-n STRING**：字符串长度非0
  - **STRING1 = STRING2**：字符串相等
  - **STRING1 != STRING2**：字符串不等
- **数值比较**：
  - **INT1 -eq INT2**：相等
  - **INT1 -ne INT2**：不等
  - **INT1 -gt INT2**：大于
  - **INT1 -ge INT2**：大于等于
  - **INT1 -lt INT2**：小于
  - **INT1 -le INT2**：小于等于
- **逻辑操作**：
  - **! EXPR**：逻辑非
  - **EXPR1 -a EXPR2**：逻辑与
  - **EXPR1 -o EXPR2**：逻辑或
```
test -f /etc/passwd && echo "File exists"          # 检查文件是否存在且为普通文件
test -d "$HOME" || echo "Home directory missing"   # 检查目录是否存在
test -z "$var" && echo "Variable is empty"         # 检查变量是否为空
test "$USER" = "root" && echo "You are root"       # 字符串比较
test 10 -gt 5 && echo "10 > 5"                      # 数值比较
test -r file.txt -a -w file.txt && echo "Read and write"  # 与操作
test ! -x script.sh && echo "Not executable"        # 非操作
```

## 11. 管道与重定向

### |：管道（将一个命令的输出作为另一个的输入）
```
ls -la | grep "txt"  # 列出文件并搜索包含txt的行
ps aux | grep nginx  # 查看进程并搜索nginx
cat file.txt | sort | uniq  # 读取文件、排序、去重
```

### >：输出重定向（覆盖）
```
ls > filelist.txt  # 将ls的输出保存到文件（覆盖）
echo "Hello" > greeting.txt  # 将字符串保存到文件
command > output.txt 2>&1  # 将标准输出和错误输出都重定向到文件
```

### >>：输出重定向（追加）
```
echo "New line" >> file.txt  # 追加内容到文件
date >> log.txt  # 将当前日期追加到日志文件
```

### <：输入重定向
```
sort < unsorted.txt  # 从文件读取输入
wc -l < document.txt  # 统计文件行数
```

### 2>：错误输出重定向
```
command 2> error.log  # 将错误输出重定向到文件
ls nofile 2> /dev/null  # 将错误输出重定向到/dev/null（丢弃）
```

### &>：标准输出和错误输出都重定向
```

command &> output.log  # 将标准输出和错误输出都重定向到文件
ls -la &> all_output.txt  # 将所有输出重定向到文件
```

### tee：读取标准输入并输出到标准输出和文件
- **-a, --append**：追加到文件而不是覆盖
- **-i, --ignore-interrupts**：忽略中断信号
- **-p**：诊断写入非管道的错误（GNU扩展）
- **-o**：忽略写入管道时的错误（GNU扩展）
- **--output-error=MODE**：设置输出错误时的行为（warn/nop/warn-nop/exit等）
```
echo "Hello World" | tee file.txt                # 输出到屏幕并写入file.txt
echo "New line" | tee -a file.txt                 # 追加到file.txt
ls -l | tee /tmp/listing.txt                       # 将ls输出同时保存到文件
ps aux | tee process.txt | grep root               # 保存完整进程列表并过滤root进程
./script.sh | tee log.txt                           # 运行脚本并同时记录输出到日志
tee file1.txt file2.txt < input.txt                 # 将input.txt内容同时写入两个文件
make 2>&1 | tee build.log                           # 将标准错误也重定向到标准输出并记录
```

### xargs：从标准输入构建和执行命令行
- **-0, --null**：以 null 字符分隔输入（处理包含空格或特殊字符的文件名，常与 `find -print0` 配合）
- **-a, --arg-file=FILE**：从指定文件读取参数，而非标准输入
- **-d, --delimiter=DELIM**：自定义输入分隔符（默认为空白字符）
- **-E EOF**：指定逻辑结束标志（遇到此标志后停止读取）
- **-I R**：将输入参数替换到命令中的占位符 R 处（例如 `-I {}`）
- **-L, --max-lines=MAX-LINES**：每个命令行最多使用 MAX-LINES 行输入
- **-n, --max-args=MAX-ARGS**：每个命令行最多使用 MAX-ARGS 个参数
- **-P, --max-procs=MAX-PROCS**：最多同时运行 MAX-PROCS 个进程（并行执行）
- **-p, --interactive**：交互模式，执行每条命令前询问确认
- **-t, --verbose**：在执行前打印命令（调试用）
- **-r, --no-run-if-empty**：如果输入为空，则不执行命令（默认行为）
- **-s, --max-chars=MAX-CHARS**：每个命令行的最大字符数限制
- **--show-limits**：显示系统对命令行长度和进程数量的限制
- **--process-slot-var=VAR**：为每个子进程设置环境变量以区分进程槽
```
find . -name "*.log" -print0 | xargs -0 rm -f        # 删除所有 .log 文件（安全处理空格）
cat filelist.txt | xargs -I {} cp {} /backup/        # 将列表中的每个文件复制到 /backup
echo "file1 file2 file3" | xargs -n 1                # 每行一个参数输出
ls *.txt | xargs -n 2 echo "处理:"                    # 每两个文件分组处理
xargs -a commands.txt -L 1 sh                         # 逐行执行 commands.txt 中的命令
find /etc -name "*.conf" | xargs grep "localhost"     # 搜索所有 .conf 文件中的字符串
seq 1 10 | xargs -P 4 -I {} echo "Process {}"        # 并行执行 4 个进程
xargs -p -t -n 1 rm < filelist                         # 交互且详细，逐个删除文件
xargs --show-limits                                    # 显示系统参数限制
printf "a\0b\0c" | xargs -0 -n 1 echo                  # 处理 null 分隔的数据
```

## 12. 其他常用命令
### exit：退出当前Shell或脚本
- **[n]**：指定退出状态码（n为数字，0表示成功，非0表示错误）
```
exit  # 退出当前Shell
exit 0  # 成功退出
exit 1  # 退出，状态码1表示一般错误
```

### startx：启动X Window系统图形界面
详情可见[X Windows](obsidian://open?vault=Obsidian%20Vault&file=LinuxStudy%2FRocky%2FX%20Windows)
```
startx  # 启动图形界面
startx /usr/bin/openbox  # 启动指定窗口管理器
```

### clear：清屏
**快捷键**：Ctrl+L
```
clear  # 清除终端屏幕
```

### which：显示命令的完整路径
- **-a**：显示所有匹配的路径
```
which ls  # 显示ls命令的路径
which -a python  # 显示所有python命令的路径
```

### whereis：定位命令的二进制、源码和手册页
- **-b**：只搜索二进制文件
- **-m**：只搜索手册页
- **-s**：只搜索源码
```
whereis ls  # 显示ls命令的位置
whereis -b python  # 只显示python的二进制文件位置
whereis -m gcc  # 只显示gcc的手册页位置
```

### locate：快速查找文件
- **-i**：忽略大小写
- **-r**：使用正则表达式
- **-c**：只显示匹配数量
- **-e**：只显示存在的文件
```
locate passwd  # 查找包含passwd的文件
locate -i "*.jpg"  # 查找所有jpg文件（忽略大小写）
locate -c "*.txt"  # 统计txt文件数量
sudo updatedb  # 更新locate数据库（需要root权限）
```

### whatis：显示命令的简要描述
```
whatis ls  # 显示ls命令的简要描述
whatis grep  # 显示grep命令的简要描述
```

### apropos：搜索手册页描述
- **-e**：精确匹配
- **-w**：匹配单词
```
apropos copy  # 搜索包含copy的手册页
apropos -e "file system"  # 精确搜索
```
