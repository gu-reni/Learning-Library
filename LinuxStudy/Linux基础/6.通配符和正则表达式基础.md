# 六.通配符和正则表达式基础
## 通配符（Shell Glob）：
```
*        # 匹配任意字符（零个或多个）
?        # 匹配单个字符
[abc]    # 匹配a、b或c中的任意一个
[a-z]    # 匹配a到z中的任意一个
[!abc]   # 匹配除a、b、c外的任意字符
{1,2,3}  # 扩展为1, 2, 3
```

### 示例：
```
ls *.txt           # 所有.txt文件
ls file?.txt       # file1.txt, file2.txt等
ls [abc]*.txt      # 以a、b或c开头的.txt文件
rm temp[0-9].log   # 删除temp0.log到temp9.log
cp file.{txt,bak}  # 复制file.txt到file.bak
```

## 基础正则表达式：
```
.        # 匹配任意单个字符
^        # 匹配行首
$        # 匹配行尾
*        # 前一个字符出现0次或多次
[]       # 字符集
[^]      # 否定字符集
\{n,m\}  # 前一个字符出现n到m次
```

## 扩展正则表达式（-E）：
```
?        # 前一个字符出现0次或1次
+        # 前一个字符出现1次或多次
|        # 或
()       # 分组
```
