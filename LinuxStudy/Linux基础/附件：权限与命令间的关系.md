# 一、让用户能进入某目录成为可工作目录的基本权限是什么
- **可使用的命令**：例如***cd***等变换工作目录的命令
- **目录所需的权限**：用户对这个目录至少需要具有***x***的权限
- **额外需求**：如果用户想要在这个目录里用***ls***查看文件名还需要***r***权限
# 二、用户在某个目录内读取一个文件的基本权限是什么
- **可使用的命令**：例如***cat***
- **目录所需的权限**：至少具有***x***
- **文件所需权限**：至少具有***r***
# 三、让用户可以修改一个文件的基本权限是什么
- **可使用的命令**：例如nano，vim
- **目录所需的权限**：至少***x***
- **文件所需权限**：至少有***r***，***w***
# 四、让一个用户可以建立一个文件的基本权限是什么
- **目录所需的权限**：要具有***w***，***x***，重点在***w***，***w***是创造和删除的的权力，***x***是允许进入的权力，先进去才能创建
# 五、让用户进入某目录并执行该目录下的某个命令的基本权限是什么
- **目录所需的权限**：至少要***x***
- **文件所需权限**：至少要***x***
