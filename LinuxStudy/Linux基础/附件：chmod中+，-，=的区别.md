## 三种操作符号对比

|符号|含义|特点|示例|
|---|---|---|---|
|**`+`**|**添加**权限|只添加指定权限，不影响其他权限|`chmod u+x file`|
|**`-`**|**移除**权限|只移除指定权限，不影响其他权限|`chmod g-w file`|
|**`=`**|**设置**权限|设置精确的权限，其他未提及的权限会被移除|`chmod o=rx file`|

---

## 详细解释

### 1. **`+`（添加权限）**

```
# 给所有者添加执行权限
chmod u+x script.sh
# 结果：如果原来是 rw-r--r--，变成 rwxr--r--

# 给组和其他人添加读权限
chmod go+r document.txt
# 结果：如果原来是 rw-------，变成 rw-r--r--
```

**特点**：

- 只添加权限，不改变其他已有权限

- 安全的权限修改方式

- 适合逐步增加权限


---

### 2. **`-`（移除权限）**

```
# 移除其他用户的写权限
chmod o-w file.txt
# 结果：如果原来是 rwxrwxrwx，变成 rwxrwxr-x

# 移除组和其他的执行权限
chmod go-x program.sh
# 结果：如果原来是 rwxr-xr-x，变成 rwxr--r--
```
**特点**：

- 只移除指定权限

- 不会添加任何新权限

- 适合安全加固，减少权限


---

### 3. **`=`（设置精确权限）**
```
# 设置其他用户的权限为只读
chmod o=r file.txt
# 结果：其他用户只有读权限，没有写和执行权限

# 设置所有用户的权限为读写执行
chmod a=rwx directory/
# 结果：ugo都变成rwx

# 清除所有权限
chmod a= file.txt
# 结果：没有任何权限（---------）
```

**特点**：

- 设置精确的权限组合
- 未提及的权限会被清除
- 适合精确控制权限


---

## 实际对比示例

### 假设文件初始权限：`rwxr-xr--` (754)
```
# 1. 使用 + 添加权限
chmod g+w file# 结果：rwxrwxr-- (774)
# 只给组加了写权限，其他权限不变

# 2. 使用 - 移除权限
chmod o-r file# 结果：rwxr-x--- (750)
# 只移除了其他用户的读权限

# 3. 使用 = 设置权限
chmod g=rw file   # 结果：rwxrw-r-- (764)
# 组权限被精确设置为rw，之前组的x权限被移除了
```

---

## 组合使用示例

```
# 同时设置多个权限
chmod u=rwx,g=rx,o=r file   # u:rwx, g:rx, o:r

# 使用逗号分隔多个操作
chmod u+x,go-w file # 给所有者加x，移除组和其他人的w

# 混合使用
chmod a+r,u+w,g=rx file # 所有人加r，所有者加w，组设为rx
```

## 记忆技巧

### **比喻理解**：
```
+  =  添加权限（像"加菜"）
-  =  移除权限（像"减菜"）
=  =  重设权限（像"换套餐"）
```

### **权限修改三步骤**：

1. 先用 `=` 设置基本权限

2. 再用 `+` 添加必要权限

3. 最后用 `-` 移除危险权限


---

## 常用模式速查

|命令|效果|适用场景|
|---|---|---|
|`chmod a+r file`|所有人可读|共享文档|
|`chmod go-w file`|防止他人修改|配置文件|
|`chmod u=rwx,g=rx,o= file`|750权限|程序目录|
|`chmod 644 file`|数字模式等效于 `u=rw,go=r`|常用文件|
|`chmod 755 file`|数字模式等效于 `u=rwx,go=rx`|可执行文件|

## 注意事项

1. **顺序重要**：
```
# 不同的顺序可能产生不同结果
chmod u=rwx,go=rx file   # 正确
chmod go=rx,u=rwx file   # 同样正确，顺序不影响
```
1. **符号 `=` 会清除未提及权限**：
```
# 如果原来权限是 rwxr-xr-x
chmod g=rw file   # 结果：rwxrw-r-x
# 注意：组的x权限被移除了，但其他的x权限还在
```
1. **使用 `a` 表示所有用户**：
```
chmod a+x script.sh  # 所有人添加执行权限
chmod a-w secret.txt # 所有人移除写权限
```
