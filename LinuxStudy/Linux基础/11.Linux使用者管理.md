# 一.Linux账号管理与ACL权限设置
## 使用者识别码：UID 与 GID

- Linux 系统不直接识别帐号名称，而是通过 **UID（User ID）** 和 **GID（Group ID）** 来识别使用者。
- 帐号与 UID/GID 的对应关系存储在 `/etc/passwd`（使用者）和 `/etc/group`（群组）中。
- 文件属性中的“拥有者”和“拥有群组”实际上记录的是 UID 和 GID，系统再根据 `/etc/passwd` 和 `/etc/group` 解析为名称。

## 使用者帐号相关文件

### `/etc/passwd` 结构

每行代表一个帐号，以冒号分隔为七个字段：

| 字段 | 含义 |
|------|------|
| 帐号名称 | 用户登录名 |
| 密码 | 早期存放加密密码，现在用 `x` 表示密码移至 `/etc/shadow` |
| UID | 用户识别码（0 为 root，1-999 为系统帐号，1000+ 为一般用户） |
| GID | 初始群组 ID |
| 使用者信息说明 | 全名或其他注释 |
| 主文件夹 | 用户家目录路径 |
| Shell | 登录后使用的 shell（如 `/bin/bash`）；若为 `/sbin/nologin` 则无法登录 |

### `/etc/shadow` 结构

用于存放加密密码及密码策略，只有 root 可读写。共九个字段：

| 字段 | 含义 |
|------|------|
| 帐号名称 | 与 `/etc/passwd` 对应 |
| 加密密码 | 经过加密的密码（若为 `*` 或 `!` 表示帐号被锁定） |
| 最近更动密码日期 | 1970/1/1 起累计天数 |
| 密码不可变更天数 | 上次修改后至少需等待几天才能再次修改（0 表示无限制） |
| 密码需要变更天数 | 密码有效期限，超过必须修改 |
| 变更前警告天数 | 密码过期前提前警告的天数 |
| 密码过期后宽限天数 | 密码过期后仍可登录的天数，超出则帐号失效 |
| 帐号失效日期 | 帐号在此日期后失效（格式同日期字段） |
| 保留字段 | 未使用 |

### `/etc/group` 结构

记录群组信息，冒号分隔为四个字段：

| 字段 | 含义 |
|------|------|
| 群组名称 | 群组名 |
| 群组密码 | 通常为 `x`，密码移至 `/etc/gshadow` |
| GID | 群组识别码 |
| 支持的帐号列表 | 将该群组作为**次要群组**的用户名（逗号分隔） |

### `/etc/gshadow` 结构

用于群组密码和群组管理员设置，字段：

| 字段 | 含义 |
|------|------|
| 群组名称 |  |
| 密码栏 | 若为 `!` 表示无群组管理员 |
| 群组管理员帐号 | 可管理群组成员的用户 |
| 支持的帐号列表 | 同 `/etc/group` |

## 有效群组与初始群组

- **初始群组**：用户在 `/etc/passwd` 中 GID 对应的群组，用户登录即自动拥有。
- **次要群组**：用户在 `/etc/group` 其他行中列出的群组，需通过 `newgrp` 切换有效群组后才能影响新建文件的群组属性。
- `groups` 命令可查看当前用户支持的所有群组，第一个为**有效群组**。
- `newgrp` 命令可切换有效群组（需用户已支持该群组），会启动新的子 shell，用 `exit` 返回。

## 帐号管理命令

### 新增/修改/删除用户

| 命令 | 作用 | 常用选项 |
|------|------|----------|
| `useradd` | 创建新用户 | `-u UID` `-g 初始群组` `-G 次要群组` `-mM` `-c 说明` `-d 家目录` `-s shell` `-r`（系统帐号） |
| `usermod` | 修改用户属性 | 选项同 `useradd`，另有 `-L`（锁定）、`-U`（解锁）、`-e`（失效日期）等 |
| `userdel` | 删除用户 | `-r` 同时删除家目录及邮件池 |

**默认值参考文件**：`/etc/default/useradd`、`/etc/login.defs`、`/etc/skel/`（家目录模板）

### 密码管理

| 命令 | 作用 | 常用选项 |
|------|------|----------|
| `passwd` | 设置或修改密码 | `-l` 锁定、`-u` 解锁、`-S` 显示状态、`-n` 最短天数、`-x` 最长天数、`-w` 警告天数、`-i` 失效天数、`--stdin`（从标准输入读密码） |
| `chage` | 修改密码期限 | `-l` 列出详细信息、`-d` 设置最近更改日期、`-E` 帐号失效日、`-m` 最小天数、`-M` 最大天数、`-W` 警告天数、`-I` 失效天数 |

### 用户信息查询与修改

| 命令 | 作用 | 示例 |
|------|------|------|
| `id` | 显示用户 UID/GID 及所属群组 | `id username` |
| `finger` | 显示用户详细信息（需安装） | `finger username` |
| `chfn` | 修改 `/etc/passwd` 中的用户信息（全名、办公室等） | `chfn` 交互式修改 |
| `chsh` | 修改登录 shell | `chsh -s /bin/csh` |

## 群组管理命令

| 命令 | 作用 | 常用选项 |
|------|------|----------|
| `groupadd` | 新增群组 | `-g GID` `-r`（系统群组） |
| `groupmod` | 修改群组 | `-g GID` `-n 新群组名` |
| `groupdel` | 删除群组 | 需确保无用户以该群组为初始群组 |
| `gpasswd` | 设置群组密码或管理员 | `-A user` 设置群组管理员、`-M user` 添加成员、`-a user` 添加、`-d user` 删除 |
| `groups` | 查看用户所属群组 | |
| `newgrp` | 切换有效群组 | |

## ACL（Access Control List）权限设置

ACL 可针对单一用户、群组设置更细粒度的权限，需文件系统支持（XFS 默认支持）。

### 命令

| 命令 | 作用 | 常用选项 |
|------|------|----------|
| `setfacl` | 设置 ACL | `-m u:用户名:权限` 或 `-m g:群组名:权限`、`-x` 删除、`-b` 移除所有、`-R` 递归、`-d` 设置默认 ACL（目录继承） |
| `getfacl` | 查看 ACL | `getfacl 文件` |

- 设置后文件权限列会显示 `+` 号。
- **mask** 定义有效权限的最大范围，通过 `setfacl -m m:权限` 设置。

## 身份切换

### `su`

- `su - username`：以 login shell 方式切换用户，完整加载环境变量。
- `su -c "命令"`：仅以目标用户执行一次命令。
- 切换到 root 需要输入 root 密码，切换到其他用户需输入该用户密码。

### `sudo`

- 允许授权用户以其他身份（通常是 root）执行命令，只需输入自己的密码。
- 配置文件 `/etc/sudoers`，必须用 `visudo` 编辑。

**`/etc/sudoers` 语法**：
```
使用者  来源主机名=(可切换身份)  可执行命令
```
示例：
- `root ALL=(ALL) ALL`：root 可在任何主机以任何身份执行任何命令。
- `%wheel ALL=(ALL) ALL`：wheel 群组所有成员拥有 sudo 权限。
- `myuser ALL=(root) /usr/bin/passwd`：myuser 仅能以 root 执行 passwd。
- 可使用 `NOPASSWD` 免密，如 `%wheel ALL=(ALL) NOPASSWD: ALL`。
- 可通过别名简化配置：`User_Alias`、`Cmnd_Alias`、`Host_Alias`。

## PAM（Pluggable Authentication Modules）简介

PAM 是一套验证模块，程序通过调用 PAM 进行身份认证，配置文件位于 `/etc/pam.d/` 下，与程序同名。

**PAM 配置文件格式**：
```
type control module-path module-arguments
```
- **type**：auth（认证）、account（授权）、session（会话）、password（密码修改）
- **control**：required、requisite、sufficient、optional（控制验证成功/失败流程）
- 常用模块：
  - `pam_unix.so`：传统 Unix 认证
  - `pam_cracklib.so` / `pam_pwquality.so`：密码强度检验
  - `pam_limits.so`：资源限制（`/etc/security/limits.conf`）
  - `pam_securetty.so`：限制 root 从安全终端登录（`/etc/securetty`）
  - `pam_nologin.so`：若 `/etc/nologin` 存在则禁止一般用户登录
  - `pam_env.so`：设置环境变量

## 批量创建账号脚本示例

利用 `passwd --stdin` 和 `chage -d 0` 可批量创建账号并强制首次登录修改密码。

脚本思路：
1. 准备账号列表文件（每行一个用户名）
2. 循环读取，用 `useradd` 创建用户
3. 生成随机密码（如 `openssl rand -base64 6`）并用 `passwd --stdin` 设置
4. 执行 `chage -d 0` 强制改密
5. 将用户名和密码保存到文件，分发给用户

详细脚本见文档中的 `accountadd.sh`。

## 重点

- UID/GID 是 Linux 识别用户的核心，通过 `/etc/passwd`、`/etc/shadow`、`/etc/group` 管理。
- 用户密码策略通过 `/etc/shadow` 的多个字段控制。
- 用户可属于多个群组，有效群组影响新建文件的群组属性。
- ACL 提供更精细的权限控制，需文件系统支持，用 `setfacl`/`getfacl` 管理。
- 身份切换用 `su` 或 `sudo`，后者需配置 `/etc/sudoers`，用 `visudo` 编辑。
- PAM 是现代 Linux 认证的基础，掌握常用模块和配置文件有助于排错。
- 管理员可通过 `w`、`last` 等命令监控用户活动，用 `write`、`mail` 与用户通信。
- 批量创建账号可借助脚本实现，注意密码安全和首次登录强制改密。
