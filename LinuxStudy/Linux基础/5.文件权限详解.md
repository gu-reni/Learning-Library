[[附件：权限与命令间的关系]]
# 基本权限类型
- **拥有者**（owner）
- **所属群组**（group） 
- **其他人**（other）

# 权限表示：
## 字符含义
### **第一个字符（文件类型）：**
- **`-`**：普通文件（文本、二进制等）
- **`d`**：目录
- **`l`**：符号链接（快捷方式）
- **`b`**：块设备文件（如硬盘）
- **`c`**：字符设备文件（如键盘）
- **`p`**：命名管道（FIFO），数据输送文件
- **`s`**：套接字文件（sockets），数据接口文件

### 符号表示法：
```
r = 读权限 (4) #对文件来说：可读取文件的实际内容，#对目录来说：可以读取目录结构列表，克寻味目录下的文件名数据，可用ls命令
w = 写权限 (2) #对文件来说：可编辑文件内容但是不可以删除文件，#对目录来说：可以建立新的文件与目录，删除已经存在的文件与目录（无论文件的权限是什么），将已经存在的文件或目录进行更名，移动该目录内的文件，目录位置
x = 执行权限 (1)#对文件来说：使文件具有可以被系统执行的权限，#对目录来说：能否进入该目录，用cd切换到改目录
- = 无权限 (0)
```
### 数字表示法：
```
755 = rwxr-xr-x
644 = rw-r--r--
777 = rwxrwxrwx
```

### 权限示例：
```
-rwxr-xr-x   # 普通文件，所有者：读写执行，组：读执行，其他：读执行
drwxr-xr-x   # 目录，所有者：读写执行，组：读执行，其他：读执行
lrwxrwxrwx   # 符号链接，所有权限都是rwx（但实际权限由目标文件决定）
```
### 特殊权限位：
```
setuid (s) - 执行时以文件所有者身份运行
setgid (s) - 执行时以文件所属组身份运行
sticky bit (t) - 目录中只有文件所有者才能删除自己的文件
```
除了基本的读(r)、写(w)、执行(x)权限，Linux还有三个特殊的权限位，用于解决特定场景下的权限管理问题：

|特殊权限|符号表示|数字表示|主要作用|
|---|---|---|---|
|**SUID**|`s`或`S`|4|用户执行时获得文件**所有者**权限|
|**SGID**|`s`或`S`|2|用户执行时获得文件**所属组**权限，或目录中新建文件继承目录组|
|**SBIT**|`t`或`T`|1|目录中用户只能删除自己的文件|
#### SUID（Set User ID）

##### 1. 基本概念

- **作用对象**：**二进制可执行文件**（对脚本无效）
- **作用原理**：当普通用户执行设置了SUID的程序时，该程序在运行期间会**临时获得文件所有者的权限**（通常是root）
- **权限显示**：在所有者执行位(x)显示为`s`（有执行权限）或`S`（无执行权限）
##### 2. 典型示例：`/usr/bin/passwd`
```
# 查看passwd命令的权限
$ ls -l /usr/bin/passwd
-rwsr-xr-x. 1 root root 32656 Apr  6  2020 /usr/bin/passwd
# ↑ 这里的's'表示设置了SUID

# 对比普通文件
$ ls -l /bin/cat
-rwxr-xr-x. 1 root root 38560 Aug 20  2019 /bin/cat
```
**为什么passwd需要SUID？**
- `/etc/shadow`文件存储密码，权限为`---------`（仅root可读写）
- 普通用户执行`passwd`时，临时获得root权限，从而能修改自己的密码
- 执行结束后，权限恢复为普通用户
##### 3. 设置与取消SUID
```
# 方法1：符号法
$ chmod u+s filename    # 设置SUID
$ chmod u-s filename    # 取消SUID

# 方法2：数字法（SUID=4）
$ chmod 4755 filename   # rwsr-xr-x
$ chmod 0755 filename   # rwxr-xr-x（取消SUID）

# 查看效果
$ touch testfile
$ chmod 4755 testfile
$ ls -l testfile
-rwsr-xr-x 1 user group 0 Jan 1 12:00 testfile
```
##### 4. 安全注意事项
- **最小化原则**：只在必要时设置SUID
- **定期审计**：检查系统中不必要的SUID程序
```
# 查找所有SUID程序
$ find / -type f -perm /4000 2>/dev/null

# 查找root所有的SUID程序
$ find / -type f -user root -perm /4000 2>/dev/null
```

#### SGID（Set Group ID）

##### 1. 对文件的SGID
- **作用对象**：**二进制可执行文件**
- **作用原理**：用户执行时，进程获得文件**所属组的权限**
- **权限显示**：在所属组执行位显示为`s`或`S`
**示例**：`/usr/bin/locate`
```
$ ls -l /usr/bin/locate
-rwx--s--x. 1 root slocate 40520 Apr 11  2018 /usr/bin/locate
# 用户执行locate时，获得slocate组权限，可读取/var/lib/mlocate/mlocate.db
```

##### 2. 对目录的SGID（更常用）
- **作用对象**：**目录**
- **作用原理**：在该目录下**新建的文件或子目录**，自动继承目录的所属组
- **典型场景**：团队协作目录
##### 3. 设置与取消SGID
```
# 对文件设置SGID
$ chmod g+s filename    # 符号法
$ chmod 2755 filename   # 数字法（SGID=2）

# 对目录设置SGID
$ mkdir /shared
$ chmod 2775 /shared
$ ls -ld /shared
drwxrwsr-x 2 root developers 4096 Jan 1 12:00 /shared

# 验证效果
$ cd /shared
$ touch file1
$ ls -l file1
-rw-r--r-- 1 user developers 0 Jan 1 12:00 file1
# 注意：所属组是developers，而不是user的默认组
```

#### SBIT（Sticky Bit）
##### 1. 基本概念
- **作用对象**：**目录**（对文件无意义）
- **作用原理**：目录中的文件**只有所有者、目录所有者、root才能删除/重命名**
- **权限显示**：在其他用户执行位显示为`t`或`T`
- **典型应用**：公共临时目录（如`/tmp`）
##### 2. `/tmp`目录示例
```
$ ls -ld /tmp
drwxrwxrwt. 15 root root 4096 Jan 1 12:00 /tmp
# ↑ 这里的't'表示设置了SBIT

# 验证效果
$ cd /tmp
$ touch alice_file
$ touch bob_file

# 用户alice无法删除bob的文件
$ rm bob_file
rm: cannot remove 'bob_file': Operation not permitted

# 但可以删除自己的文件
$ rm alice_file
```

##### 3. 设置与取消SBIT
```
# 设置SBIT
$ mkdir /public
$ chmod 1777 /public     # 数字法（SBIT=1）
# 或
$ chmod o+t /public      # 符号法

$ ls -ld /public
drwxrwxrwt 2 root root 4096 Jan 1 12:00 /public

# 取消SBIT
$ chmod o-t /public
$ chmod 0777 /public
```
#### 组合使用与数字表示

##### 1. 数字表示法汇总

|权限组合|数字表示|示例|
|---|---|---|
|SUID only|4xxx|4755 → rwsr-xr-x|
|SGID only|2xxx|2755 → rwxr-sr-x|
|SBIT only|1xxx|1777 → rwxrwxrwt|
|SUID+SGID|6xxx|6755 → rwsr-sr-x|
|三者全有|7xxx|7777 → rwsrwsrwt|

##### 2. 综合示例
```
# 创建测试目录和文件
$ mkdir -p /test/special
$ cd /test/special

# 1. 创建SUID程序（模拟）
$ cp /bin/ls ./mysuids
$ chmod 4755 mysuids    # 设置SUID

# 2. 创建SGID目录
$ mkdir sgid_dir
$ chmod 2777 sgid_dir   # 设置SGID

# 3. 创建SBIT目录
$ mkdir sbit_dir
$ chmod 1777 sbit_dir   # 设置SBIT

# 查看结果
$ ls -l
-rwsr-xr-x 1 user user  ... mysuids   # SUID
drwxrwsrwx 2 user user  ... sgid_dir  # SGID
drwxrwxrwt 2 user user  ... sbit_dir  # SBIT
```

#### 权限显示规则总结

|情况|所有者位|所属组位|其他用户位|说明|
|---|---|---|---|---|
|有执行权限+SUID|`s`|-|-|小写s|
|无执行权限+SUID|`S`|-|-|大写S|
|有执行权限+SGID|-|`s`|-|小写s|
|无执行权限+SGID|-|`S`|-|大写S|
|有执行权限+SBIT|-|-|`t`|小写t|
|无执行权限+SBIT|-|-|`T`|大写T|
- **SUID**：**S**uper user ID → 获得所有者权限（常为root）
- **SGID**：**S**et **G**roup ID → 获得组权限或继承组
- **SBIT**：**S**ticky **B**IT → 粘滞位，防删除
- **数字记忆**：**4**（SUID）、**2**（SGID）、**1**（SBIT）→ 4+2+1=7，与普通权限777类似
