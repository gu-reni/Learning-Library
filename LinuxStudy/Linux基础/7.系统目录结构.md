# 一. Linux目录配置依据
## FHS标准
### 1.FHS目录分类框架

FHS根据文件使用频率和是否允许修改，将目录定义为四种交互形态：

|                   | 可分享 (shareable)      | 不可分享 (unshareable) |
| ----------------- | -------------------- | ------------------ |
| **不变（static）**    | /usr（软件存放处）          | /etc（配置文件）         |
|                   | /opt（第三方辅助软件）        | /boot（启动与内核文件）     |
| **可变动（variable）** | /var/mail（用户邮箱）      | /var/run（程序相关）     |
|                   | /var/spool/news（新闻组） | /var/lock（程序相关）    |
- **可分享**：可分享给其他系统挂载使用的目录（执行文件、用户邮件等）
- **不可分享**：仅与自身机器相关的文件（设备文件、socket文件等）
- **不变**：不经常变动的数据（函数库、说明文档、管理员工具）
- **可变**：经常修改的数据（日志文件、新闻组等）
### 2. FHS核心三层目录

FHS主要规范三层目录结构：
- **/**：根目录（系统启动与修复）
- **/usr**：UNIX Software Resource（操作系统软件资源）
- **/var**：Variable（系统运行产生的可变数据）

## 二、根目录（/）的详细配置

### 1. FHS要求必须存在的目录

|目录|说明与内容|
|---|---|
|**/bin**|单人维护模式下可用的基本命令：`cat`, `chmod`, `chown`, `date`, `mv`, `mkdir`, `cp`, `bash`等|
|**/boot**|启动相关文件：内核文件（vmlinuz）、启动引导程序（如/boot/grub2/）|
|**/dev**|设备文件：`/dev/null`, `/dev/zero`, `/dev/tty`, `/dev/loop*`, `/dev/sd*`等|
|**/etc**|系统配置文件：账号密码、服务启动文件等（一般用户可读，仅root可写）|
|**/lib**|系统函数库（包括/etc/x11/等X Window配置文件）|
|**/media**|可移动设备挂载点：`/media/floppy`, `/media/cdrom`等|
|**/mnt**|临时挂载目录|
|**/opt**|第三方辅助软件（如KDE桌面系统）|
|**/run**|系统启动后产生的信息（新版FHS规定，常驻内存提升性能）|
|**/sbin**|系统管理命令（仅root使用）：`fdisk`, `fsck`, `ifconfig`, `mkfs`等|
|**/srv**|网络服务数据：WWW服务数据可放`/srv/www/`（默认建议放`/var/lib`）|
|**/tmp**|临时文件（所有人可存取，启动时可能被清除）|
|**/usr**|第二层FHS设置（详见下文）|
|**/var**|第二层FHS设置（详见下文）|

### 2. FHS建议可存在的目录

|目录|说明|
|---|---|
|**/home**|用户家目录，`~`代表当前用户家目录，`~username`代表指定用户家目录|
|**/lib64**|64位函数库（与/lib不同格式）|
|**/root**|root用户的家目录（与根目录同分区便于单人维护）|

### 3. 其他重要目录

|目录|说明|
|---|---|
|**/lost+found**|ext2/3/4文件系统错误时存放遗失片段（xfs文件系统无此目录）|
|**/proc**|虚拟文件系统，内存中的数据：系统内核、进程信息、设备状态（如`/proc/cpuinfo`, `/proc/interrupts`）|
|**/sys**|虚拟文件系统，内核与硬件信息：已加载模块、硬件设备信息|

## 三、/usr目录结构

/usr存放可分享且不变动的数据，是UNIX Software Resource的缩写。

|目录|应放置文件内容|
|---|---|
|**/usr/bin/**|所有一般用户命令（CentOS 7中/bin链接至此）|
|**/usr/lib/**|系统函数库（/lib链接至此）|
|**/usr/local/**|本机自行安装的软件（非发行版提供），有bin、etc、include、lib等子目录|
|**/usr/sbin/**|非系统正常运行必需的系统命令（如网络服务器daemon，/sbin链接至此）|
|**/usr/share/**|只读的共享数据（文本文件）：  <br>- /usr/share/man：在线帮助文件  <br>- /usr/share/doc：软件说明文档  <br>- /usr/share/zoneinfo：时区文件|
|**/usr/games/**|游戏相关数据|
|**/usr/include/**|C/C++等程序语言的头文件（header）与包含文件|
|**/usr/lib/cuda/**|非用户常用的执行文件或脚本（如X窗口命令）|
|**/usr/src/**|源代码（内核源代码建议放/usr/src/linux/）|

## 四、/var目录结构

/var主要存放变动性数据。

|目录|应放置文件内容|
|---|---|
|**/var/cache/**|应用程序运行中产生的缓存|
|**/var/lib/**|程序运行所需数据文件：  <br>- /var/lib/mysql/：MySQL数据库  <br>- /var/lib/rpm：rpm数据库|
|**/var/lock/**|设备或文件资源锁文件（确保单一软件使用）|
|**/var/log/**|日志记录（登录信息等）|
|**/var/mail/**|个人电子邮箱（常与/var/spool/mail链接）|
|**/var/run/**|程序或服务的PID文件（链接到/run）|
|**/var/spool/**|队列数据（使用后常被删除）：  <br>- /var/spool/mail/：待收邮件  <br>- /var/spool/mqueue/：待发邮件  <br>- /var/spool/cron/：计划任务数据|

# 三.绝对路径与相对路径
## 1. 定义
- **绝对路径**：从根目录（/）开始，如 `/home/dmtsai/.bashrc`
- **相对路径**：从当前目录开始（不以/开头），如 `../home/dmtsai/`

## 2. 特殊目录符号
- **`.`**：当前目录（也可用`./`表示）
- **`..`**：上一层目录（也可用`../`表示）

## 3. 示例
```
# 进入/var/log目录的两种方式
cd /var/log           # 绝对路径
cd ../var/log         # 相对路径（假设当前在/home）

# 在/var/spool下切换子目录
cd /var/spool/mail    # 先进入mail
cd ../cron            # 再进入cron（使用相对路径）
```
