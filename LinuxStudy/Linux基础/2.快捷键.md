## 终端/Shell快捷键：
- **Ctrl + C**：强制终止当前正在运行的前台程序
- **Ctrl + Z**：暂停当前程序并放到后台（可用fg恢复）
- **Ctrl + D**：退出当前Shell或结束输入（发送EOF信号）
- **Ctrl + L**：清屏（等效于clear命令）
- **Ctrl + A**：移动光标到行首
- **Ctrl + E**：移动光标到行尾
- **Ctrl + U**：剪切光标前到行首的所有内容
- **Ctrl + K**：剪切光标后到行尾的所有内容
- **Ctrl + W**：剪切光标前的一个单词
- **Ctrl + Y**：粘贴最近剪切的内容
- **Ctrl + R**：在历史命令中反向搜索
- **Tab**：命令或文件名自动补全（按两次显示所有可能选项）
- **Alt + .**：插入上一个命令的最后一个参数
- **!!**：重新执行上一条命令（不是快捷键，是命令历史特性）
- **↑/↓**：在命令历史中上下导航
```
Ctrl + C          # 终止一个正在运行的ping命令
Ctrl + Z          # 暂停vim编辑器，然后用fg命令恢复前台运行
Ctrl + D          # 退出当前Shell或结束cat命令的输入
Ctrl + L          # 清除屏幕，保持当前输入行不变
Ctrl + A → 输入sudo → Ctrl + E → 输入完整命令：sudo apt update
Ctrl + R → 输入git → 搜索历史中的git相关命令
Tab → 输入ls /u → 按Tab自动补全为ls /usr/
Alt + .           # 输入cat → 按Alt+. → 自动插入上一个命令的最后一个参数
```
