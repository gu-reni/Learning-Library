# X Window System 设置

## 1. X Window System 概述

### 1.1 什么是 X Window System
- **X Window System**（简称 X 或 X11）是 Unix/Linux 系统中的图形用户接口（GUI）标准，采用**网络主从式架构**。
- 1984 年由 MIT 开发，1987 年发布 X11 版本，1994 年推出 X11R6，后续版本沿用此基础（如 X11R7）。
- 目前主流实现由 **Xorg 基金会**维护，CentOS 7 使用的 X Server 为 Xorg。

### 1.2 核心组件
| 组件 | 作用 |
|------|------|
| **X Server** | 管理本地硬件（显卡、显示器、键盘、鼠标），负责屏幕绘制和输入设备事件接收，并将事件传递给 X Client。 |
| **X Client** | 应用程序（如终端、浏览器），接收 X Server 传来的事件，处理后返回绘图数据给 X Server。每个 X Client 独立存在，互不知晓。 |
| **Window Manager （WM）** | 特殊的 X Client，管理窗口的移动、缩放、重叠、最小化等，并提供工作列、虚拟桌面等功能。常见的有 GNOME、KDE、XFCE、twm。 |
| **Display Manager （DM）** | 提供图形化登录界面，如 GDM（GNOME Display Manager），负责用户认证并启动选定的 Window Manager。 |

### 1.3 X Window 的运作流程
1. X Server 启动，管理硬件并监听输入事件。
2. X Client 连接到 X Server（通过 `-display` 指定显示编号，如 `:0`）。
3. X Server 将输入事件（鼠标移动、按键）传给当前活动的 X Client。
4. X Client 处理后返回绘图指令给 X Server。
5. X Server 根据指令在屏幕上绘制图形。
6. Window Manager 作为特殊的 X Client，协调各窗口的布局和行为。

## 2. X Window 的启动流程

### 2.1 启动方式
- **命令行启动**：在文本界面执行 `startx`。
- **图形界面启动**：系统默认进入 `graphical.target`，由 Display Manager 提供登录界面。

### 2.2 startx 与 xinit
- `startx` 是一个 shell 脚本，用于查找 X Server 和 X Client 的启动参数，然后调用 `xinit` 实际启动 X。
- **参数查找顺序**：
  - **X Server**：`startx` 后的参数 → `~/.xserverrc` → `/etc/X11/xinit/xserverrc`（通常不存在） → 默认执行 `/usr/bin/X`。
  - **X Client**：`startx` 后的参数 → `~/.xinitrc` → `/etc/X11/xinit/xinitrc` → 默认执行 `xterm`。
- 最终执行的命令示例：`xinit /etc/X11/xinit/xinitrc -- /usr/bin/X :0`

### 2.3 显示编号与终端对应
- X 支持同时启动多个实例，通过 `:0`、`:1` 等标识。
- 默认第一个 X（:0）运行在 tty2，第二个（:1）在 tty3，以此类推。
- 网络监听端口：6000 对应 `:0`，6001 对应 `:1`（但 CentOS 7 默认使用 socket 文件，不开放网络端口）。

### 2.4 用户自定义启动（`~/.xinitrc`）
可在主目录创建 `.xinitrc` 文件，自定义启动的 X Client。示例：
```bash
xclock -geometry 100x100-5+5 &
xterm -geometry 80x50-50+150 &
exec /usr/bin/twm   # 最后一个必须用 exec 且不加 &，确保它成为主进程
```

## 3. X Server 配置文件

### 3.1 配置文件位置
- 主配置文件：`/etc/X11/xorg.conf`（CentOS 7 默认不存在，由系统自动侦测）
- 额外配置目录：`/etc/X11/xorg.conf.d/*.conf`（推荐使用，可覆盖或补充自动侦测设置）

### 3.2 生成配置文件模板
```bash
Xorg -configure   # 生成 /root/xorg.conf.new
```
测试生成的配置文件：`X -config /root/xorg.conf.new`

### 3.3 配置文件结构（section）
| Section | 作用 |
|---------|------|
| `ServerLayout` | 整合各组件，指定使用的 InputDevice、Screen 等 |
| `Files` | 设置字体路径 |
| `Module` | 载入扩展模块（如 `glx`） |
| `InputDevice` | 配置输入设备（键盘、鼠标） |
| `Monitor` | 配置显示器参数（水平/垂直刷新率） |
| `Device` | 配置显卡（驱动程序、BusID） |
| `Screen` | 配置显示分辨率和色彩深度，关联 Device 和 Monitor |
| `DRI` | 直接渲染基础架构权限设置 |

示例（关键部分）：
```conf
Section "Monitor"
    Identifier   "Monitor0"
    HorizSync    30.0 - 80.0
    VertRefresh  50.0 - 100.0
    Modeline     "1024x768_75.00"  81.80 1024 1080 1192 1360 768 769 772 802 -HSync +Vsync
EndSection

Section "Device"
    Identifier  "Card0"
    Driver      "nvidia"   # 或 intel, radeon, modesetting 等
    BusID       "PCI:1:0:0"
EndSection

Section "Screen"
    Identifier "Screen0"
    Device     "Card0"
    Monitor    "Monitor0"
    SubSection "Display"
        Depth    24
        Modes    "1920x1080" "1280x720"
    EndSubSection
EndSection
```

### 3.4 字体管理
- 字体目录：`/usr/share/X11/fonts/`、`/usr/share/fonts/`
- X Server 通过 `/etc/X11/fontpath.d/` 下的链接文件找到字体。
- **字体缓存管理**：
  - `fc-cache [-fv]`：重建字体缓存。
  - `fc-list`：列出系统已缓存的字体。
- **安装新字体**：
  1. 将字体文件（如 `.ttf`）复制到 `/usr/share/fonts/` 下新建的目录。
  2. 执行 `fc-cache -f -v` 更新缓存。
  3. 重启 X 或重新登录即可使用。

### 3.5 显示器分辨率调整
- **临时调整**（X 运行中）：`xrandr -s 1280x800`
- **永久调整**（通过配置文件）：
  1. 使用 `gtf` 生成 Modeline：
     ```bash
     gtf 1024 768 75 -x   # 输出 Modeline 行
     ```
  2. 将 Modeline 添加到 `Monitor` 段落。
  3. 在 `Screen` 的 `Display` 子段中添加该分辨率到 `Modes` 列表。
  4. 重启 X。

## 4. 显卡驱动程序安装示例

### 4.1 通用准备
- 安装开发工具和内核头文件：
  ```bash
  yum groupinstall "Development Tools"
  yum install kernel-devel kernel-headers
  ```

### 4.2 NVIDIA 显卡（官方驱动）
1. **禁用开源驱动 nouveau**：
   - 创建 `/etc/modprobe.d/blacklist.conf`，添加：
     ```
     blacklist nouveau
     options nouveau modeset=0
     ```
   - 修改 `/etc/default/grub`，在 `GRUB_CMDLINE_LINUX` 中添加 `rd.driver.blacklist=nouveau nouveau.modeset=0`。
   - 重新生成 grub 配置：`grub2-mkconfig -o /boot/grub2/grub.cfg`。
   - 重启并确认 `lsmod | grep nouveau` 无输出。
2. **切换到文本模式**：`systemctl isolate multi-user.target`
3. **运行安装程序**：
   ```bash
   sh NVIDIA-Linux-x86_64-*.run
   ```
   根据提示接受许可、选择安装 32 位兼容库，并允许自动更新 xorg.conf。
4. **验证**：安装后 `Device` 段的 `Driver` 变为 `nvidia`，且有 `nvidia-installer` 工具。

### 4.3 AMD/ATI 显卡（通过 ELRepo 仓库）
1. **导入 ELRepo 密钥并安装仓库**：
   ```bash
   rpm --import https://www.elrepo.org/RPM-GPG-KEY-elrepo.org
   rpm -Uvh http://www.elrepo.org/elrepo-release-7.0-2.el7.elrepo.noarch.rpm
   ```
2. **安装驱动**：
   ```bash
   yum --enablerepo elrepo-testing install fglrx-x11-drv
   ```
3. **配置**：使用 `aticonfig` 工具生成或修改 xorg.conf。

### 4.4 Intel 显卡
- Intel 驱动已开源，通常系统已包含（`/usr/lib64/xorg/modules/drivers/intel_drv.so`）。
- 若需手动指定，在 `Device` 段设置 `Driver "intel"`，并确保载入 `glx` 和 `dri` 模块，添加 `DRI` 权限段：
  ```conf
  Section "DRI"
      Mode 0666
  EndSection
  ```

## 5. 重点

- X Window System 是 Unix/Linux 的图形接口标准，采用 X Server / X Client 架构，通过网络主从式设计实现硬件与应用的分离。
- X Server 管理硬件和绘制，X Client 处理应用逻辑，Window Manager 负责窗口管理，Display Manager 提供登录界面。
- `startx` 命令通过查找 `~/.xinitrc` 和 `/etc/X11/xinit/xinitrc` 等配置，调用 `xinit` 启动 X。
- 多个 X 实例可通过 `:0`、`:1` 等显示编号区分，对应不同的终端和端口。
- X Server 配置文件 `/etc/X11/xorg.conf` 已非必需，推荐在 `/etc/X11/xorg.conf.d/` 下添加 `.conf` 文件进行自定义设置。
- 配置文件包含 `ServerLayout`、`Files`、`Module`、`InputDevice`、`Monitor`、`Device`、`Screen` 等关键段落。
- 字体管理通过 `fc-cache` 和 `fc-list` 操作，新增字体需放入 `/usr/share/fonts/` 并更新缓存。
- 分辨率调整可使用 `gtf` 生成 Modeline 并写入配置文件。
- 显卡驱动安装：NVIDIA 推荐官方驱动（需禁用 nouveau），AMD 可通过 ELRepo 仓库安装 fglrx，Intel 驱动通常已内置。
