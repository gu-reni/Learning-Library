# 登录文件（Log）

## 1. 什么是登录文件

- **定义**：记录系统活动信息的文件，包括事件发生的时间、主机、服务、实际内容等。
- **重要性**：
  - 解决系统错误（硬件、服务无法启动）。
  - 解决网络服务问题（如邮件、FTP）。
  - 记录过往事件（入侵追查、流量分析）。
- **常见登录文件**（位于 `/var/log/`）：
  - `boot.log`：开机启动信息。
  - `cron`：例行性工作调度日志。
  - `dmesg`：核心侦测过程信息。
  - `lastlog`：最近一次登录记录。
  - `maillog` 或 `mail/*`：邮件服务日志。
  - `messages`：系统主要错误/信息记录。
  - `secure`：涉及帐号密码的登录/授权记录（如 ssh、su、sudo）。
  - `wtmp`、`faillog`：正确/错误登录记录。
  - 各服务自己的日志（如 `httpd/*`、`samba/*`）。

## 2. 登录文件相关服务与程序

- **systemd-journald.service**：由 systemd 提供，将日志以二进制形式记录于内存（`/run/log`），可通过 `journalctl` 查询。
- **rsyslog.service**：主要的日志记录服务，将各类消息分类写入对应文件。
- **logrotate**：日志轮替工具，定期分割、压缩、删除旧日志，防止日志无限增长。

## 3. rsyslog.service 配置与管理

### 3.1 配置文件 `/etc/rsyslog.conf`

语法：
```
服务名称.等级    日志文件/设备
```
- **服务名称**（通过 `man 3 syslog` 或 `syslog.h` 定义）：
  - `kern`（内核）、`user`（用户）、`mail`（邮件）、`daemon`（系统服务）、
    `auth`（认证）、`syslog`（syslog自身）、`lpr`（打印）、`news`（新闻组）、
    `uucp`、`cron`、`authpriv`（私有认证）、`ftp`、`local0~7`（本地使用）。
- **等级**（从低到高）：
  - `debug`（调试）、`info`（信息）、`notice`（注意）、`warning`（警告）、
    `err`（错误）、`crit`（临界）、`alert`（警报）、`emerg`（紧急）。
  - 可用 `.`（含该级及以上）、`.=`（仅该级）、`.!`（除该级外）连接。
- **日志文件/设备**：绝对路径、打印机、用户、远程主机（`@host`）、`*`（所有在线用户）。

### 3.2 CentOS 7 默认配置
```
*.info;mail.none;authpriv.none;cron.none    /var/log/messages
authpriv.*                                  /var/log/secure
mail.*                                      -/var/log/maillog   # - 表示先写入内存缓冲区
cron.*                                      /var/log/cron
*.emerg                                     :omusrmsg:*
uucp,news.crit                              /var/log/spooler
local7.*                                    /var/log/boot.log
```

### 3.3 自定义日志文件
在 `/etc/rsyslog.conf` 中添加规则，例如：
```
*.info    /var/log/admin.log
```
修改后需重启 rsyslog：`systemctl restart rsyslog`

### 3.4 日志安全
- 可对日志文件设置 `chattr +a` 属性，使其只能追加不能删除/修改（避免被篡改）。
- 但 `+a` 会影响 logrotate，需在轮替前后临时取消/恢复属性（通过 prerotate/postrotate）。

### 3.5 日志服务器设置
- **服务器端**：在 `/etc/rsyslog.conf` 中启用 TCP/UDP 监听（默认 port 514）。
  ```
  $ModLoad imtcp
  $InputTCPServerRun 514
  ```
  重启服务后监听端口。
- **客户端**：在 `/etc/rsyslog.conf` 中添加：
  ```
  *.* @@192.168.1.100   # TCP 传输；若用 UDP 则为 @
  ```

## 4. logrotate（日志轮替）

- **作用**：定期将当前日志文件改名（如 `messages` → `messages.1`），创建新空文件，并可选压缩旧文件，保留指定份数。
- **主配置文件**：`/etc/logrotate.conf`
- **额外配置目录**：`/etc/logrotate.d/`（每个服务可独立配置）
- **默认配置项**：
  ```
  weekly          # 每周轮替
  rotate 4        # 保留 4 个旧文件
  create          # 轮替后创建新文件
  dateext         # 轮替文件加日期后缀
  #compress       # 是否压缩（默认不压缩）
  include /etc/logrotate.d   # 包含目录下所有配置
  ```
- **自定义配置示例**（`/etc/logrotate.d/admin`）：
  ```
  /var/log/admin.log {
      monthly
      size=10M
      rotate 5
      compress
      sharedscripts
      prerotate
          /usr/bin/chattr -a /var/log/admin.log
      endscript
      sharedscripts
      postrotate
          /bin/kill -HUP `cat /var/run/syslogd.pid`
          /usr/bin/chattr +a /var/log/admin.log
      endscript
  }
  ```
- **手动执行**：`logrotate [-vf] /etc/logrotate.conf`（-v 显示过程，-f 强制轮替）

## 5. systemd-journald.service 与 journalctl

- **特点**：由 systemd 管理，日志存于内存（`/run/log`），重启后丢失。若需持久化，可创建 `/var/log/journal` 并设置权限。
- **查询命令 `journalctl`**：
  - `journalctl`：显示所有日志（从旧到新）。
  - `journalctl -n 20`：显示最近 20 行。
  - `journalctl -r`：反向输出（新到旧）。
  - `journalctl -f`：实时跟踪（类似 `tail -f`）。
  - `journalctl -p err`：只显示错误及以上等级。
  - `journalctl --since today` / `--since "2025-01-01"`：按时间过滤。
  - `journalctl _SYSTEMD_UNIT=sshd.service`：指定 unit 的日志。
  - `journalctl _COMM=su`：按命令名过滤。
  - `journalctl SYSLOG_FACILITY=4`：按 syslog 设施序号过滤（4 为 auth）。
- **持久化 journal**：
  ```bash
  mkdir /var/log/journal
  chown root:systemd-journal /var/log/journal
  chmod 2775 /var/log/journal
  systemctl restart systemd-journald
  ```

## 6. logger 命令：向日志写入自定义消息

- **语法**：`logger [-p 设施.等级] "消息"`
- **示例**：`logger -p user.info "Backup started"`
- 常与脚本结合，记录关键操作的时间戳。

## 7. 日志分析工具

### 7.1 logwatch
- CentOS 默认未安装，需通过 yum 安装（依赖 perl 等）。
- 安装后由 cron 每日执行（`/etc/cron.daily/0logwatch`），分析结果通过邮件发送给 root。
- 可手动执行：`/etc/cron.daily/0logwatch` 并查看 mail。

### 7.2 鸟哥自写日志分析脚本
- 可从 [http://linux.vbird.org/linux_basic/0570syslog/logfile_centos7.tar.gz](http://linux.vbird.org/linux_basic/0570syslog/logfile_centos7.tar.gz) 下载。
- 解压至根目录，会在 `/etc/cron.d/` 添加每日任务（每天 00:10 执行），分析结果同样发邮件给 root。
- 分析内容包括系统概况、开放端口、各服务（SSH、postfix 等）日志统计。

## 8. 重点

- 登录文件记录事件的时间、主机、服务、描述，是系统排错、安全审计的关键。
- 主要日志文件位于 `/var/log/`，如 `messages`、`secure`、`maillog`、`cron` 等。
- rsyslog 是传统日志服务，通过 `/etc/rsyslog.conf` 控制分类与存储。
- logrotate 负责日志轮替，配置位于 `/etc/logrotate.conf` 和 `/etc/logrotate.d/`。
- systemd-journald 提供高性能内存日志，用 `journalctl` 查询；可持久化到磁盘。
- 使用 `logger` 可手动写入自定义日志。
- 日志分析工具如 logwatch、鸟哥脚本可自动化分析并邮件提醒。
