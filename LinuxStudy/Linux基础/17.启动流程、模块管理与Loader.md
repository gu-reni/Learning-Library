# 开机流程、模块管理与 Loader 重要内容整理

## 1. 开机流程一览

- **步骤概述**：
  1. BIOS/UEFI 加载硬件信息，进行开机自检（POST），并获取第一个可开机设备。
  2. 读取第一个开机设备 MBR/GPT 中的 **boot loader**。
  3. Boot loader 载入 **kernel** 和 **initramfs** 到内存，并启动内核。
  4. 内核解压缩后，重新侦测硬件，加载 initramfs 中的必要驱动（如磁盘、文件系统模块）。
  5. 内核挂载实际根目录，调用第一个程序 **systemd**（PID 1）。
  6. systemd 根据 **default.target** 启动系统服务，最终进入用户操作界面。

## 2. BIOS、boot loader 与 kernel 载入

- **BIOS 功能**：读取 CMOS 设置，决定开机设备顺序，通过 INT 13 中断读取 MBR。
- **MBR/GPT**：存放 boot loader 主程序（446 字节/分区表保留空间）。
- **boot loader 功能**：
  - 提供菜单（选择不同操作系统或内核）。
  - 直接载入内核文件。
  - 转交控制权给其他 boot loader（通过 chainloader）。
- **核心与 initramfs**：
  - 内核文件：`/boot/vmlinuz-版本`。
  - initramfs：`/boot/initramfs-版本.img`，包含开机必需的驱动（SATA、SCSI、LVM、RAID 等）。
  - 作用：解决“核心不认识磁盘 → 无法加载模块 → 无法挂载根目录”的矛盾。
  - 可通过 `lsinitrd` 查看内容，用 `dracut` 重建。

## 3. systemd 开机流程

- **default.target**：软链接到 `multi-user.target`（文本模式）或 `graphical.target`（图形模式）。
- **关键 target**：
  - `local-fs.target` + `swap.target`：挂载 `/etc/fstab` 中定义的文件系统和交换分区。
  - `sysinit.target`：初始化系统，加载核心模块、设置主机名、挂载特殊文件系统等。
  - `basic.target`：加载基础服务（防火墙、SELinux、音效等）。
  - `multi-user.target`：启动所有非图形服务（网络服务、本机服务）。
  - `graphical.target`：启动图形界面（如 gdm）。
- **服务启动方式**：
  - 系统服务脚本：`/usr/lib/systemd/system/`。
  - 管理员自定义：`/etc/systemd/system/` 下创建链接或配置文件。
  - 开机自启动管理：`systemctl enable/disable` 实质是在 `/etc/systemd/system/multi-user.target.wants/` 中创建/删除链接。
- **兼容 rc.local**：
  - 脚本：`/etc/rc.d/rc.local`，需赋予可执行权限（`chmod +x`），由 `rc-local.service` 在开机最后执行。

## 4. 核心模块管理

- **模块位置**：`/lib/modules/$(uname -r)/kernel/`
- **模块相依性文件**：`/lib/modules/$(uname -r)/modules.dep`（由 `depmod` 生成）。
- **常用指令**：
  - `lsmod`：列出已加载模块。
  - `modinfo 模块名`：查看模块信息。
  - `modprobe 模块名`：智能加载模块（自动处理依赖）。
  - `rmmod 模块名`：移除模块（不建议，可用 `modprobe -r`）。
  - `insmod /完整路径/模块.ko`：手动加载，不处理依赖。
- **模块参数设置**：在 `/etc/modprobe.d/*.conf` 中使用 `options 模块名 参数=值`。
- **开机自动加载模块**：在 `/etc/modules-load.d/*.conf` 中每行一个模块名。

## 5. Boot Loader: Grub2

### 5.1 Grub2 的 stage 概念
- **stage1**：放在 MBR 或 boot sector，极小主程序。
- **stage2**：配置文件与模块存放在 `/boot/grub2/`，支持多种文件系统。

### 5.2 Grub2 中的磁盘代号
- 格式：`(hdN, M)`，N 从 0 开始（硬盘顺序），M 从 1 开始（分区号）。
- 可加分区类型标识：`(hd0,msdos1)` 或 `(hd0,gpt1)`。

### 5.3 配置文件 `/boot/grub2/grub.cfg`
- 由 `/etc/default/grub` 和 `/etc/grub.d/` 下的脚本生成，**不建议手动修改**。
- 重要参数（在 `/etc/default/grub` 中设置）：
  - `GRUB_TIMEOUT`：菜单等待秒数。
  - `GRUB_DEFAULT`：默认菜单项（可用数字、title、--id）。
  - `GRUB_CMDLINE_LINUX`：传递给内核的额外参数。
  - `GRUB_TERMINAL`：终端类型（如 `gfxterm` 开启图形）。
  - `GRUB_GFXMODE`：图形分辨率（如 `1024x768x24`）。
- **生成新配置**：`grub2-mkconfig -o /boot/grub2/grub.cfg`

### 5.4 自定义开机菜单
- 编辑 `/etc/grub.d/40_custom`，添加 `menuentry` 块。
- **直接引导内核**示例：
  ```
  menuentry 'My Linux' {
      set root='(hd0,gpt2)'
      linux16 /vmlinuz-... root=/dev/mapper/centos-root ro
      initrd16 /initramfs-....img
  }
  ```
- **chainloader 移交控制权**示例（引导 Windows）：
  ```
  menuentry 'Windows' {
      insmod chain
      insmod ntfs
      set root='(hd0,1)'
      chainloader +1
  }
  ```

### 5.5 安装 Grub2
- 安装到 MBR：`grub2-install /dev/sda`
- 安装到分区（boot sector）：`grub2-install /dev/sda1`（可能需要 `--force` 等参数）。

### 5.6 开机时编辑参数
- 在 Grub2 菜单界面按 `e` 进入编辑模式。
- 修改 linux16 行，添加参数如 `systemd.unit=rescue.target` 进入救援模式。
- 修改后按 `Ctrl+x` 启动。

### 5.7 为菜单设置密码
- 生成加密密码：`grub2-mkpasswd-pbkdf2`
- 在 `/etc/grub.d/01_users` 中设置 `set superusers="用户名"` 和 `password_pbkdf2` 行。
- 在 `menuentry` 中添加 `--unrestricted`（允许所有人）或 `--users 用户名`（仅指定用户可进入）。
- 重启后受保护菜单需要输入密码才能选择或编辑。

## 6. 创建 initramfs
- **命令**：`dracut [-f] [--add-drivers "模块列表"] 文件名 内核版本`
- 示例：`dracut -f initramfs-xxx.img $(uname -r)`
- 用途：当添加新硬件或修改驱动后，需重建 initramfs。

## 7. 开机问题解决

### 7.1 忘记 root 密码
- 在 Grub2 菜单按 `e`，在 linux16 行末尾添加 `rd.break`。
- 按 `Ctrl+x` 启动，进入 emergency 模式（RAM Disk 环境）。
- 重新挂载 `/sysroot` 为可读写：`mount -o remount,rw /sysroot`
- 切换到实际系统：`chroot /sysroot`
- 修改 root 密码：`echo "新密码" | passwd --stdin root`
- 强制 SELinux 重新标记：`touch /.autorelabel`
- 退出并重启：`exit` → `reboot`
- **替代方法**：使用 `init=/bin/bash` 直接进入 bash，但需手动挂载根目录并处理 SELinux。

### 7.2 文件系统错误无法开机
- 系统会提示输入 root 密码进入维护模式。
- 输入密码后，重新挂载根目录为可读写：`mount -o remount,rw /`
- 根据错误提示，运行 `fsck`（ext 系列）或 `xfs_repair`（xfs 文件系统）修复对应分区。
- 修复后重启。

## 8. 重点
- 开机流程：BIOS → MBR → boot loader → kernel + initramfs → systemd → 目标 target。
- boot loader 三大功能：菜单、加载内核、转交控制权。
- initramfs 包含关键驱动，解决内核与根目录的矛盾。
- systemd 并行启动服务，通过 target 组织。
- 核心模块用 `modprobe` 管理，配置文件在 `/etc/modprobe.d/`。
- Grub2 配置文件由 `/etc/default/grub` 和 `/etc/grub.d/` 生成，使用 `grub2-mkconfig` 更新。
- Grub2 磁盘命名 `(hdN, M)`，与 Linux 不同。
- 忘记密码可通过 `rd.break` 进入救援修改，注意 SELinux 重标。
- 文件系统错误可进入维护模式后用 `fsck` / `xfs_repair` 修复。
