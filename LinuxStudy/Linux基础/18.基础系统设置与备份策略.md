# 系统设置与备份

## 1. 系统基本设置

### 1.1 网络设置
- **网络参数获取方式**：
  - 手动设置固定 IP（需 IP、Netmask、Gateway、DNS）
  - DHCP 自动获取
  - 拨号连接（如 ADSL，生成 ppp0 接口）
- **网卡命名规则**（CentOS 7）：
  - `eno1`：主板 BIOS 内置网卡
  - `ens1`：主板 BIOS 内置 PCI-E 网卡
  - `enp2s0`：PCI-E 独立网卡
  - `eth0`：传统命名
- **使用 `nmcli` 配置网络**：
  - 查看连接：`nmcli connection show`
  - 修改连接：`nmcli connection modify eth0 [参数] [值]`
  - 常用参数：`connection.autoconnect`, `ipv4.method`（manual/auto）, `ipv4.addresses`（IP/掩码）, `ipv4.gateway`, `ipv4.dns`
  - 激活连接：`nmcli connection up eth0`
- **主机名修改**：
  - 查看：`hostnamectl`
  - 设置：`hostnamectl set-hostname 新主机名`

### 1.2 日期与时间设置
- **`timedatectl` 命令**：
  - 查看当前时区/时间：`timedatectl`
  - 列出时区：`timedatectl list-timezones`
  - 设置时区：`timedatectl set-timezone 时区`
  - 设置时间：`timedatectl set-time "YYYY-MM-DD HH:MM"`
  - 启用 NTP 自动同步：`timedatectl set-ntp yes`
- **手动网络校时**（`ntpdate`）：
  ```bash
  ntpdate tock.stdtime.gov.tw   # 以台湾时间服务器为例
  hwclock -w                    # 写入硬件时钟
  ```

### 1.3 语系设置
- **查看系统语系**：`localectl`
- **设置系统语系**：`localectl set-locale LANG=en_US.utf8`
- **当前会话语系**：由环境变量 `LANG`, `LC_ALL` 等控制（可用 `locale` 查看）

### 1.4 防火墙简易设置（firewalld）
- **图形界面**：`firewall-config`（需安装并运行在 X 环境）
- **命令行 `firewall-cmd`**：
  - 添加永久规则：`firewall-cmd --permanent --add-rich-rule='rule family="ipv4" source address="192.168.1.0/24" accept'`
  - 重新加载配置：`firewall-cmd --reload`
- **常用区域（zone）**：默认 `public`，可通过图形界面勾选服务（如 ssh, http, ftp）或添加端口（如 222, 555）

## 2. 服务器硬件数据收集

### 2.1 `dmidecode`：读取硬件信息（主板、内存等）
- `dmidecode -t 1`：系统信息（主板型号等）
- `dmidecode -t 4`：CPU 信息
- `dmidecode -t 17`：内存插槽信息

### 2.2 硬件侦测命令
- **`lspci`**：列出 PCI 设备
  - `lspci -v`：详细信息
  - `lspci -s 00:03.0 -vv`：查看指定设备
  - 设备 ID 对应表：`/usr/share/hwdata/pci.ids`
  - 更新对应表：`update-pciids`
- **`lsusb`**：列出 USB 设备
  - `lsusb -t`：树状显示
- **`iostat`**（需安装 `sysstat`）：查看 CPU 与磁盘 I/O 统计
  - `iostat`：显示 CPU 和所有磁盘统计
  - `iostat -d 2 3 vda`：每2秒一次，共3次，仅显示 vda
- **`smartctl`**（需安装 `smartmontools`）：查看磁盘健康状态
  - `smartctl -a /dev/sda`：显示所有 SMART 信息
  - `smartctl -t short /dev/sda`：执行短自检

## 3. 备份要点

### 3.1 备份考虑因素
- **哪些文件需要备份**：
  - 系统配置文件：`/etc/`
  - 用户数据：`/home/`, `/root/`
  - 邮件：`/var/spool/mail/`
  - 计划任务：`/var/spool/{cron,at}/`
  - 系统核心：`/boot/`
  - 服务数据库：如 `/var/lib/mysql`, `/var/www` 等
- **不需要备份的目录**：`/proc`, `/sys`, `/run`, `/tmp`, `/mnt`, `/media` 等临时或虚拟文件系统
- **备份媒体选择**：外接硬盘、NAS、磁带、光盘等，考虑容量、速度、可靠性、异地备援
- **备份方式**：完整备份、累积备份、差异备份
- **备份频率**：根据数据变化量和服务重要性决定

### 3.2 备份策略类型
- **累积备份（Incremental）**：
  - 第一次完整备份，后续只备份与上次备份相比变化的数据。
  - 还原时需要完整备份 + 所有累积备份，顺序还原。
  - 工具：`xfsdump`（支持 level 0~9）、`tar`（结合 `find` 或 `-N` 选项）、`rsync`
- **差异备份（Differential）**：
  - 每次备份都与第一次完整备份比较，只备份变化的数据。
  - 还原时需要完整备份 + 最后一次差异备份。
  - 工具：`xfsdump`（固定 level 1）、`tar -N`、`rsync`
- **关键数据备份**：
  - 只备份重要配置文件和数据，不备份系统本身。
  - 还原时需重新安装系统，再恢复数据。

### 3.3 常用备份工具示例
- **`dd`**：扇区级复制（完整备份磁盘）
  ```bash
  dd if=/dev/sda of=/dev/sdb   # 磁盘对拷
  ```
- **`cpio`**：配合 `find` 备份所有文件
  ```bash
  find / -print | cpio -covB > /dev/st0   # 备份到磁带
  cpio -iduv < /dev/st0                    # 还原
  ```
- **`xfsdump`**：支持累积备份（XFS 文件系统）
  ```bash
  xfsdump -l 0 -L "full" -f /backup/home.dump /home          # 完整
  xfsdump -l 1 -L "inc1" -f /backup/home.dump1 /home         # 累积
  ```
- **`tar`**：常用打包工具，支持排除目录
  ```bash
  tar --exclude /proc --exclude /mnt -jcvp -f /backup/system.tar.bz2 /
  tar -N '2015-09-01' -jcvf /backup/home.tar.bz2 /home       # 差异（按时间）
  ```
- **`rsync`**：镜像同步，支持 ssh 加密传输
  ```bash
  rsync -av /home /backupdata/                # 本地同步
  rsync -av -e ssh /backup/weekly user@remote:/home/backup/   # 远程同步
  ```

## 4. 鸟哥的备份策略示例

### 4.1 每周备份脚本（`backupwk.sh`）
- 备份目录：`/backup/weekly/`
- 备份内容：
  - 系统服务配置（如 named, postfix, vsftpd, ssh, samba, httpd）
  - 数据库（MySQL）
  - 系统关键目录：`/etc`, `/usr/local`
  - 用户相关：`/etc/passwd`, `/etc/shadow`, `/etc/group`, `/home`, 邮件, 计划任务
- 脚本核心操作：
  - 创建子目录
  - 使用 `cp -a` 复制配置目录
  - 使用 `tar -jpc` 打包数据

### 4.2 每日备份脚本（`backupday.sh`）
- 备份目录：`/backup/daily/`
- 备份内容：
  - MySQL 数据库（`/var/lib/mysql`）
  - CGI 程序（`/var/www/cgi-bin`）
- 使用 `tar -jpc` 并生成带日期的文件名（如 `mysql.2015-09-01.tar.bz2`）

### 4.3 远程备援脚本（`rsync.sh`）
- 使用 `rsync` 通过 SSH 将本地备份同步到远程主机
- 前提：设置 SSH 免密登录
- 示例：
  ```bash
  rsync -av -e ssh /backup/weekly user@remote:/home/backup/
  ```

### 4.4 定时执行（crontab）
```cron
30 3 * * 0 root /backup/backupwk.sh   # 每周日凌晨 3:30
30 2 * * * root /backup/backupday.sh  # 每日凌晨 2:30
```

## 5. 灾难复原考虑
- **硬件损毁且有完整备份**：
  - 修复硬件后，直接恢复完整备份（如用 `dd` 或 `xfsrestore`）
- **软件问题（被攻击）**：
  1. 拔掉网络，备份现有系统以备调查。
  2. 分析日志，找出问题。
  3. 安装新系统（建议最新发行版），配置防火墙和安全措施。
  4. 从关键数据备份恢复配置和用户数据。
  5. 测试后重新上线。
- **异地备援**：将备份数据定期复制到远程位置，防止本地灾难（如火灾、盗窃）。

## 重点
- 网络设置可使用 `nmcli` 管理，主机名用 `hostnamectl`，时区时间用 `timedatectl`。
- 硬件信息收集：`dmidecode`（主板/内存）、`lspci`（PCI设备）、`lsusb`（USB设备）、`iostat`（I/O统计）、`smartctl`（磁盘健康）。
- 备份策略分完整、累积、差异三种，常用工具：`dd`（块级）、`cpio`（文件级）、`xfsdump`（XFS累积）、`tar`（打包）、`rsync`（镜像同步）。
- 关键数据应至少包括 `/etc`, `/home`, `/var/spool/mail`, 服务数据等；避免备份 `/proc` 等虚拟目录。
- 自动备份应写入 crontab，并考虑异地备援。
- 灾难恢复时根据原因选择适当步骤：硬件故障则直接恢复完整备份；软件攻击则需重装系统并恢复关键数据。
