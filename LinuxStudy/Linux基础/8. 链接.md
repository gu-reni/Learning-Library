## 硬链接：
- **本质**：在某个目录下新增一条“文件名 ↔ inode 号码”的关联记录，**多个文件名指向同一个 inode**。
- **特性**：
    - 与原始文件**完全平等**，删除任一文件名，文件数据依然存在（只要还有一个文件名指向该 inode）。
    - **不可跨文件系统**。
    - **不可链接目录**（避免造成目录树环路及维护复杂度）。
    - 不额外占用 inode 与 block（仅目录 block 可能微增）。
- **链接计数**：`ls -l` 第二字段表示“有多少个文件名链接到此 inode”。新建硬链接时该计数 +1。
- **安全价值**：重要配置文件可创建硬链接到其他目录，防止误删除导致数据丢失。
```
ln source.txt hardlink.txt  # 创建硬链接
# 特点：
# 1. 与源文件共享相同的inode和数据块
# 2. 删除源文件，硬链接仍然有效
# 3. 不能跨文件系统
# 4. 不能链接目录
```

## 软链接（符号链接）：
- **本质**：创建一个**独立的文件**（拥有自己的 inode 与 block），其内容存储的是**目标文件的路径名**。
- **特性**：
    - 相当于 Windows 的“快捷方式”。
    - 可跨文件系统，可链接目录。
    - 源文件被删除后，符号链接**无法访问**（出现“No such file or directory”）。
    - 文件大小 = 目标路径的字符数（Bytes）。
**灵活性**：广泛用于软件版本切换、快捷访问，但需注意源文件存在性。
```
ln -s source.txt symlink.txt  # 创建软链接
# 特点：
# 1. 独立的inode，包含指向源文件的路径
# 2. 源文件删除后，软链接失效
# 3. 可以跨文件系统
# 4. 可以链接目录
```

- **目录链接数意义**：
    - 空目录至少包含 `.` 与 `..`，故新目录自身链接数为 **2**；上层目录的链接数因新增 `..` 项而 **+1**。


### 查看链接：
```
ls -l                  # 查看文件类型和链接
readlink symlink.txt   # 查看软链接指向的目标
stat file.txt          # 查看文件的inode信息
```
