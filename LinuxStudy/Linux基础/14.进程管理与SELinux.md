# 一.程序与资源管理

## 1. 什么是程序（process）

- **程序（program）**：存放在存储介质中的二进制可执行文件。
- **进程（process）**：程序被触发后，载入内存并分配PID，拥有执行者的权限与属性。
- **父程序与子程序**：进程之间存在衍生关系，通过 **fork-and-exec** 机制产生子程序。每个进程有唯一的 **PID** 和 **PPID**（父进程ID）。
- **常驻程序（daemon）**：在内存中持续运行的服务程序，通常文件名以 `d` 结尾（如 `crond`、`sshd`）。
- **Linux多用户多任务**：CPU在不同进程间快速切换，实现多用户同时操作。每个登录者获得独立的shell进程（bash），拥有各自的PID。

## 2. 工作管理（job control）

### 2.1 基本概念
- **前景（foreground）**：可以接收键盘输入并直接操作的环境。
- **背景（background）**：无法接收键盘输入，可自行运行或暂停的工作。
- 工作管理的对象必须是当前shell的子进程。

### 2.2 常用命令与操作
| 命令/操作 | 作用 |
|-----------|------|
| `命令 &` | 将命令放入后台执行（输出信息仍会显示，建议重定向） |
| `Ctrl + Z` | 将当前前台工作暂停并放入后台 |
| `jobs` | 列出当前shell的所有后台工作（带 `+` 为最近放入的工作） |
| `fg %工作号` | 将指定后台工作调回前台执行 |
| `bg %工作号` | 将暂停的后台工作继续在后台运行 |
| `kill %工作号` | 终止指定的后台工作（可配合信号 `-9` 强制删除） |

### 2.3 离线管理
- 后台工作与终端绑定，注销后会被中断。若需在离线后继续执行，可使用：
  ```bash
  nohup 命令 &   # 忽略挂断信号，输出追加到 ~/nohup.out
  ```

## 3. 进程管理

### 3.1 进程观察

| 命令 | 常用选项 | 说明 |
|------|----------|------|
| `ps -l` | 仅查看自己bash相关的进程（显示F,S,UID,PID,PPID,PRI,NI等） |
| `ps aux` | 查看系统所有进程（显示USER,PID,%CPU,%MEM,VSZ,RSS,TTY,STAT,START,TIME,COMMAND） |
| `ps -lA` | 以`-l`格式显示所有进程 |
| `ps axjf` | 显示进程树关系 |
| `top` | 动态显示进程资源使用，支持交互命令（P按CPU排序，M按内存排序，k给信号，r改nice值） |
| `pstree [-Aup]` | 以树状结构显示进程及其PID和所属用户 |

**进程状态（STAT）**：R（运行）、S（睡眠）、D（不可唤醒睡眠）、T（停止）、Z（僵尸）。

### 3.2 进程控制
- **信号（signal）**：通过 `kill` 或 `killall` 给进程发送信号。常用信号：
  - `1`（SIGHUP）：重新加载配置
  - `9`（SIGKILL）：强制终止
  - `15`（SIGTERM）：正常终止（默认）
- `kill -信号 PID`：向指定PID发送信号。
- `killall -信号 程序名`：向所有以该程序名启动的进程发送信号。

### 3.3 进程执行顺序
- **PRI**：内核动态调整的优先级，数值越小越优先。
- **NI（nice值）**：用户可调整的优先级范围，范围 -20 ~ 19（root可调至负数，一般用户只能调高0~19）。
- 新进程设置nice值：`nice -n 数值 命令`
- 调整已有进程nice值：`renice 数值 PID` 或 在 `top` 中按 `r` 修改。

### 3.4 系统资源观察
| 命令 | 作用 |
|------|------|
| `free [-h]` | 显示内存和swap使用情况（total, used, free, buff/cache） |
| `uname -a` | 显示系统与内核信息 |
| `uptime` | 显示开机时间、登录用户数、1/5/15分钟平均负载 |
| `netstat [-tunlp]` | 查看网络连接和监听端口（`-t` tcp，`-u` udp，`-n` 不解析服务名，`-l` 监听，`-p` 显示PID/程序名） |
| `dmesg` | 查看内核环缓冲区信息（硬件侦测、驱动等） |
| `vmstat [延迟 [次数]]` | 动态报告系统进程、内存、swap、I/O、CPU状态 |

## 4. 特殊文件与进程

- **/proc 文件系统**：存放进程信息和系统状态。每个PID对应一个目录，如 `/proc/1/` 包含PID为1的进程信息。系统级文件如 `/proc/cpuinfo`、`/proc/meminfo` 等。
- **fuser**：通过文件或文件系统找出正在使用它的进程。
  - `fuser -uv 目录/文件`：显示使用该文件的进程及权限。
  - `fuser -mki 挂载点`：交互式终止占用文件系统的进程（用于无法卸载时）。
- **lsof**：列出进程打开的文件或设备。
  - `lsof -u 用户`：显示该用户进程打开的文件。
  - `lsof +d 目录`：列出该目录下被打开的文件。
- **pidof**：根据程序名找出PID。`pidof 程序名`

# 二.SELinux 

## 1.什么是SELinux
- **Security Enhanced Linux**，由NSA开发，实现**强制访问控制（MAC）**，弥补传统**自主访问控制（DAC）**（基于UGO权限）的不足。
- **MAC**：对主体（进程）和目标（文件资源）进行细粒度控制，即使进程以root身份运行，也需符合SELinux策略才能访问资源。
- **DAC问题**：root权限过高，目录权限设置不当易导致资源误用。

## 2.SELinux运行模式与概念
- **模式**：
  - `enforcing`：强制模式，违反策略则阻止并记录。
  - `permissive`：宽容模式，仅记录不阻止。
  - `disabled`：关闭SELinux。
- **政策（Policy）**：预定义的规则集合。CentOS 7默认 `targeted`（主要限制网络服务），另有 `minimum` 和 `mls`。
- **安全性本文（security context）**：每个进程和文件都有一个安全上下文，格式为 `identify:role:type`。其中 **type** 是关键字段。
  - 进程的type称为 **domain**，文件的type称为 **type**。
  - 策略中定义了domain可以访问哪些type的文件。

## 3.SELinux管理命令
| 命令 | 作用 |
|------|------|
| `getenforce` | 查看当前模式 |
| `sestatus` | 显示SELinux详细状态（政策、模式、配置文件等） |
| `setenforce 0/1` | 临时切换为permissive(0)或enforcing(1)（需先启用SELinux） |
| `/etc/selinux/config` | 修改默认模式和政策（需重启生效） |
| `ls -Z` | 查看文件的安全上下文 |
| `ps -eZ` | 查看进程的安全上下文 |

## 4.策略规则管理
- **getsebool -a**：列出所有策略规则的布尔值（开启/关闭）。
- **setsebool -P 规则名 on/off**：永久修改规则（`-P` 写入配置文件）。
- **seinfo**：显示SELinux统计信息（类型、规则数等）。
- **sesearch**：搜索规则详情，如 `sesearch -A -s 主体domain -t 目标type` 可查看特定domain允许访问的type。

## 5.修改安全上下文
- **临时修改**：`chcon [-t type] 文件` 或 `chcon --reference=参考文件 目标文件`
- **恢复默认**：`restorecon [-Rv] 目录/文件` 根据默认策略恢复安全上下文。
- **管理默认上下文**：`semanage fcontext -l` 查询默认上下文；`semanage fcontext -a -t type 路径表达式` 添加自定义默认上下文，再用 `restorecon` 应用。

## 6.日志与排错
- **auditd** 与 **setroubleshootd** 共同处理SELinux事件，错误信息记录在 `/var/log/messages` 和 `/var/log/audit/audit.log`。
- `sealert -l 报警ID`：根据日志中的报警ID获取详细分析和建议（如启用某个布尔值或修改上下文）。
- 案例中展示了常见问题及解决方法：
  - 匿名FTP无法下载：检查文件权限（`chmod a+r`）。
  - 一般用户无法从主文件夹下载：启用 `ftp_home_dir` 布尔值。
  - 非标准目录访问：修改目录的安全上下文为 `public_content_t`。
  - 更改服务端口：用 `semanage port -a -t ftp_port_t -p tcp 555` 添加端口许可。

# 重点

- 进程是运行中的程序，拥有PID和PPID，通过fork-and-exec创建子进程。
- 工作管理允许在单个终端下前后台切换任务，使用 `&`、`Ctrl+Z`、`jobs`、`fg`、`bg` 等控制。
- 进程观察工具 `ps`、`top`、`pstree` 可查看状态和资源占用。
- 通过 `kill` 发送信号（1,9,15）管理进程，`killall` 可批量结束同名进程。
- 进程优先级由PRI和NI共同决定，用户可通过 `nice` 和 `renice` 调整NI值。
- 系统资源观察工具包括 `free`、`uptime`、`netstat`、`dmesg`、`vmstat`。
- `/proc` 文件系统提供进程和内核信息；`fuser`、`lsof`、`pidof` 用于查询进程与文件的关系。
- SELinux采用MAC机制，通过安全上下文和策略规则限制进程访问文件。常见模式为 enforcing、permissive、disabled。
- 管理SELinux需熟悉 `getenforce`、`setenforce`、`getsebool`、`setsebool`、`chcon`、`restorecon`、`semanage` 等命令，并善用 `/var/log/messages` 和 `sealert` 排错。
