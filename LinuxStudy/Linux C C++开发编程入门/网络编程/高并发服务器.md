## 1. 概述

本项目实现了一个**高并发 TCP 服务器与配套客户端**，采用 epoll 事件驱动模型，支持单进程管理数万并发连接。服务器监听多个端口（默认 100 个），使用非阻塞 I/O 和边缘触发（EPOLLET）高效处理连接建立与数据收发。客户端通过非阻塞 connect 和 epoll 事件驱动，快速建立大量长连接，并通过轮询服务器多端口均匀分配负载。项目在虚拟机环境中进行了系统调优，成功实现 7 万并发长连接的稳定运行。

## 5. 主要函数思路详解

### 5.1 服务器端

#### 5.1.1 `set_nonblock`
```c
static int set_nonblock(int fd) {
    int flags = fcntl(fd, F_GETFL, 0);
    if (flags < 0) return -1;
    flags |= O_NONBLOCK;
    return fcntl(fd, F_SETFL, flags);
}
```
- **作用**：将文件描述符设置为非阻塞模式。
- **关键点**：使用 `fcntl` 获取当前标志，添加 `O_NONBLOCK` 后设置。非阻塞 I/O 配合 epoll 边缘触发，避免线程阻塞。

#### 5.1.2 `main` 服务器主逻辑
**设计思路**：创建 epoll 实例，依次绑定多个端口，将监听套接字加入 epoll。主循环中等待事件，对监听套接字调用 `accept` 接受新连接并加入 epoll；对客户端套接字读取数据并打印（过滤特定消息）。

**实现步骤**：
1. 解析命令行参数（起始端口），创建 epoll 实例。
2. 循环创建 `MAX_PORT_NUM` 个监听套接字：
   - 设置 `SO_REUSEADDR` 以便快速重启。
   - 绑定端口（`START_PORT + i`），开始监听。
   - 设置非阻塞，加入 epoll（关注 `EPOLLIN`）。
   - 记录监听套接字数组。
3. 主事件循环：
   - 调用 `epoll_wait`（超时 -1，无限等待）。
   - 遍历就绪事件：
     - 若为监听套接字，循环调用 `accept` 接受所有待处理连接（非阻塞），每个新连接设置非阻塞，加入 epoll（关注 `EPOLLIN | EPOLLET`，边缘触发）。
     - 若为客户端套接字，读取数据：
       - 若 `recv` 返回 ≤0，关闭连接并从 epoll 中删除。
       - 否则打印接收到的数据（过滤掉 "data from" 前缀的消息）。

**关键点**：
- 使用边缘触发（`EPOLLET`），要求一次性读完所有数据（代码中只读一次，存在数据残留风险，但本例中客户端发送短消息，可接受）。
- 监听套接字设置为非阻塞，`accept` 在循环中处理直到返回 `EAGAIN`。
- 使用 `SO_REUSEADDR` 避免端口占用问题。
- 监听多个端口，分散连接压力。

#### 5.2.2 `main` 客户端主逻辑
**设计思路**：使用 epoll 管理大量非阻塞 connect，快速建立连接并发送问候，同时处理服务器回应的数据（丢弃）。通过轮询端口策略，均匀分配负载。定期打印连接速率。

**实现步骤**：
1. 解析命令行参数（服务器 IP），创建 epoll 实例。
2. 进入无限循环，持续创建新连接：
   - 创建套接字，设置为非阻塞。
   - 设置目标地址端口（轮询 `START_PORT` 到 `START_PORT+PORT_NUM-1`）。
   - 调用 `connect`，若返回 -1 且 `errno` 为 `EINPROGRESS`，表示连接正在进行。
   - 将套接字加入 epoll，关注 `EPOLLOUT | EPOLLIN`（等待连接成功，同时关注读事件）。
   - 连接数加 1，端口轮转。
3. 调用 `epoll_wait`（超时 0，非阻塞），处理就绪事件：
   - 若事件包含 `EPOLLOUT`，表示连接成功，发送问候消息（"Hello Server: client --> %d\n"），然后修改事件为只关注 `EPOLLIN`（避免重复触发）。
   - 若事件包含 `EPOLLIN`，读取数据并丢弃，若返回 ≤0 则关闭连接并从 epoll 中删除。
4. 每建立 1000 个连接，打印耗时和当前连接数。
5. 使用 `usleep(500)` 控制连接创建速率，防止 CPU 飙升。

**关键点**：
- 使用非阻塞 `connect`，通过 `EPOLLOUT` 事件检测连接成功。
- 轮询端口策略：`current_port` 循环遍历 100 个端口，使连接均匀分布到服务器各端口。
- 事件修改：连接成功后，将事件从 `EPOLLOUT|EPOLLIN` 改为 `EPOLLIN`，避免后续写事件再次触发。
- 性能统计：每 1000 个连接计算一次耗时，便于观察建立速率。

## 6. 完整代码注释

### 6.1 服务器代码
```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>
#include <arpa/inet.h>
#include <errno.h>
#include <sys/epoll.h>
#include <fcntl.h>

#define MAX_PORT_NUM   100          // 监听的端口数量
#define START_PORT     8888
#define MAX_EVENTS     10240
#define BUFFER_SIZE    1024

// 设置非阻塞
static int set_nonblock(int fd) {
    int flags = fcntl(fd, F_GETFL, 0);
    if (flags < 0) return -1;
    flags |= O_NONBLOCK;
    return fcntl(fd, F_SETFL, flags);
}

int main(int argc, char *argv[]) {
    if (argc < 2) {
        printf("Usage: %s [start_port]\n", argv[0]);
        return 1;
    }
    int start_port = atoi(argv[1]);

    int epfd = epoll_create(1);
    if (epfd < 0) {
        perror("epoll_create");
        return 1;
    }

    struct epoll_event ev, events[MAX_EVENTS];
    int listen_fds[MAX_PORT_NUM] = {0};
    int listen_cnt = 0;

    // 创建并绑定多个端口
    for (int i = 0; i < MAX_PORT_NUM; i++) {
        int sockfd = socket(AF_INET, SOCK_STREAM, 0);
        if (sockfd < 0) {
            perror("socket");
            continue;
        }
        int opt = 1;
        setsockopt(sockfd, SOL_SOCKET, SO_REUSEADDR, &opt, sizeof(opt));

        struct sockaddr_in addr;
        memset(&addr, 0, sizeof(addr));
        addr.sin_family = AF_INET;
        addr.sin_port = htons(start_port + i);
        addr.sin_addr.s_addr = htonl(INADDR_ANY);

        if (bind(sockfd, (struct sockaddr *)&addr, sizeof(addr)) < 0) {
            perror("bind");
            close(sockfd);
            continue;
        }
        if (listen(sockfd, 1024) < 0) {   // 增大 backlog
            perror("listen");
            close(sockfd);
            continue;
        }
        set_nonblock(sockfd);   // 监听 socket 也设为非阻塞（可选）

        ev.events = EPOLLIN;
        ev.data.fd = sockfd;
        epoll_ctl(epfd, EPOLL_CTL_ADD, sockfd, &ev);
        listen_fds[listen_cnt++] = sockfd;
        printf("Listening on port %d (fd=%d)\n", start_port + i, sockfd);
    }

    printf("Server started, listening on %d ports\n", listen_cnt);

    while (1) {
        int nready = epoll_wait(epfd, events, MAX_EVENTS, -1);
        if (nready < 0) {
            if (errno == EINTR) continue;
            perror("epoll_wait");
            break;
        }

        for (int i = 0; i < nready; i++) {
            int fd = events[i].data.fd;
            // 判断是否为监听 socket
            int is_listen = 0;
            for (int j = 0; j < listen_cnt; j++) {
                if (fd == listen_fds[j]) {
                    is_listen = 1;
                    break;
                }
            }
            if (is_listen) {
                // 接受新连接
                while (1) {
                    struct sockaddr_in client_addr;
                    socklen_t client_len = sizeof(client_addr);
                    int clientfd = accept(fd, (struct sockaddr *)&client_addr, &client_len);
                    if (clientfd < 0) {
                        if (errno == EAGAIN || errno == EWOULDBLOCK) break;
                        perror("accept");
                        break;
                    }
                    set_nonblock(clientfd);
                    ev.events = EPOLLIN | EPOLLET;   // 边缘触发，需一次读完
                    ev.data.fd = clientfd;
                    epoll_ctl(epfd, EPOLL_CTL_ADD, clientfd, &ev);
                }
            } else {
                // 已连接客户端的数据
                int clientfd = fd;
                char buffer[BUFFER_SIZE];
                int len = recv(clientfd, buffer, sizeof(buffer) - 1, 0);
                if (len <= 0) {
                    // 连接关闭或出错
                    close(clientfd);
                    epoll_ctl(epfd, EPOLL_CTL_DEL, clientfd, NULL);
                } else {
                    buffer[len] = '\0';
                    // 过滤掉 "data from" 消息，只显示 Hello Server
                    char *line = strtok(buffer, "\n");
                    while (line) {
                        if (strncmp(line, "data from", 9) != 0) {
                            printf("Recv: %s (%d bytes), clientfd=%d\n", line, (int)strlen(line), clientfd);
                        }
                        line = strtok(NULL, "\n");
                    }
                }
            }
        }
    }

    for (int i = 0; i < listen_cnt; i++) close(listen_fds[i]);
    close(epfd);
    return 0;
}
```

### 6.2 客户端代码
```c
#include <stdio.h>
#include <string.h>
#include <stdlib.h>
#include <unistd.h>
#include <arpa/inet.h>
#include <errno.h>
#include <sys/epoll.h>
#include <fcntl.h>
#include <sys/time.h>

#define START_PORT     8888
#define PORT_NUM       100
#define MAX_EVENTS     10240
#define BUF_SIZE       128
#define TIME_SUB_MS(tv1, tv2) ((tv1.tv_sec - tv2.tv_sec) * 1000 + (tv1.tv_usec - tv2.tv_usec) / 1000)

static int set_nonblock(int fd) {
    int flags = fcntl(fd, F_GETFL, 0);
    if (flags < 0) return -1;
    flags |= O_NONBLOCK;
    return fcntl(fd, F_SETFL, flags);
}

int main(int argc, char *argv[]) {
    if (argc != 2) {
        printf("Usage: %s server_ip\n", argv[0]);
        return 1;
    }
    const char *server_ip = argv[1];

    int epfd = epoll_create(1);
    if (epfd < 0) {
        perror("epoll_create");
        return 1;
    }

    struct epoll_event ev, events[MAX_EVENTS];
    int connections = 0;
    struct sockaddr_in addr;
    memset(&addr, 0, sizeof(addr));
    addr.sin_family = AF_INET;
    addr.sin_addr.s_addr = inet_addr(server_ip);

    int current_port = START_PORT;
    struct timeval tv_begin;
    gettimeofday(&tv_begin, NULL);

    while (1) {
        // 创建新连接
        int sockfd = socket(AF_INET, SOCK_STREAM, 0);
        if (sockfd < 0) {
            perror("socket");
            usleep(1000);
            continue;
        }
        set_nonblock(sockfd);
        addr.sin_port = htons(current_port);
        int ret = connect(sockfd, (struct sockaddr *)&addr, sizeof(addr));
        if (ret < 0 && errno != EINPROGRESS) {
            close(sockfd);
            usleep(100);
            continue;
        }

        ev.events = EPOLLOUT | EPOLLIN;
        ev.data.fd = sockfd;
        epoll_ctl(epfd, EPOLL_CTL_ADD, sockfd, &ev);
        connections++;

        // 轮换端口
        current_port++;
        if (current_port >= START_PORT + PORT_NUM) current_port = START_PORT;

        // 处理 epoll 事件
        int nfds = epoll_wait(epfd, events, MAX_EVENTS, 0);
        for (int i = 0; i < nfds; i++) {
            int fd = events[i].data.fd;
            if (events[i].events & EPOLLOUT) {
                // 连接成功，发送问候
                char buf[BUF_SIZE];
                snprintf(buf, sizeof(buf), "Hello Server: client --> %d\n", connections);
                send(fd, buf, strlen(buf), 0);
                // 改为只监听读（可选项，不再写）
                ev.events = EPOLLIN;
                ev.data.fd = fd;
                epoll_ctl(epfd, EPOLL_CTL_MOD, fd, &ev);
                // 可选：每成功一个就打印（调试用，高并发时建议注释）
                // printf("Connection %d established, fd=%d\n", connections, fd);
            }
            if (events[i].events & EPOLLIN) {
                // 接收数据，简单丢弃（保持连接活跃）
                char buf[1024];
                int len = recv(fd, buf, sizeof(buf) - 1, 0);
                if (len <= 0) {
                    close(fd);
                    epoll_ctl(epfd, EPOLL_CTL_DEL, fd, NULL);
                }
            }
        }

        // 每 1000 个连接打印统计
        if (connections % 1000 == 0) {
            struct timeval tv_cur;
            gettimeofday(&tv_cur, NULL);
            int time_used = TIME_SUB_MS(tv_cur, tv_begin);
            printf("connections: %d, time_used: %d ms\n", connections, time_used);
            gettimeofday(&tv_begin, NULL);
        }

        usleep(500);   // 控制创建速率，避免 CPU 飙升
    }

    close(epfd);
    return 0;
}
```

## 7. 实习面试常见问题及解答思路

### Q1：为什么服务器使用边缘触发（EPOLLET）而不是水平触发？
**答**：边缘触发只在状态变化时通知一次，配合非阻塞 I/O 循环读取，可避免频繁触发，提高效率。水平触发会持续通知直到数据读完，可能增加系统调用次数。但在本代码中，客户端发送短消息，边缘触发与水平触发差别不大。边缘触发需确保一次性读完所有数据，否则可能丢失后续通知。

### Q2：客户端如何检测非阻塞 connect 完成？
**答**：将套接字设置为非阻塞，调用 `connect` 返回 -1，`errno` 为 `EINPROGRESS`。然后通过 epoll 监听 `EPOLLOUT` 事件，当连接成功时，`EPOLLOUT` 会触发。此时可发送数据并修改事件。

### Q3：服务器为什么要监听多个端口？有什么好处？
**答**：多端口策略可以分散连接压力，避免单端口成为瓶颈。在客户端轮询端口时，可将大量连接均匀分配到不同端口，提高并发处理能力。同时，多端口可避免内核单端口连接队列溢出的问题。

### Q4：代码中 `epoll_wait` 的超时参数分别有什么作用？
**答**：服务器使用 -1（无限阻塞），节省 CPU 资源，直到有事件发生才返回。客户端使用 0（非阻塞），立即返回，以便在循环中快速创建新连接并处理已就绪事件。客户端通过 `usleep` 控制创建速率，避免 CPU 飙升。

### Q5：如何在高并发下优化系统参数？
**答**：需要调整：
- **文件描述符上限**：`ulimit -n 1000000`，并修改 `/etc/security/limits.conf`。
- **本地端口范围**：`sysctl -w net.ipv4.ip_local_port_range="1024 65000"`，扩大可用端口数。
- **TIME_WAIT 快速回收**：`sysctl -w net.ipv4.tcp_tw_reuse=1`（注意安全性）。
- **TCP 内存参数**：调整 `net.ipv4.tcp_mem`、`net.core.rmem_max` 等，减少每个连接的内存开销。

### Q6：服务器中 `accept` 循环为什么在 `EAGAIN` 时退出？
**答**：非阻塞模式下，`accept` 在没有新连接时会返回 -1，`errno` 为 `EAGAIN` 或 `EWOULDBLOCK`。此时应退出循环，等待下次 epoll 事件触发。这样可一次处理所有已到达的连接，提高效率。

### Q7：客户端中 `EPOLLOUT` 和 `EPOLLIN` 同时监听，连接成功后为什么改为只监听 `EPOLLIN`？
**答**：连接成功后发送一次问候，之后只需关注读事件（接收服务器可能返回的数据）。若继续监听 `EPOLLOUT`，由于套接字始终可写，会持续触发 `EPOLLOUT`，造成不必要的 epoll 事件。修改后避免无效唤醒。

### Q8：性能统计中如何计算连接建立速率？
**答**：使用 `gettimeofday` 获取微秒级时间，每 1000 个连接计算一次差值，换算为毫秒，输出连接数和耗时，便于观察并发建立速度。

  - **项目描述**：基于 epoll 边缘触发实现多端口 TCP 服务器，单进程管理数万并发连接；配套客户端采用非阻塞 connect 和 epoll 事件驱动，快速建立大量长连接，并通过轮询端口均匀分配负载。在虚拟机环境中进行系统调优（文件描述符上限、端口范围、TCP 参数等），成功实现 7 万并发长连接稳定运行。项目深入实践了 epoll 事件驱动、非阻塞 I/O、高并发调优等关键技术。
  - **技术栈**：C 语言、Linux 套接字、epoll、非阻塞 I/O、TCP/IP、系统调优
  - **收获**：掌握了 epoll 在高并发场景下的使用方法，理解了边缘触发与水平触发的区别，学会了非阻塞 connect 的检测技巧，积累了系统参数调优经验。
