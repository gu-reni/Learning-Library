## 高并发 TCP 服务器（C/Epoll）

### 1. 概述

该服务器基于 epoll 边缘触发（EPOLLET）实现，单进程管理多个监听端口，支持高并发长连接。采用非阻塞 I/O 和事件驱动模型，高效处理连接建立与数据收发。服务器通过监听多个端口分散连接压力，并针对虚拟机环境进行系统调优，实现了 7 万并发长连接的稳定运行。

### 5. 主要函数思路详解

#### 5.1 `set_nonblock`

```c
static int set_nonblock(int fd) {
    int flags = fcntl(fd, F_GETFL, 0);
    if (flags < 0) return -1;
    flags |= O_NONBLOCK;
    return fcntl(fd, F_SETFL, flags);
}
```

**作用**：将文件描述符设置为非阻塞模式。  
**实现步骤**：
1. 使用 `fcntl` 获取当前标志位。
2. 添加 `O_NONBLOCK` 标志。
3. 写回设置。  
**关键点**：非阻塞模式是 epoll 边缘触发的基础，避免线程阻塞。

#### 5.2 `main` 服务器主逻辑

**设计思路**：创建多个监听套接字，加入 epoll，循环处理连接建立和数据收发。

**实现步骤**：
1. 解析命令行参数（起始端口），创建 epoll 实例。
2. 循环创建 `MAX_PORT_NUM` 个监听套接字：
   - 设置 `SO_REUSEADDR` 以便快速重启。
   - 绑定端口（`start_port + i`），开始监听，`backlog` 设为 1024。
   - 设置为非阻塞，加入 epoll（关注 `EPOLLIN`）。
   - 记录套接字到 `listen_fds` 数组。
3. 主事件循环：
   - 调用 `epoll_wait`（超时 -1，无限阻塞）等待事件。
   - 遍历就绪事件：
     - **监听套接字事件**：循环调用 `accept` 接受所有待处理连接（非阻塞），为每个新连接设置非阻塞，加入 epoll（关注 `EPOLLIN | EPOLLET`，边缘触发）。
     - **客户端套接字事件**：调用 `recv` 读取数据，若返回值 ≤0 则关闭连接并从 epoll 中删除；否则打印接收到的数据（过滤掉 "data from" 前缀的消息）。
4. 退出时关闭所有监听套接字和 epoll 实例。

**关键点**：
- **多端口监听**：将负载分散到 100 个端口，避免单端口队列溢出。
- **边缘触发（ET）**：要求一次性读完数据，但代码中只读一次（客户端短消息，影响小）；实际生产需循环读取直到 `EAGAIN`。
- **非阻塞 accept**：`accept` 循环直到返回 `EAGAIN`，一次性处理所有新连接。
- **`SO_REUSEADDR`**：允许端口快速重用，避免 `TIME_WAIT` 导致绑定失败。

### 6. 完整代码注释

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>
#include <arpa/inet.h>
#include <errno.h>
#include <sys/epoll.h>
#include <fcntl.h>

#define MAX_PORT_NUM   100
#define START_PORT     8888
#define MAX_EVENTS     10240
#define BUFFER_SIZE    1024

// 设置非阻塞
static int set_nonblock(int fd) {
    int flags = fcntl(fd, F_GETFL, 0);
    if (flags < 0) return -1;
    flags |= O_NONBLOCK;
    return fcntl(fd, F_SETFL, flags);
}

int main(int argc, char *argv[]) {
    if (argc < 2) {
        printf("Usage: %s [start_port]\n", argv[0]);
        return 1;
    }
    int start_port = atoi(argv[1]);

    int epfd = epoll_create(1);
    if (epfd < 0) {
        perror("epoll_create");
        return 1;
    }

    struct epoll_event ev, events[MAX_EVENTS];
    int listen_fds[MAX_PORT_NUM] = {0};
    int listen_cnt = 0;

    // 创建并绑定多个端口
    for (int i = 0; i < MAX_PORT_NUM; i++) {
        int sockfd = socket(AF_INET, SOCK_STREAM, 0);
        if (sockfd < 0) {
            perror("socket");
            continue;
        }
        int opt = 1;
        setsockopt(sockfd, SOL_SOCKET, SO_REUSEADDR, &opt, sizeof(opt));

        struct sockaddr_in addr;
        memset(&addr, 0, sizeof(addr));
        addr.sin_family = AF_INET;
        addr.sin_port = htons(start_port + i);
        addr.sin_addr.s_addr = htonl(INADDR_ANY);

        if (bind(sockfd, (struct sockaddr *)&addr, sizeof(addr)) < 0) {
            perror("bind");
            close(sockfd);
            continue;
        }
        if (listen(sockfd, 1024) < 0) {   // 增大 backlog
            perror("listen");
            close(sockfd);
            continue;
        }
        set_nonblock(sockfd);   // 监听 socket 也设为非阻塞（可选）

        ev.events = EPOLLIN;
        ev.data.fd = sockfd;
        epoll_ctl(epfd, EPOLL_CTL_ADD, sockfd, &ev);
        listen_fds[listen_cnt++] = sockfd;
        printf("Listening on port %d (fd=%d)\n", start_port + i, sockfd);
    }

    printf("Server started, listening on %d ports\n", listen_cnt);

    while (1) {
        int nready = epoll_wait(epfd, events, MAX_EVENTS, -1);
        if (nready < 0) {
            if (errno == EINTR) continue;
            perror("epoll_wait");
            break;
        }

        for (int i = 0; i < nready; i++) {
            int fd = events[i].data.fd;
            // 判断是否为监听 socket
            int is_listen = 0;
            for (int j = 0; j < listen_cnt; j++) {
                if (fd == listen_fds[j]) {
                    is_listen = 1;
                    break;
                }
            }
            if (is_listen) {
                // 接受新连接
                while (1) {
                    struct sockaddr_in client_addr;
                    socklen_t client_len = sizeof(client_addr);
                    int clientfd = accept(fd, (struct sockaddr *)&client_addr, &client_len);
                    if (clientfd < 0) {
                        if (errno == EAGAIN || errno == EWOULDBLOCK) break;
                        perror("accept");
                        break;
                    }
                    set_nonblock(clientfd);
                    ev.events = EPOLLIN | EPOLLET;   // 边缘触发
                    ev.data.fd = clientfd;
                    epoll_ctl(epfd, EPOLL_CTL_ADD, clientfd, &ev);
                }
            } else {
                // 已连接客户端的数据
                int clientfd = fd;
                char buffer[BUFFER_SIZE];
                int len = recv(clientfd, buffer, sizeof(buffer) - 1, 0);
                if (len <= 0) {
                    close(clientfd);
                    epoll_ctl(epfd, EPOLL_CTL_DEL, clientfd, NULL);
                } else {
                    buffer[len] = '\0';
                    // 过滤掉 "data from" 消息，只显示 Hello Server
                    char *line = strtok(buffer, "\n");
                    while (line) {
                        if (strncmp(line, "data from", 9) != 0) {
                            printf("Recv: %s (%d bytes), clientfd=%d\n", line, (int)strlen(line), clientfd);
                        }
                        line = strtok(NULL, "\n");
                    }
                }
            }
        }
    }

    for (int i = 0; i < listen_cnt; i++) close(listen_fds[i]);
    close(epfd);
    return 0;
}
```

### 7. 实习面试常见问题及解答思路

#### Q1：为什么使用 epoll 而不是 select/poll？
**答**：epoll 采用事件驱动，只返回就绪的文件描述符，复杂度 O(1)，而 select/poll 需要遍历整个集合，效率随 fd 数量线性下降。epoll 支持百万级并发，且无需每次调用重新传递 fd 集合。

#### Q2：边缘触发（EPOLLET）与水平触发（EPOLLLT）的区别？
**答**：边缘触发只在状态变化时通知一次（如从不可读变为可读），要求应用一次性读完所有数据，否则后续数据可能不再触发。水平触发则只要有数据就持续通知。边缘触发可减少系统调用次数，但实现更复杂，通常配合非阻塞 I/O 和循环读取。

#### Q3：为什么监听多个端口？
**答**：分散连接压力，避免单端口连接队列（`listen` 的 `backlog`）溢出。客户端可轮询端口，将大量连接均匀分配到不同端口，提高并发处理能力。

#### Q4：`accept` 循环中为什么判断 `EAGAIN` 后退出？
**答**：非阻塞模式下，`accept` 在没有新连接时返回 -1，`errno` 为 `EAGAIN` 或 `EWOULDBLOCK`。此时应退出循环，等待下次 epoll 事件触发，避免无限循环。

#### Q5：如何优化系统参数以支持高并发？
**答**：
- **文件描述符上限**：`ulimit -n 1000000` 并修改 `/etc/security/limits.conf`。
- **本地端口范围**：`sysctl -w net.ipv4.ip_local_port_range="1024 65000"`。
- **TIME_WAIT 快速回收**：`sysctl -w net.ipv4.tcp_tw_reuse=1`。
- **TCP 内存参数**：调整 `net.ipv4.tcp_mem`、`net.core.rmem_max` 等，降低每个连接的内存开销。

#### Q6：`recv` 返回 0 和 -1 分别代表什么？
**答**：0 表示对方正常关闭连接；-1 表示出错（如连接重置）。两种情况下都应关闭套接字并从 epoll 中删除。

#### 5.2 `main` 客户端主逻辑

**设计思路**：使用 epoll 管理大量非阻塞 `connect`，快速建立连接并发送问候，同时处理服务器回应的数据（丢弃）。通过轮询端口均匀分配负载，定期打印连接速率。

**实现步骤**：
1. 解析命令行参数（服务器 IP），创建 epoll 实例。
2. 进入无限循环，持续创建新连接：
   - 创建套接字，设置为非阻塞。
   - 设置目标地址端口（轮询 `START_PORT` 到 `START_PORT+PORT_NUM-1`）。
   - 调用非阻塞 `connect`，若返回 -1 且 `errno` 为 `EINPROGRESS`，表示连接正在进行。
   - 将套接字加入 epoll，关注 `EPOLLOUT | EPOLLIN`。
   - 连接数加 1，端口轮转。
3. 调用 `epoll_wait`（超时 0，非阻塞），处理就绪事件：
   - **`EPOLLOUT` 事件**：连接成功，发送问候消息（"Hello Server: client --> %d\n"），然后修改事件为只关注 `EPOLLIN`（避免写事件重复触发）。
   - **`EPOLLIN` 事件**：读取服务器返回的数据并丢弃，若返回 ≤0 则关闭连接并从 epoll 中删除。
4. 每建立 1000 个连接，打印当前连接数和耗时。
5. 使用 `usleep(500)` 控制创建速率，防止 CPU 飙升。

**关键点**：
- **非阻塞 connect**：通过 `EPOLLOUT` 事件检测连接成功，避免阻塞。
- **轮询端口**：`current_port` 循环遍历，均匀分配负载。
- **事件修改**：连接成功后，将事件从 `EPOLLOUT|EPOLLIN` 改为 `EPOLLIN`，避免无效唤醒。
- **速率控制**：`usleep(500)` 防止客户端过快占用 CPU，同时保证连接建立速度。

### 6. 完整代码注释

```c
#include <stdio.h>
#include <string.h>
#include <stdlib.h>
#include <unistd.h>
#include <arpa/inet.h>
#include <errno.h>
#include <sys/epoll.h>
#include <fcntl.h>
#include <sys/time.h>

#define START_PORT     8888
#define PORT_NUM       100
#define MAX_EVENTS     10240
#define BUF_SIZE       128
#define TIME_SUB_MS(tv1, tv2) ((tv1.tv_sec - tv2.tv_sec) * 1000 + (tv1.tv_usec - tv2.tv_usec) / 1000)

static int set_nonblock(int fd) {
    int flags = fcntl(fd, F_GETFL, 0);
    if (flags < 0) return -1;
    flags |= O_NONBLOCK;
    return fcntl(fd, F_SETFL, flags);
}

int main(int argc, char *argv[]) {
    if (argc != 2) {
        printf("Usage: %s server_ip\n", argv[0]);
        return 1;
    }
    const char *server_ip = argv[1];

    int epfd = epoll_create(1);
    if (epfd < 0) {
        perror("epoll_create");
        return 1;
    }

    struct epoll_event ev, events[MAX_EVENTS];
    int connections = 0;
    struct sockaddr_in addr;
    memset(&addr, 0, sizeof(addr));
    addr.sin_family = AF_INET;
    addr.sin_addr.s_addr = inet_addr(server_ip);

    int current_port = START_PORT;
    struct timeval tv_begin;
    gettimeofday(&tv_begin, NULL);

    while (1) {
        // 创建新连接
        int sockfd = socket(AF_INET, SOCK_STREAM, 0);
        if (sockfd < 0) {
            perror("socket");
            usleep(1000);
            continue;
        }
        set_nonblock(sockfd);
        addr.sin_port = htons(current_port);
        int ret = connect(sockfd, (struct sockaddr *)&addr, sizeof(addr));
        if (ret < 0 && errno != EINPROGRESS) {
            close(sockfd);
            usleep(100);
            continue;
        }

        ev.events = EPOLLOUT | EPOLLIN;
        ev.data.fd = sockfd;
        epoll_ctl(epfd, EPOLL_CTL_ADD, sockfd, &ev);
        connections++;

        // 轮换端口
        current_port++;
        if (current_port >= START_PORT + PORT_NUM) current_port = START_PORT;

        // 处理 epoll 事件
        int nfds = epoll_wait(epfd, events, MAX_EVENTS, 0);
        for (int i = 0; i < nfds; i++) {
            int fd = events[i].data.fd;
            if (events[i].events & EPOLLOUT) {
                // 连接成功，发送问候
                char buf[BUF_SIZE];
                snprintf(buf, sizeof(buf), "Hello Server: client --> %d\n", connections);
                send(fd, buf, strlen(buf), 0);
                // 改为只监听读（可选项，不再写）
                ev.events = EPOLLIN;
                ev.data.fd = fd;
                epoll_ctl(epfd, EPOLL_CTL_MOD, fd, &ev);
                // 可选：每成功一个就打印（调试用，高并发时建议注释）
                // printf("Connection %d established, fd=%d\n", connections, fd);
            }
            if (events[i].events & EPOLLIN) {
                // 接收数据，简单丢弃（保持连接活跃）
                char buf[1024];
                int len = recv(fd, buf, sizeof(buf) - 1, 0);
                if (len <= 0) {
                    close(fd);
                    epoll_ctl(epfd, EPOLL_CTL_DEL, fd, NULL);
                }
            }
        }

        // 每 1000 个连接打印统计
        if (connections % 1000 == 0) {
            struct timeval tv_cur;
            gettimeofday(&tv_cur, NULL);
            int time_used = TIME_SUB_MS(tv_cur, tv_begin);
            printf("connections: %d, time_used: %d ms\n", connections, time_used);
            gettimeofday(&tv_begin, NULL);
        }

        usleep(500);   // 控制创建速率，避免 CPU 飙升
    }

    close(epfd);
    return 0;
}
```

### 7. 实习面试常见问题及解答思路

#### Q1：如何检测非阻塞 `connect` 成功？
**答**：将套接字设置为非阻塞，调用 `connect` 返回 -1，`errno` 为 `EINPROGRESS`。然后通过 epoll 监听 `EPOLLOUT` 事件，当连接成功时，`EPOLLOUT` 会触发。此时可发送数据并修改事件。

#### Q2：为什么连接成功后要修改事件为只监听 `EPOLLIN`？
**答**：发送问候后，套接字始终可写，若继续监听 `EPOLLOUT`，会持续触发事件，造成不必要的系统调用和 CPU 占用。改为只监听读事件，避免无效唤醒。

#### Q3：轮询端口的目的是什么？
**答**：与服务器多端口策略配合，将连接均匀分配到不同端口，避免单端口成为瓶颈，提高整体并发处理能力。

#### Q4：`epoll_wait` 的超时为什么设置为 0？
**答**：超时 0 表示非阻塞，立即返回，以便主循环能快速创建新连接并处理已就绪的事件。配合 `usleep` 控制创建速率，防止 CPU 飙升。

#### Q5：如何统计连接建立速率？
**答**：使用 `gettimeofday` 获取微秒级时间，每 1000 个连接计算一次时间差，换算为毫秒，输出连接数和耗时，便于观察建立速度。

#### Q6：客户端如何避免创建过快导致系统资源耗尽？
**答**：通过 `usleep(500)` 微秒级休眠控制创建速率，同时在创建失败（如 `socket` 失败）时也进行短暂休眠，防止空转占用 CPU。
