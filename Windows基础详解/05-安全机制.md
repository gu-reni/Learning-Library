## 5.1 用户账户控制 (UAC)

### 原理
应用程序提权时弹出确认对话框，防止恶意软件静默获取管理员权限

### 配置级别

```
控制面板 → 用户账户 → 更改用户账户控制设置
```

| 级别 | 说明 | 推荐度 |
|------|------|--------|
| 始终通知 | 任何更改都通知 | ⭐⭐⭐ |
| 默认 | 应用更改时通知 | ⭐⭐⭐⭐⭐ |
| 仅应用更改时通知 | 不通知用户操作 | ⭐⭐ |
| 从不通知 | 关闭 UAC | ❌ 不推荐 |

### UAC 提示场景
- 安装软件
- 修改系统设置
- 运行管理员程序
- 访问系统文件

### 注册表位置
```
HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System
键名：EnableLUA
值：1 = 启用，0 = 禁用
```

## 5.2 Windows Defender 防病毒

### 打开方式
```
方法 1: 搜索 "Windows 安全中心"
方法 2: 设置 → 更新和安全 → Windows 安全中心
方法 3: 任务栏盾牌图标
```

### 功能模块

| 模块 | 功能 |
|------|------|
| 病毒和威胁防护 | 实时保护、扫描 |
| 防火墙和网络保护 | 入站/出站规则 |
| 应用和浏览器控制 | SmartScreen、Exploit 保护 |
| 设备安全性 | 安全启动、TPM、虚拟化保护 |
| 家庭选项 | 儿童账户管理 |
| 设备性能和运行状况 | 系统健康检查 |

### 扫描类型

| 类型 | 范围 | 耗时 |
|------|------|------|
| 快速扫描 | 系统关键区域 | 1-5 分钟 |
| 完全扫描 | 所有文件和程序 | 1 小时 + |
| 自定义扫描 | 指定位置 | 视范围而定 |

### 命令行扫描
```powershell
# 快速扫描
MpCmdRun.exe -Scan -ScanType 1

# 完整扫描
MpCmdRun.exe -Scan -ScanType 2

# 自定义扫描
MpCmdRun.exe -Scan -ScanType 3 -ScanPath C:\path

# 查看签名版本
MpCmdRun.exe -SignatureUpdate
```

### 排除项设置
```
病毒和威胁防护 → 管理设置 → 排除项
可排除：文件夹、文件类型、文件、进程
```

⚠️ **注意：** 仅排除可信项目，否则会降低安全性！

## 5.3 Windows 防火墙

### 打开方式
```
方法 1: 控制面板 → Windows Defender 防火墙
方法 2: Win + R → firewall.cpl
方法 3: 搜索 "防火墙"
```

### 防火墙规则

**入站规则：** 控制外部访问本机
**出站规则：** 控制本机访问外部

### 创建规则
```
1. 高级设置 → 入站规则 → 新建规则
2. 选择规则类型（程序/端口/预定义）
3. 设置程序路径或端口号
4. 选择操作（允许/阻止）
5. 选择配置文件（域/专用/公用）
6. 命名规则 → 完成
```

### 配置文件
| 类型 | 场景 | 安全级别 |
|------|------|----------|
| 域 | 公司网络 | 中 |
| 专用 | 家庭网络 | 中 |
| 公用 | 咖啡厅/机场 | 高 |

### 命令行管理
```cmd
# 查看防火墙状态
netsh advfirewall show allprofiles

# 关闭防火墙（不推荐）
netsh advfirewall set allprofiles state off

# 开启防火墙
netsh advfirewall set allprofiles state on

# 重置防火墙
netsh advfirewall reset
```

## 5.4 BitLocker 驱动器加密

### 要求
- 专业版/企业版（家庭版无）
- TPM 1.2 或更高版本（或 USB 启动密钥）
- BIOS 支持 TPM

### 启用 BitLocker
```
1. 控制面板 → BitLocker 驱动器加密
2. 点击"启用 BitLocker"
3. 选择解锁方式：
   - TPM 自动解锁
   - 输入 PIN
   - USB 启动密钥
4. 保存恢复密钥（重要！）
5. 选择加密模式
6. 开始加密
```

### 恢复密钥位置
- Microsoft 账户在线
- 打印的纸质副本
- USB 闪存驱动器
- Active Directory（企业环境）

### 管理命令
```cmd
# 查看加密状态
manage-bde -status

# 加密 C 盘
manage-bde -on C:

# 解密 C 盘
manage-bde -off C:

# 添加恢复密码
manage-bde -protectors -add C: -rp

# 暂停保护
manage-bde -protectors -disable C:

# 恢复保护
manage-bde -protectors -enable C:
```

### 注意事项
⚠️ **务必备份恢复密钥！** 丢失后数据无法恢复！

## 5.5 安全启动与信任启动

### 安全启动 (Secure Boot)
UEFI 固件验证启动加载器签名，防止引导级恶意软件

### 信任启动 (Trusted Boot)
Windows 验证内核和驱动签名

### 查看状态
```
1. Win + R → msinfo32
2. 查看以下项目：
   - 安全启动状态：开/关
   - PC 是否处于信任启动模式：是/否
```

### 配置安全启动
```
1. 重启进入 BIOS/UEFI 设置
2. 找到 Secure Boot 选项
3. 启用/禁用
4. 保存并退出
```

⚠️ **注意：** 禁用安全启动可能导致某些系统无法启动！

## 5.6 Windows Hello

## 5.7 SmartScreen

## 5.8 设备加密（家庭版）

### 要求
- 现代设备（支持 Modern Standby）
- TPM 芯片
- Microsoft 账户登录

### 启用
```
设置 → 更新和安全 → 设备加密
→ 开启设备加密
```

### 与 BitLocker 区别
| 特性 | 设备加密 | BitLocker |
|------|----------|-----------|
| 版本 | 家庭版 | 专业版 + |
| 配置选项 | 简化 | 完整 |
| 加密范围 | 系统盘 | 任意驱动器 |
