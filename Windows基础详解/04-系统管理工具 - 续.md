## 4.10 网络工具（命令行）

### ipconfig

```cmd
ipconfig                    # 查看 IP 配置
ipconfig /all               # 详细信息（MAC 地址等）
ipconfig /release           # 释放 DHCP
ipconfig /renew             # 更新 DHCP
ipconfig /flushdns          # 刷新 DNS 缓存
ipconfig /displaydns        # 显示 DNS 缓存
ipconfig /registerdns       # 重新注册 DNS
```

**输出解读：**
| 字段 | 含义 |
|------|------|
| IPv4 地址 | 本机 IP |
| 子网掩码 | 网络范围 |
| 默认网关 | 路由器 IP |
| DHCP 服务器 | 分配 IP 的服务器 |
| DNS 服务器 | 域名解析服务器 |

---

### ping

```cmd
ping www.baidu.com          # 测试连通性
ping 192.168.1.1 -t         # 持续 ping（Ctrl+C 停止）
ping 192.168.1.1 -l 1000    # 发送 1000 字节包
ping 192.168.1.1 -n 10      # 发送 10 次
ping 192.168.1.1 -4         # 强制 IPv4
ping 192.168.1.1 -6         # 强制 IPv6
```

**结果解读：**
| 指标 | 含义 | 正常值 |
|------|------|--------|
| 时间 (ms) | 往返延迟 | 内网<1ms，外网<50ms |
| 丢失率 | 丢包百分比 | 0% |
| TTL | 生存时间 | 64/128/255 |

---

### tracert / pathping

```cmd
tracert www.baidu.com       # 追踪路由
pathping www.baidu.com      # 更详细的路径分析（较慢）
```

**输出解读：**
- 每一跳是一个路由器
- `* * *` 表示该节点不响应
- 延迟突然增加的位置可能是瓶颈

---

### netstat

```cmd
netstat -an                 # 显示所有连接和端口
netstat -ano                # 显示进程 PID
netstat -rn                 # 显示路由表
netstat -e                  # 显示以太网统计
netstat -s                  # 显示协议统计
```

**常用排查：**
```cmd
# 查看占用 80 端口的进程
netstat -ano | findstr :80

# 查看 ESTABLISHED 连接
netstat -an | findstr ESTABLISHED

# 查看监听端口
netstat -an | findstr LISTENING
```

**状态说明：**
| 状态 | 含义 |
|------|------|
| LISTENING | 监听端口 |
| ESTABLISHED | 已建立连接 |
| TIME_WAIT | 等待关闭 |
| CLOSE_WAIT | 远程已关闭 |

---

### nslookup

```cmd
nslookup www.baidu.com      # 查询域名 IP
nslookup                    # 进入交互模式
> server 8.8.8.8            # 切换 DNS 服务器
> www.baidu.com             # 查询
> exit                      # 退出
```

---

### netsh

```cmd
# 重置网络堆栈
netsh winsock reset
netsh int ip reset

# 查看 WiFi 密码
netsh wlan show profile name=WiFi 名称 key=clear

# 重置防火墙
netsh advfirewall reset

# 查看网络配置
netsh interface ip show config

# 设置静态 IP
netsh interface ip set address "以太网" static 192.168.1.100 255.255.255.0 192.168.1.1
```

## 4.11 系统配置 (msconfig)

### 打开方式
```
Win + R → msconfig
```

### 选项卡说明

| 选项卡 | 功能 |
|--------|------|
| 常规 | 启动类型选择（正常/诊断/有选择） |
| 引导 | 多系统引导设置、安全模式 |
| 服务 | 服务启用/禁用 |
| 启动 | 启动项（Win10 后移至任务管理器） |
| 工具 | 快速访问系统工具 |

### 进入安全模式
```
1. 引导选项卡 → 高级选项
2. 勾选"安全引导"
3. 选择最小/网络/其他
4. 确定 → 重启
```

### 诊断启动
```
用于排查问题：
1. 常规 → 有选择的启动
2. 取消"加载启动项"
3. 服务 → 隐藏所有 Microsoft 服务 → 全部禁用
4. 重启 → 逐一启用排查
```

## 4.12 任务计划程序

### 打开方式
```
Win + R → taskschd.msc
```

### 创建基本任务
```
1. 右侧"创建基本任务"
2. 输入名称和描述
3. 选择触发器（时间/事件/登录等）
4. 选择操作（启动程序/发送邮件等）
5. 完成
```

### 常用触发器
| 类型 | 说明 |
|------|------|
| 按计划 | 定时执行 |
| 登录时 | 用户登录时执行 |
| 启动时 | 系统启动时执行 |
| 事件发生时 | 特定事件 ID 触发 |

## 4.13 组策略编辑器 (gpedit.msc)

### 适用版本
专业版及以上（家庭版无此功能）

### 打开方式
```
Win + R → gpedit.msc
```

### 常用配置

**禁用 Windows 更新**
```
计算机配置 → 管理模板 → Windows 组件 → Windows 更新
→ 配置自动更新 → 禁用
```

**禁用 OneDrive**
```
计算机配置 → 管理模板 → Windows 组件 → OneDrive
→ 禁止使用 OneDrive 进行文件存储 → 已启用
```

**限制软件运行**
```
用户配置 → 管理模板 → 系统
→ 不要运行指定的 Windows 应用程序 → 已启用
```

## 4.14 本地安全策略 (secpol.msc)

### 打开方式
```
Win + R → secpol.msc
```

### 策略分类

| 分类 | 内容 |
|------|------|
| 账户策略 | 密码策略、账户锁定 |
| 本地策略 | 审计策略、用户权限、安全选项 |
| 高级审计策略 | 详细审计配置 |
| 软件限制策略 | 应用程序控制 |

### 常用设置

**密码策略**
```
账户策略 → 账户锁定策略
→ 账户锁定阈值：3 次失败后锁定
→ 账户锁定时间：30 分钟
```

**审计登录**
```
高级审计策略 → 账户登录
→ 审核登录事件 → 成功和失败
```

## 4.15 命令提示符 (CMD)

### 打开方式
```
方法 1: Win + R → cmd
方法 2: 搜索 "命令提示符"
方法 3: Win + X → Windows PowerShell（管理员）
```

### 常用命令速查

| 命令 | 功能 | 示例 |
|------|------|------|
| `dir` | 列出目录 | `dir /a` 显示隐藏 |
| `cd` | 切换目录 | `cd C:\Windows` |
| `copy` | 复制文件 | `copy a.txt b.txt` |
| `xcopy` | 高级复制 | `xcopy /E /I src dst` |
| `robocopy` | 镜像复制 | `robocopy src dst /MIR` |
| `del` | 删除文件 | `del *.tmp` |
| `move` | 移动文件 | `move a.txt folder\` |
| `ren` | 重命名 | `ren old.txt new.txt` |
| `mkdir` | 创建目录 | `mkdir newfolder` |
| `rmdir` | 删除目录 | `rmdir /s /q folder` |
| `type` | 显示文件 | `type readme.txt` |
| `findstr` | 搜索文本 | `findstr "error" *.log` |
| `cls` | 清屏 | `cls` |
| `exit` | 退出 | `exit` |

### 查看帮助
```cmd
command /?      # 如：dir /?
help command    # 如：help dir
```

## 4.16 Windows PowerShell

### 打开方式
```
Win + X → Windows PowerShell（管理员）
```

### 常用 Cmdlet

```powershell
# 文件操作
Get-ChildItem           # 列出目录
Copy-Item               # 复制
Move-Item               # 移动
Remove-Item             # 删除
Get-Content             # 读取文件
Set-Content             # 写入文件

# 系统信息
Get-Process             # 进程列表
Get-Service             # 服务列表
Get-EventLog            # 事件日志

# 网络
Get-NetIPAddress        # IP 配置
Test-NetConnection      # 网络测试
```

### 管道示例
```powershell
# 查找占用内存最多的 5 个进程
Get-Process | Sort-Object WorkingSet -Descending | Select-Object -First 5

# 停止所有 notepad 进程
Get-Process notepad | Stop-Process
```

## 4.17 系统文件检查器 (SFC)

### 打开方式
```
管理员 CMD 或 PowerShell
```

### 命令
```cmd
sfc /scannow              # 扫描并修复
sfc /scanonce             # 下次启动时扫描
sfc /scanboot             # 每次启动时扫描
sfc /verifyonly           # 仅验证不修复
```

### 结果解读
| 结果 | 含义 |
|------|------|
| 未找到完整性冲突 | 系统文件正常 |
| 已找到损坏文件并修复 | 修复成功 |
| 找到损坏文件但无法修复 | 需使用 DISM |

## 4.18 DISM (部署映像服务和管理)

### 常用命令
```cmd
# 检查映像健康状态
dism /online /cleanup-image /scanhealth

dism /online /cleanup-image /restorehealth

dism /online /cleanup-image /startcomponentcleanup
```

## 4.19 Windows 恢复环境 (WinRE)

### 进入方式
```
设置 → 更新和安全 → 恢复 → 高级启动 → 立即重新启动
或 开机时强制关机 3 次
```

### 高级启动选项
| 选项 | 功能 |
|------|------|
| 继续 | 退出并继续启动 Windows |
| 疑难解答 | 进入恢复选项 |
| 关闭电脑 | 关机 |

### 疑难解答选项
- **系统还原**：还原到还原点
- **系统映像恢复**：从备份恢复
- **启动修复**：自动修复启动问题
- **命令提示符**：高级修复
- **启动设置**：安全模式等
