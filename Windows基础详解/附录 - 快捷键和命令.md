## A.3 CMD 常用命令

### 文件和目录

```cmd
dir             # 列出目录
cd              # 切换目录
mkdir           # 创建目录
rmdir /s /q     # 删除目录树
copy            # 复制文件
xcopy /E /I     # 复制目录树
robocopy        # 高级复制
move            # 移动文件
del             # 删除文件
ren             # 重命名
type            # 显示文件内容
findstr         # 搜索文本
```

### 系统信息

```cmd
systeminfo      # 系统详细信息
ver             # Windows 版本
hostname        # 主机名
whoami          # 当前用户
tasklist        # 进程列表
taskkill        # 结束进程
netstat         # 网络连接
ipconfig        # IP 配置
```

### 磁盘操作

```cmd
chkdsk          # 检查磁盘
format          # 格式化
diskpart        # 磁盘分区
vol             # 显示卷标
label           # 设置卷标
```

### 网络

```cmd
ping            # 测试连通性
tracert         # 追踪路由
pathping        # 路径分析
nslookup        # DNS 查询
netsh           # 网络配置
```

### 用户和权限

```cmd
net user        # 用户账户
net localgroup  # 本地组
net share       # 共享管理
cacls           # 文件权限
icacls          # 文件权限（高级）
```

## A.4 PowerShell 常用 Cmdlet

### 文件操作

```powershell
Get-ChildItem       # 列出目录 (ls, dir)
Copy-Item           # 复制 (cp)
Move-Item           # 移动 (mv)
Remove-Item         # 删除 (rm, del)
Get-Content         # 读取文件 (cat, type)
Set-Content         # 写入文件
Add-Content         # 追加内容
```

### 系统管理

```powershell
Get-Process         # 进程 (ps)
Stop-Process        # 结束进程
Get-Service         # 服务
Start-Service       # 启动服务
Stop-Service        # 停止服务
Get-EventLog        # 事件日志
Get-WmiObject       # WMI 查询
```

### 网络

```powershell
Get-NetIPAddress    # IP 配置
Test-NetConnection  # 网络测试
Get-DnsClientCache  # DNS 缓存
```

### 帮助

```powershell
Get-Help 命令名          # 查看帮助
Get-Help 命令名 -Examples # 查看示例
Get-Command             # 查找命令
```

## A.5 故障排查命令组合

### 网络重置

```cmd
ipconfig /release
ipconfig /renew
ipconfig /flushdns
netsh winsock reset
netsh int ip reset
# 重启电脑
```

### 系统修复

```cmd
sfc /scannow
dism /online /cleanup-image /restorehealth
chkdsk C: /f /r
# 重启电脑
```

### 更新组件重置

```cmd
net stop wuauserv
net stop cryptSvc
net stop bits
net stop msiserver
ren C:\Windows\SoftwareDistribution SoftwareDistribution.old
ren C:\Windows\System32\catroot2 catroot2.old
net start wuauserv
net start cryptSvc
net start bits
net start msiserver
```
