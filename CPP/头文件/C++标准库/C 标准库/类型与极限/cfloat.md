## `<cfloat>` 头文件详解

`<cfloat>` 是 C++ 标准库中从 C 标准库继承而来的头文件，定义了**浮点类型**（`float`、`double`、`long double`）的**极限值**和**精度参数**。这些宏与具体平台/编译器的浮点实现（通常为 IEEE 754）相关，用于在程序中获取浮点数的范围、有效数字位数、舍入模式等信息，便于编写可移植的数值计算代码。

---

## 一、宏定义详解

以下宏根据 C 标准（及 C++ 标准）定义，值取决于目标平台的浮点表示。

### 1. 浮点类型的“最大值”和“最小值”

| 宏名 | 作用 |
|------|------|
| `FLT_MAX` | `float` 类型的最大有限值（约 `3.40282347e+38F`） |
| `DBL_MAX` | `double` 类型的最大有限值（约 `1.7976931348623157e+308`） |
| `LDBL_MAX` | `long double` 类型的最大有限值 |
| `FLT_MIN` | `float` 类型的最小**规范化**正数（约 `1.17549435e-38F`） |
| `DBL_MIN` | `double` 类型的最小**规范化**正数（约 `2.2250738585072014e-308`） |
| `LDBL_MIN` | `long double` 类型的最小规范化正数 |

### 2. 浮点类型的精度（有效数字位数）

| 宏名 | 作用 |
|------|------|
| `FLT_DIG` | `float` 的十进制有效数字位数（通常为 `6`） |
| `DBL_DIG` | `double` 的十进制有效数字位数（通常为 `15`） |
| `LDBL_DIG` | `long double` 的十进制有效数字位数 |

### 3. 指数范围

| 宏名 | 作用 |
|------|------|
| `FLT_MIN_EXP` | `float` 的二进制指数最小值（基数为 `FLT_RADIX`） |
| `DBL_MIN_EXP` | `double` 的二进制指数最小值 |
| `LDBL_MIN_EXP` | `long double` 的二进制指数最小值 |
| `FLT_MIN_10_EXP` | `float` 的十进制指数最小值（通常 `-37`） |
| `DBL_MIN_10_EXP` | `double` 的十进制指数最小值（通常 `-307`） |
| `LDBL_MIN_10_EXP` | `long double` 的十进制指数最小值 |
| `FLT_MAX_EXP` | `float` 的二进制指数最大值 |
| `DBL_MAX_EXP` | `double` 的二进制指数最大值 |
| `LDBL_MAX_EXP` | `long double` 的二进制指数最大值 |
| `FLT_MAX_10_EXP` | `float` 的十进制指数最大值（通常 `+38`） |
| `DBL_MAX_10_EXP` | `double` 的十进制指数最大值（通常 `+308`） |
| `LDBL_MAX_10_EXP` | `long double` 的十进制指数最大值 |

### 4. 基数与舍入相关

| 宏名 | 作用 |
|------|------|
| `FLT_RADIX` | 指数表示的基数（通常为 `2`，即二进制） |
| `FLT_ROUNDS` | 当前浮点加法的舍入模式（参见下表） |
| `FLT_EVAL_METHOD`（C99/C++11） | 浮点表达式求值方法（如 `0` 表示以类型精度求值） |

`FLT_ROUNDS` 的可能值：

| 值 | 舍入方向 |
|----|----------|
| -1 | 不确定 |
| 0 | 向零舍入 |
| 1 | 向最近值舍入（默认） |
| 2 | 向正无穷舍入 |
| 3 | 向负无穷舍入 |

### 5. 其他极限宏

| 宏名 | 作用 |
|------|------|
| `FLT_EPSILON` | 1.0 与 **大于** 1.0 的最小 `float` 值之差（约 `1.19209290e-7F`） |
| `DBL_EPSILON` | 1.0 与大于 1.0 的最小 `double` 值之差（约 `2.2204460492503131e-16`） |
| `LDBL_EPSILON` | `long double` 的类似值 |
| `FLT_MANT_DIG` | `float` 的尾数位数（二进制） |
| `DBL_MANT_DIG` | `double` 的尾数位数 |
| `LDBL_MANT_DIG` | `long double` 的尾数位数 |

---

## 二、类型定义

`<cfloat>` 不定义任何新类型，仅提供宏。

---

## 三、模板声明

`<cfloat>` 是纯 C 风格头文件，不包含 C++ 模板。
