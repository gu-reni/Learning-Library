## `<climits>` 头文件详解

`<climits>` 是 C++ 标准库中从 C 标准库继承而来的头文件，定义了**整数类型**（`char`、`short`、`int`、`long`、`long long` 及它们的 `unsigned` 变体）的**极限值**。这些宏常量与具体平台/编译器相关，用于在程序中获取整数类型的最小值、最大值以及位宽等信息，帮助编写可移植的数值处理代码。

---

## 一、宏定义详解

以下宏根据 C 标准（及 C++ 标准）定义，值取决于目标平台的整数表示（通常为补码）。

### 1. `char` 类型的极限

| 宏名 | 作用 |
|------|------|
| `CHAR_BIT` | `char` 对象的位数（通常为 `8`） |
| `SCHAR_MIN` | `signed char` 的最小值（通常 `-128`） |
| `SCHAR_MAX` | `signed char` 的最大值（通常 `127`） |
| `UCHAR_MAX` | `unsigned char` 的最大值（通常 `255`） |
| `CHAR_MIN` | `char` 的最小值（若 `char` 默认有符号则同 `SCHAR_MIN`，否则 `0`） |
| `CHAR_MAX` | `char` 的最大值（若 `char` 默认有符号则同 `SCHAR_MAX`，否则 `UCHAR_MAX`） |

### 2. `short int` 类型的极限

| 宏名 | 作用 |
|------|------|
| `SHRT_MIN` | `short` 的最小值（通常 `-32768`） |
| `SHRT_MAX` | `short` 的最大值（通常 `32767`） |
| `USHRT_MAX` | `unsigned short` 的最大值（通常 `65535`） |

### 3. `int` 类型的极限

| 宏名 | 作用 |
|------|------|
| `INT_MIN` | `int` 的最小值（通常 `-2147483648`） |
| `INT_MAX` | `int` 的最大值（通常 `2147483647`） |
| `UINT_MAX` | `unsigned int` 的最大值（通常 `4294967295`） |

### 4. `long int` 类型的极限

| 宏名 | 作用 |
|------|------|
| `LONG_MIN` | `long` 的最小值（32 位系统通常 `-2147483648`，64 位系统可能 `-9223372036854775808`） |
| `LONG_MAX` | `long` 的最大值（对应平台） |
| `ULONG_MAX` | `unsigned long` 的最大值（对应平台） |

### 5. `long long int` 类型的极限（C++11 起）

| 宏名 | 作用 |
|------|------|
| `LLONG_MIN` | `long long` 的最小值（通常 `-9223372036854775808`） |
| `LLONG_MAX` | `long long` 的最大值（通常 `9223372036854775807`） |
| `ULLONG_MAX` | `unsigned long long` 的最大值（通常 `18446744073709551615`） |

### 6. 其他宏

| 宏名 | 作用 |
|------|------|
| `MB_LEN_MAX` | 多字节字符的最大字节数（取决于 `locale` 和平台） |

---

## 二、类型定义

`<climits>` 不定义任何新类型，仅提供宏。

---

## 三、模板声明

`<climits>` 是纯 C 风格头文件，不包含 C++ 模板。
