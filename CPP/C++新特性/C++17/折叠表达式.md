# 折叠表达式（Fold Expressions）（C++17）

**一句话定义**：折叠表达式是对变参模板的参数包应用二元运算符的简化语法，支持对参数包中的所有元素进行递归计算（如求和、逻辑与、逗号运算等），替代了 C++11/14 中复杂的递归模板或初始化列表展开技巧。

---

## 详细语法与用法

### 基本形式

折叠表达式有四种形式，均使用 `...` 和二元运算符：

| 类型 | 语法 | 展开示例（args = 1, 2, 3） | 结合顺序 |
|------|------|---------------------------|----------|
| 一元右折叠 | `(pack op ...)` | `(1 op (2 op 3))` | 右结合 |
| 一元左折叠 | `(... op pack)` | `((1 op 2) op 3)` | 左结合 |
| 二元右折叠 | `(init op ... op pack)` | `(1 op (2 op (3 op init)))` | 右结合，初始值在最右 |
| 二元左折叠 | `(init op ... op pack)` 也可写作 `(pack op ... op init)`？标准规定二元折叠只有一种写法：`(init op ... op pack)`，实际效果等同于左折叠？需要澄清 | 实际二元折叠通常为左折叠：`(((init op arg1) op arg2) ... op argN)` | 左结合，初始值在最左 |

**标准精确定义**：
- 一元右折叠：`(pack op ...)` → `(arg1 op (arg2 op ... (argN-1 op argN)))`
- 一元左折叠：`(... op pack)` → `(((arg1 op arg2) op arg3) ... op argN)`
- 二元右折叠：`(pack op ... op init)` → `(arg1 op (arg2 op ... (argN op init)))`
- 二元左折叠：`(init op ... op pack)` → `(((init op arg1) op arg2) ... op argN)`

**注意**：二元折叠的初始值 `init` 类型可能与参数包类型不同。

### 基本示例

```cpp
#include <iostream>

// 一元右折叠：求和
template<typename... Args>
auto sum_right(Args... args) {
    return (args + ...);   // 右折叠：arg1 + (arg2 + (arg3 + ...))
}

// 一元左折叠：求和（对于整数加法结果相同）
template<typename... Args>
auto sum_left(Args... args) {
    return (... + args);   // 左折叠：((arg1 + arg2) + arg3) ...
}

int result = sum_right(1, 2, 3, 4);  // 10
int result2 = sum_left(1, 2, 3, 4);  // 10

// 对于非结合律运算符，顺序重要
template<typename... Args>
auto sub_right(Args... args) {
    return (args - ...);
}
// sub_right(10, 1, 2) → 10 - (1 - 2) = 10 - (-1) = 11

template<typename... Args>
auto sub_left(Args... args) {
    return (... - args);
}
// sub_left(10, 1, 2) → (10 - 1) - 2 = 7
```

### 二元折叠（带初始值）

```cpp
// 带初始值的求和
template<typename... Args>
auto sum_with_init(Args... args) {
    return (0 + ... + args);   // 二元左折叠：(((0 + arg1) + arg2) ...)
}

// 也可以写为 (args + ... + 0) 二元右折叠
template<typename... Args>
auto sum_with_init_right(Args... args) {
    return (args + ... + 0);   // 右折叠：arg1 + (arg2 + (arg3 + ... + 0))
}

// 字符串拼接
template<typename... Args>
std::string concat(Args... args) {
    return (std::string{} + ... + args);  // 初始值为空字符串
}
std::string s = concat("Hello", " ", "World");  // "Hello World"
```

### 支持的运算符

折叠表达式支持以下二元运算符：
- 算术：`+ - * / %`
- 位运算：`^ & | << >>`
- 逻辑：`&& ||`
- 比较：`== != < > <= >=`
- 赋值：`=`
- 逗号：`,`
- 箭头：`->*`（成员指针）

**特殊规则**：
- 空参数包时，一元折叠表达式**通常**会产生编译错误（除 `&&` 结果为 `true`，`||` 结果为 `false`，逗号运算符结果为 `void()`）。标准对空包的支持不统一，建议避免空包。
- 逻辑运算符 `&&` 和 `||` 会进行短路求值（但标准未强制，实践中编译器会短路）。

### 实际应用场景

#### 1. 打印所有参数

```cpp
template<typename... Args>
void print(Args... args) {
    (std::cout << ... << args) << '\n';   // 左折叠输出
}

template<typename... Args>
void print_with_space(Args... args) {
    ((std::cout << args << ' '), ...);    // 逗号折叠，依次输出每个参数后加空格
    std::cout << '\n';
}
print(1, 2.5, "hello");  // 125hello（无分隔符）
print_with_space(1, 2.5, "hello"); // 1 2.5 hello
```

#### 2. 对所有元素应用函数

```cpp
template<typename F, typename... Args>
void for_each(F f, Args... args) {
    (f(args), ...);   // 逗号折叠
}

for_each([](auto x) { std::cout << x << ' '; }, 1, 2, 3); // 1 2 3
```

#### 3. 检查所有参数是否满足条件

```cpp
template<typename... Args>
bool all_true(Args... args) {
    return (true && ... && args);   // 逻辑与折叠，注意空包返回 true
}

bool b = all_true(true, true, false); // false
```

#### 4. 哈希组合（如自定义类型哈希）

```cpp
template<typename... Args>
std::size_t hash_combine(Args... args) {
    std::size_t seed = 0;
    ( (seed ^= std::hash<Args>{}(args) + 0x9e3779b9 + (seed<<6) + (seed>>2)), ... );
    return seed;
}
```

#### 5. 最小/最大值（需谨慎，因为运算符不是对称的）

```cpp
template<typename... Args>
auto min(Args... args) {
    return (args - ... - ???); // 减法不能求最小，需用比较运算符
}
// 正确实现最小：使用三元运算符？但折叠表达式不支持三元。可用 lambda
template<typename T>
T min(T a, T b) { return a < b ? a : b; }
template<typename... Args>
auto min_all(Args... args) {
    return (args, ...); // 逗号只返回最后一个，不对
    // 正确：使用初始化列表或递归。折叠表达式不适合非结合律操作
}
// 推荐使用 initializer_list 或 C++17 的 std::min({args...})
```

## 底层原理与实现机制

### 1. 编译器展开

折叠表达式是语法糖，编译器将其直接展开为嵌套的二元表达式。对于一元左折叠 `(... op pack)`，编译器生成类似 `((arg1 op arg2) op arg3) ...` 的语法树。与手动递归模板相比，折叠表达式生成的代码量更少，且编译速度更快。

### 2. 与参数包展开的关系

折叠表达式是参数包展开的一种特殊形式，专为二元运算符设计。其核心语法 `...` 指示编译器递归应用运算符。展开过程在编译期完成，不产生运行时递归调用。

### 3. 空包的处理

C++17 标准规定：
- 一元右折叠 `(pack op ...)` 对空包非法（编译错误），除非 `op` 是 `&&`（结果为 `true`）或 `||`（结果为 `false`）或逗号运算符（结果为 `void()`）。但大多数编译器对空包的实现不一致，建议避免空包或使用二元折叠提供初始值。
- 二元折叠 `(init op ... op pack)` 在包为空时，结果为 `init`。

因此，安全做法是使用二元折叠并提供一个合理的初始值。

### 4. 短路求值

对于 `&&` 和 `||`，折叠表达式理论上应该短路。标准说“折叠表达式具有与展开后代码相同的求值顺序和短路行为”，但实际实现可能依赖于编译器。对于 `(false && ... && args)`，如果第一个参数为 `false`，后续参数不应求值。这在模板元编程中很重要。

### 5. 性能

折叠表达式展开后与手写展开完全一致，无额外开销。相比 C++11/14 使用递归模板或 `std::initializer_list` 的技巧，折叠表达式生成的代码更直接，更易于优化。

## 与相关特性的对比

### 1. 折叠表达式 vs 递归模板展开（C++11/14）

| 方面 | 折叠表达式（C++17） | 递归模板（C++11/14） |
|------|---------------------|----------------------|
| 代码量 | 极少（一行） | 多（需定义终止函数 + 递归特化） |
| 可读性 | 高 | 低 |
| 编译速度 | 快 | 慢（递归实例化） |
| 支持空包 | 需谨慎（推荐二元折叠） | 可处理（通过特化） |
| 短路逻辑 | 支持（理论上） | 支持（需特殊设计） |

### 2. 折叠表达式 vs `std::initializer_list` 技巧

C++11 中常用 `(void)std::initializer_list<int>{ (f(args),0)... }` 来依次执行函数。折叠表达式更简洁：

```cpp
// C++11
template<typename... Args>
void call(Args... args) {
    (void)std::initializer_list<int>{ (f(args), 0)... };
}
// C++17
template<typename... Args>
void call(Args... args) {
    (f(args), ...);
}
```

### 3. 一元折叠 vs 二元折叠

| 方面 | 一元折叠 | 二元折叠 |
|------|----------|----------|
| 空包支持 | 通常非法（除 `&&`/`||`/`,`） | 合法，结果为 `init` |
| 语法 | `(args + ...)` | `(init + ... + args)` |
| 典型场景 | 非空参数包 | 需要默认值时 |

## 常见面试问题与解答

### 问题 1：左折叠和右折叠有什么区别？什么时候需要区分？

**答**：左折叠 `(... op args)` 从左到右结合，右折叠 `(args op ...)` 从右到左结合。对于结合律运算符（如加法、乘法、逻辑与/或），结果相同；对于非结合律运算符（如减法、除法），结果不同。

```cpp
sub_left(10, 1, 2)  → (10 - 1) - 2 = 7
sub_right(10, 1, 2) → 10 - (1 - 2) = 11
```

需要区分时，根据期望的运算顺序选择。例如，减法通常期望左折叠，逗号表达式通常期望左折叠（依次执行从左到右）。

---

### 问题 2：折叠表达式中的 `...` 位置如何记忆？一元折叠中 `...` 在运算符左边还是右边？

**答**：
- 一元左折叠：`(... op pack)` → `...` 在运算符左边，且后面紧跟参数包。
- 一元右折叠：`(pack op ...)` → 参数包在左边，运算符后跟 `...`。

记忆技巧：`...` 出现在哪一侧，就表示将那一侧的东西展开到另一侧。左折叠的 `...` 在左，表示左侧递归展开；右折叠的 `...` 在右，表示右侧递归展开。

---

### 问题 3：如何在折叠表达式中处理空参数包？如何保证空包时程序正确？

**答**：一元折叠对空包通常非法，但逻辑运算符 `&&` 和 `||` 有特例：`(&& ...)` 空包结果为 `true`，`(|| ...)` 结果为 `false`。逗号运算符空包结果为 `void()`。但依赖这些特例可移植性差。

**最佳实践**：使用二元折叠提供初始值，这样空包时直接返回初始值。

```cpp
template<typename... Args>
int sum(Args... args) {
    return (0 + ... + args);   // 空包时返回 0
}
```

---

### 问题 4：折叠表达式能否用于自定义运算符？能否用于函数调用？

**答**：折叠表达式仅支持内置的二元运算符，不能直接用于自定义 `operator+` 或函数调用。但若自定义类型重载了这些运算符（如 `std::string` 的 `+`），折叠表达式会使用重载版本。如果需要类似“对所有元素调用一个函数”，可以用逗号折叠：

```cpp
(f(args), ...);   // 依次调用 f
```

如果需要更复杂的组合（如 `std::min`），可借助 lambda 和三元运算符，但折叠表达式不支持三元，通常用初始化列表替代。

## 典型错误与最佳实践

### ❌ 典型错误

#### 错误 1：对空包使用一元折叠导致编译错误

```cpp
template<typename... Args>
auto sum(Args... args) {
    return (args + ...);   // 如果 args 为空，编译错误
}
sum();  // 错误
```

**修复**：使用二元折叠 `(0 + ... + args)`。

#### 错误 2：混淆左折叠和右折叠导致非预期结果（尤其是减法和除法）

```cpp
auto r = (10 - ... - 1);   // 错误语法？实际应该 (10 - ...) 或 (... - 1)
// 正确：sub_left(10,1) 期望 (10-1)=9，但 sub_right(10,1) 为 (10-1) 相同？因为两个参数时左右折叠等价
// 三个参数时不同
```

#### 错误 3：在逻辑折叠中依赖短路但未考虑参数包可能为空

```cpp
template<typename... Args>
bool all(Args... args) {
    return (true && ... && args);   // 空包返回 true，可能不符合预期
}
all();  // true
```

#### 错误 4：逗号折叠中表达式有副作用但求值顺序未指定

逗号运算符保证从左到右求值，所以 `(f(args), ...)` 是安全的。但如果是 `(args , ...)` 则只返回最后一个参数的值，前面的副作用仍会执行。

---

### ✅ 最佳实践

| 实践 | 说明 |
|------|------|
| **优先使用二元折叠处理可能为空的参数包** | 提供初始值，避免空包问题 |
| **使用左折叠处理逗号表达式** | `(f(args), ...)` 依次执行 |
| **使用左折叠处理加法/乘法等结合律运算** | 与直觉一致 |
| **使用 `&&` 折叠检查所有条件** | `(cond && ... && args)` 可短路 |
| **避免使用一元折叠处理可能为空的包** | 除非明确知道包非空 |
| **复杂逻辑用递归或初始化列表** | 折叠表达式不是万能，不适合非结合律的归约（如求最小值） |

```cpp
// 好例子：安全打印，处理空包
template<typename... Args>
void print(Args... args) {
    ((std::cout << args << ' '), ...);
    std::cout << '\n';
}
print();  // 仅输出换行

// 好例子：使用二元折叠实现字符串连接
template<typename... Args>
std::string join(std::string sep, Args... args) {
    std::string result;
    ((result += args + sep), ...);
    if (!result.empty()) result.resize(result.size() - sep.size());
    return result;
}
```
