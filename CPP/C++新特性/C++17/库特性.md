# C++17 标准库特性全景

C++17 标准库在 C++11/14 基础上进行了大量增强，引入了多个实用组件和算法，显著提升了表达力、性能和代码安全性。本文档覆盖 C++17 中所有主要且常见的库特性，每个特性简要说明并附关键用法。

---

## 特性总览

| 特性 | 一句话描述 |
|------|------------|
| `std::optional` | 可空值容器，表达“可能有值也可能没有” |
| `std::variant` | 类型安全的联合体，存储多种类型之一 |
| `std::any` | 类型擦除容器，可存储任意可拷贝类型 |
| `std::string_view` | 非拥有的只读字符串视图，避免拷贝 |
| `std::filesystem` | 跨平台文件系统操作库 |
| 并行算法 + 执行策略 | 支持多线程并行和向量化的 STL 算法 |
| `std::scoped_lock` | RAII 锁，可同时锁定多个互斥量，避免死锁 |
| `std::shared_mutex` | 读写锁（共享互斥量） |
| `std::apply` | 将 tuple 展开为函数参数 |
| `std::make_from_tuple` | 从 tuple 构造对象 |
| `std::gcd` / `std::lcm` | 最大公约数和最小公倍数 |

| `std::byte` | 字节类型，用于原始内存操作 |

| `std::conjunction` / `std::disjunction` / `std::negation` | 编译期逻辑运算 trait |

| `std::any_cast` 改进 | 更安全的访问 |

## 重点特性详解

### 1. `std::optional`

**一句话定义**：`std::optional<T>` 是一个容器，要么包含一个 `T` 类型的值，要么为空（`std::nullopt`），用于表达“可能没有结果”的语义。

**核心用法**：

```cpp
std::optional<int> parse_int(const std::string& s) {
    try { return std::stoi(s); }
    catch (...) { return std::nullopt; }
}

auto val = parse_int("42");
if (val) {
    std::cout << *val;
} else {
    std::cout << "not a number";
}
```

**底层原理**：存储空间为 `alignas(T) unsigned char buf[sizeof(T)]` + 一个布尔标志，无动态分配。

**面试常问**：与 `unique_ptr` 区别（栈 vs 堆）；`value()` 与 `operator*` 区别（检查异常 vs 无检查）。

---

### 2. `std::variant`

**一句话定义**：`std::variant<Types...>` 是一个类型安全的联合体，在任意时刻存储类型列表中的某一个值。

**核心用法**：

```cpp
std::variant<int, double, std::string> v = "hello";
v = 42;
int i = std::get<int>(v);         // 若当前不是 int 则抛异常
double* d = std::get_if<double>(&v); // 返回 nullptr
std::visit([](auto&& arg) { std::cout << arg; }, v);
```

**底层原理**：存储缓冲区（最大类型大小）+ 类型索引；`std::visit` 使用跳转表 O(1)。

**面试常问**：与 `union` 区别（自动构造/析构、类型安全）；如何存储引用（使用 `std::reference_wrapper`）。

---

### 3. `std::any`

**一句话定义**：`std::any` 可以存储任意可拷贝类型的单个值，类型信息在运行时擦除。

**核心用法**：

```cpp
std::any a = 42;
a = std::string("hello");
if (a.type() == typeid(std::string)) {
    std::string s = std::any_cast<std::string>(a);
}
```

**底层原理**：小对象优化（SBO），对于大类型堆分配；内部使用虚函数表或函数指针管理拷贝/析构。

**面试常问**：与 `variant` 区别（类型集合固定 vs 任意）；性能开销（类型擦除 + 可能堆分配）。

---

### 4. `std::string_view`

**一句话定义**：非拥有的只读字符串视图，指向字符序列，不拷贝数据。

**核心用法**：

```cpp
void log(std::string_view msg) { std::cout << msg; }
log("hello");          // 无分配
std::string s = "world";
log(s);                // 无拷贝
```

**底层原理**：只存储 `const char*` 和 `size_t`，大小 16 字节（64位）。

**面试常问**：与 `const string&` 区别（隐式分配）；生命周期风险（悬垂引用）；`data()` 不保证 `\0` 结尾。

---

### 5. `std::filesystem`

**一句话定义**：跨平台文件系统操作库，提供路径、目录遍历、文件属性等。

**核心用法**：

```cpp
namespace fs = std::filesystem;
fs::path p = "/usr/bin";
p /= "gcc";
if (fs::exists(p)) {
    std::cout << fs::file_size(p);
}
for (auto& entry : fs::directory_iterator(".")) {
    std::cout << entry.path();
}
```

**底层原理**：封装 POSIX 或 Windows API，路径类处理分隔符差异。

**面试常问**：如何遍历目录（`directory_iterator`）；错误处理（异常 vs `error_code`）；符号链接处理。

---

### 6. 并行算法与执行策略

**一句话定义**：为标准算法增加执行策略参数（`seq`、`par`、`par_unseq`），支持多线程并行和 SIMD 向量化。

**核心用法**：

```cpp
#include <execution>
std::vector<int> v(1e7);
std::sort(std::execution::par, v.begin(), v.end());
std::for_each(std::execution::par_unseq, v.begin(), v.end(), [](int& x){ x *= 2; });
```

**底层原理**：依赖底层线程库（如 TBB）和编译器向量化。

**面试常问**：`par` 与 `par_unseq` 区别（后者允许向量化，操作必须无数据竞争且可交错）；何时并行效果差（数据量小、操作轻量）。

---

### 7. `std::scoped_lock`

**一句话定义**：RAII 锁管理器，可同时锁定多个互斥量，避免死锁（使用死锁避免算法）。

**核心用法**：

```cpp
std::mutex m1, m2;
void safe_transfer() {
    std::scoped_lock lock(m1, m2);   // 同时锁定，不会死锁
    // 操作共享数据
}
```

**底层原理**：使用 `std::lock(m1, m2...)` 一次性锁定所有互斥量。

**面试常问**：与 `lock_guard` 区别（`scoped_lock` 支持多个锁且更灵活）。

---

### 8. `std::shared_mutex` 与 `std::shared_lock`

**一句话定义**：读写锁，允许多个读者并发，写者独占。

**核心用法**：

```cpp
std::shared_mutex mtx;
void reader() { std::shared_lock lock(mtx); /* 读 */ }
void writer() { std::unique_lock lock(mtx); /* 写 */ }
```

**底层原理**：通常基于操作系统读写锁（如 POSIX `pthread_rwlock_t`）。

**面试常问**：读写锁适用场景（读多写少）；与 `mutex` 性能对比（读者无竞争时更快）。

---

### 9. `std::apply`

**一句话定义**：将 `std::tuple` 的元素作为参数调用可调用对象。

**核心用法**：

```cpp
auto add = [](int a, int b) { return a + b; };
auto t = std::make_tuple(3, 4);
int result = std::apply(add, t);   // 7
```

**底层原理**：通过 `std::index_sequence` 展开 tuple 元素。

**面试常问**：与 `std::make_from_tuple` 区别（后者构造对象）。

---

### 10. `std::gcd` / `std::lcm` / `std::clamp`

**核心用法**：

```cpp
int g = std::gcd(12, 18);       // 6
int l = std::lcm(12, 18);       // 36
int c = std::clamp(5, 1, 10);   // 5
int c2 = std::clamp(15, 1, 10); // 10
```

**底层原理**：`gcd` 使用欧几里得算法（编译期优化），`clamp` 等价于 `max(min(x, hi), lo)`。

---

### 11. `std::to_chars` / `std::from_chars`

**一句话定义**：高性能、独立于 locale 的数值与字符串转换函数，无动态分配。

**核心用法**：

```cpp
char buf[20];
auto [ptr, ec] = std::to_chars(buf, buf+20, 3.14159);
*ptr = '\0';
std::cout << buf;   // 3.14159

int value;
auto [end, ec2] = std::from_chars(buf, ptr, value);
```

**面试常问**：与 `std::to_string` / `std::stoi` 区别（无 locale 影响、无异常、更快，适合性能敏感代码）。

---

### 12. `std::as_const`

**核心用法**：

```cpp
std::vector<int> v{1,2,3};
auto& ref = std::as_const(v);   // const std::vector<int>&
```

**底层原理**：返回 `static_cast<const T&>(t)`。

**用途**：重载决议中强制选择 const 版本。

---

### 13. `std::byte`

**一句话定义**：枚举类类型，表示原始字节，不进行算术运算（除位运算）。

**核心用法**：

```cpp
std::byte b{0xFF};
b = b << 1;               // 移位允许
// int i = b;             // 错误，不能隐式转换
int i = std::to_integer<int>(b);
```

**底层原理**：底层存储为 `unsigned char`，禁止隐式转换，避免整数算术误用。

---

### 14. `std::pmr` (Polymorphic Memory Resources)

**一句话定义**：提供运行时多态的内存分配器抽象，支持不同分配策略（如池、单调缓冲区等），位于 `<memory_resource>`。

**核心用法**：

```cpp
#include <memory_resource>
std::pmr::vector<int> vec(std::pmr::new_delete_resource());
vec.push_back(42);
```

**底层原理**：`std::pmr::memory_resource` 基类，用户可实现自己的分配器。

**面试常问**：与 `std::allocator` 区别（运行时多态 vs 编译期多态）；应用场景（容器间共享分配器、池化分配）。

## 总结

C++17 标准库大幅增强了 C++ 的表达力和实用性，引入了 `optional`、`variant`、`any`、`string_view`、`filesystem` 等常用工具，以及并行算法、多态内存分配器等高级特性。这些特性不仅简化了代码，还提高了性能和安全性。面试中应重点掌握 `optional`、`variant`、`string_view` 的使用场景、生命周期和性能特点，以及并行算法的正确使用方法。对于日常开发，`std::filesystem` 和 `std::to_chars` 也是极大便利的工具。
