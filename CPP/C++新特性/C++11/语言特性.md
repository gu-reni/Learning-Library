# C++11 主要语言特性全景

C++11 引入了大量语言层面的新特性，显著提升了 C++ 的类型安全、表达力、性能和编码便利性。以下是所有主要且常见的语言特性，按功能分类整理。

---

## 1. `auto` – 类型自动推导

**一句话定义**：`auto` 让编译器根据初始化表达式自动推导变量类型，简化冗长类型名书写，尤其适用于模板和迭代器。

### 语法与用法

```cpp
auto x = 42;               // int
auto y = 3.14;             // double
auto p = &x;               // int*
auto it = vec.begin();     // std::vector<int>::iterator

// const/引用 需要显式标注
const auto& cr = x;        // const int&
auto&& ur = x;             // 万能引用，推导为 int&

// C++14 起 auto 可用于函数返回类型推导
auto add(int a, int b) { return a + b; }
```

### 底层原理

`auto` 使用与模板参数推导相同的规则：去除顶层 const 和引用，数组退化为指针，除非声明为 `auto&`。例如 `auto a = 10; const int& cr = a; auto b = cr;` 推导为 `int`（忽略 const 和引用）。

### 常见陷阱

```cpp
auto v = std::vector<int>{1,2,3};
auto size = v.size();      // size_t，注意有符号/无符号混用

auto f() { return {1,2,3}; } // 错误：不能推导 initializer_list
```

### 最佳实践

- 当类型明显或冗长时使用 `auto`（如迭代器、lambda 类型）
- 需要拷贝时用 `auto`，需要引用时用 `auto&` 或 `const auto&`
- 避免在 API 边界使用 `auto` 返回非显然类型

## 2. `decltype` – 表达式类型查询

**一句话定义**：`decltype` 返回表达式的精确类型（包括引用和 const 限定），常用于模板编程和 `decltype(auto)`（C++14）。

### 语法与用法

```cpp
int x = 0;
decltype(x) a = x;         // int
decltype((x)) b = x;       // int&（加括号产生左值表达式）

struct S { double d; };
decltype(S::d) c = 3.14;   // double

// 与 auto 配合：decltype(auto) 保持引用性
int& get(int& r) { return r; }
decltype(auto) r = get(x); // int&，而不是 int
```

### 底层原理

- 若参数是**未加括号的标识符/类成员访问**，`decltype` 得到该实体的声明类型。
- 若参数是**其他表达式**（如函数调用、加括号变量），`decltype` 得到该表达式的值类别对应的类型：
  - 左值表达式 → `T&`
  - 纯右值 → `T`
  - 将亡值 → `T&&`

### 常见陷阱

```cpp
int* p = &x;
decltype(*p) y = x;        // int&，因为 *p 是左值表达式
```

### 最佳实践

- 在需要精确返回类型时使用 `decltype(auto)`（如转发函数）
- 注意括号的影响：`decltype((var))` 一定是引用

## 3. 右值引用与移动语义（详见独立章节）

简要总结：`&&` 语法、移动构造函数、`std::move`、`std::forward`、完美转发。核心价值：消除不必要的深拷贝。

## 4. Lambda 表达式（详见独立章节）

简要总结：`[capture](params) -> ret { body }`，捕获列表、泛型 lambda（C++14）、`mutable`。核心价值：就地定义函数对象，极大提升 STL 算法和回调的表达力。

---

## 5. `nullptr` – 类型安全的空指针（详见独立章节）

简要总结：`std::nullptr_t` 类型，可隐式转换为任意指针类型，但不能转换为整数，解决 `NULL` 的重载二义性。

---

## 6. `constexpr` – 编译期求值（详见独立章节）

简要总结：编译期常量表达式、`constexpr` 函数（C++11 单行，C++14 放宽）、`constexpr` 构造函数。核心价值：编译期计算，替代宏和模板元编程的部分场景。

---

## 7. 强枚举类型 `enum class`（详见独立章节）

简要总结：作用域限定、类型安全（无隐式转换）、可指定底层类型。核心价值：避免命名污染和意外整数转换。

---

## 8. 初始化列表 `std::initializer_list`（详见独立章节）

简要总结：花括号初始化、统一初始化语法、防止窄化转换。核心价值：容器可像数组一样初始化，统一初始化语法。

---

## 9. 变参模板（详见独立章节）

简要总结：`typename... Args`、参数包、包展开 `...`、`sizeof...`、折叠表达式（C++17）。核心价值：支持任意数量任意类型的模板参数，实现 `tuple`、`function` 等。

## 10. `static_assert` – 编译期断言

**一句话定义**：在编译期检查条件，若为 false 则产生编译错误并输出指定信息，用于验证模板参数、配置等。

### 语法与用法

```cpp
static_assert(sizeof(int) >= 4, "int must be at least 4 bytes");
static_assert(std::is_integral<T>::value, "T must be integral"); // C++11
static_assert(std::is_integral_v<T>, "T must be integral");      // C++17
```

### 底层原理

编译器在编译期求值常量表达式，失败时停止编译并打印错误信息。零运行时开销。

### 最佳实践

- 在模板中检查类型约束（替代 SFINAE 的部分场景）
- 验证编译期常量（如数组大小、结构体布局）

---

## 11. `override` 与 `final` 说明符

**一句话定义**：`override` 显式声明成员函数覆盖基类虚函数，`final` 禁止进一步覆盖或继承。

### 语法与用法

```cpp
struct Base {
    virtual void foo();
    virtual void bar() final;
};

struct Derived : Base {
    void foo() override;      // 正确：覆盖基类虚函数
    // void foo(int) override; // 错误：签名不匹配
    // void bar() override;    // 错误：bar 在 Base 中为 final
};

struct Final final { };       // Final 类不能被继承
```

### 底层原理

`override` 让编译器检查是否存在可覆盖的基类虚函数，避免因签名错误而意外创建新虚函数。`final` 禁止派生类覆盖该函数，可用于优化（devirtualization）。

### 最佳实践

- 所有覆盖基类虚函数的派生类函数都应标注 `override`
- 设计类层次时，考虑将不应被覆盖的函数标记 `final`

## 12. 默认函数与删除函数

**一句话定义**：使用 `= default` 要求编译器生成默认实现（特殊成员函数），使用 `= delete` 禁止某个函数的使用。

### 语法与用法

```cpp
class Widget {
public:
    Widget() = default;                    // 默认构造函数
    Widget(const Widget&) = delete;        // 禁止拷贝构造
    Widget& operator=(const Widget&) = delete;
    ~Widget() = default;
};

void process(int) {}
void process(char) = delete;               // 禁止 char 版本
```

### 底层原理

`= default` 告诉编译器生成与隐式版本完全相同的代码，可用于恢复被用户构造函数抑制的默认构造函数。`= delete` 让函数参与重载但调用时产生编译错误。

### 最佳实践

- 需要禁用拷贝时使用 `= delete`（而非 private 声明）
- 显式要求编译器生成特殊成员函数时用 `= default`
- 删除特定重载（如禁止 double 到 int 的隐式转换）

---

## 13. 委托构造函数

**一句话定义**：一个构造函数可以调用同一个类的另一个构造函数，避免代码重复。

### 语法与用法

```cpp
class Point {
    int x, y;
public:
    Point() : Point(0, 0) {}               // 委托给双参构造函数
    Point(int a) : Point(a, a) {}
    Point(int a, int b) : x(a), y(b) {}
};
```

### 底层原理

编译器将委托构造展开为：首先执行被委托构造函数的初始化列表和函数体，然后执行当前构造函数的函数体（如果有）。注意：不能形成循环委托。

### 常见陷阱

```cpp
Point(int a, int b) : Point(a), y(b) {}    // 错误：不能既委托又初始化成员
```

委托后，当前构造函数的初始化列表不能再初始化其他成员。

### 最佳实践

- 使用委托构造函数减少冗余初始化代码
- 将被委托的构造函数设计为“主构造函数”

---

## 14. 继承构造函数

**一句话定义**：派生类可以通过 `using Base::Base` 直接继承基类的所有构造函数（除默认、拷贝、移动外）。

### 语法与用法

```cpp
struct Base {
    Base(int x) {}
    Base(double d) {}
};

struct Derived : Base {
    using Base::Base;   // 继承 Base(int) 和 Base(double)
    Derived(int x, int y) : Base(x) {} // 自定义构造函数
};

Derived d1(42);        // 调用 Base(int)
Derived d2(3.14);      // 调用 Base(double)
```

### 底层原理

编译器为每个继承的构造函数生成一个派生类版本的构造函数，其参数完美转发给基类构造函数。

### 最佳实践

- 当派生类没有新增成员需要初始化时，使用继承构造函数简化代码
- 注意基类构造函数可能抛出异常，派生类应正确处理

---

## 15. `long long` 与固定宽度整数类型

**一句话定义**：`long long` 保证至少 64 位，`<cstdint>` 提供 `int64_t`、`uint32_t` 等精确宽度类型。

```cpp
long long big = 9223372036854775807LL;
unsigned long long huge = 18446744073709551615ULL;
#include <cstdint>
int32_t i32 = 100;
uint64_t u64 = 1ULL << 60;
```

## 16. 原始字符串字面量

**一句话定义**：`R"delim(content)delim"` 内的内容不做转义，用于正则表达式、文件路径等。

```cpp
std::string path = R"(C:\Program Files\MyApp)";
std::string regex = R"(\d+\.\d+)";  // 无需转义反斜杠
std::string custom = R"delim(Hello "world")delim";
```

---

## 17. 用户定义字面量

**一句话定义**：允许为字面量后缀定义自定义行为，如 `"hello"_s` 返回 `std::string`。

```cpp
std::string operator"" _s(const char* str, size_t len) {
    return std::string(str, len);
}
auto str = "hello"_s;   // std::string

long long operator"" _km(long long x) { return x * 1000; }
auto dist = 5_km;       // 5000
```

### 限制

- 只能用于字面量后缀，不能改变内置字面量的含义
- 后缀以下划线开头（避免与标准库冲突）

---

## 18. `alignof` 与 `alignas`

**一句话定义**：`alignof` 查询类型的对齐要求，`alignas` 指定变量或类型的对齐字节数。

```cpp
int x;
std::cout << alignof(int);           // 通常为 4
alignas(64) double arr[100];         // 按 64 字节对齐
struct alignas(16) Vec4 { float x,y,z,w; };
```

---

## 19. `noexcept` 说明符

**一句话定义**：指定函数不会抛出异常，编译器可进行优化，且移动操作若为 `noexcept` 会被 STL 容器采用。

```cpp
void f() noexcept;                    // 不会抛出
void g() noexcept(true);              // 等价
void h() noexcept(false);             // 可能抛出

// 条件 noexcept
template<typename T>
void swap(T& a, T& b) noexcept(noexcept(T(std::move(a))));
```

### 底层原理

`noexcept` 违反时会调用 `std::terminate`（而非栈回溯）。编译器可生成更高效的代码（如不记录异常处理信息）。

---

## 20. `thread_local` 存储期

**一句话定义**：每个线程拥有独立的变量实例，生命周期与线程相同。

```cpp
thread_local int counter = 0;   // 每个线程独立
void inc() { ++counter; }
```

---

## 21. 范围 for 循环（Range-based for）

**一句话定义**：简洁遍历容器或数组的语法。

```cpp
std::vector<int> v = {1,2,3};
for (int x : v) std::cout << x;
for (auto& x : v) x *= 2;
for (const auto& x : v) std::cout << x;
```

### 底层原理

等价于：
```cpp
for (auto it = begin(v); it != end(v); ++it) {
    int x = *it;
}
```

---

## 22. 显式转换运算符

**一句话定义**：用 `explicit` 修饰类型转换运算符，禁止隐式转换。

```cpp
struct SafeBool {
    explicit operator bool() const { return true; }
};
SafeBool sb;
if (sb) { ... }        // OK：显式使用 bool 上下文
// bool b = sb;        // 错误：需要显式转换
```

---

## 总结

C++11 的语言特性围绕以下核心目标设计：
- **类型安全**：`nullptr`、强枚举、`explicit` 转换运算符
- **泛型增强**：变参模板、`decltype`、`auto`、继承/委托构造函数
- **性能优化**：右值引用与移动语义、`constexpr`、`noexcept`
- **代码简洁**：lambda、范围 for、初始化列表、原始字符串
- **编译期编程**：`static_assert`、`alignof`/`alignas`

这些特性奠定了现代 C++ 的基础，后续标准（C++14/17/20）在此基础上进一步增强。
