# C++11 主要库特性全景

C++11 标准库引入了大量新组件，极大地提升了 C++ 的表达力、安全性和性能。以下是所有主要且常见的库特性，按功能分类整理。

---

## 1. 智能指针

| 特性 | 说明 |
|------|------|
| `std::unique_ptr` | 独占所有权智能指针，不可拷贝，可移动 |
| `std::shared_ptr` | 共享所有权智能指针，引用计数 |
| `std::weak_ptr` | 弱引用，配合 `shared_ptr` 打破循环引用 |
| `std::make_shared` | 单次分配创建 `shared_ptr` 和管理对象 |
| `std::make_unique`（C++14） | 创建 `unique_ptr`（C++11 缺失，C++14 补入） |
| `std::default_delete` | 默认删除器 |

**核心价值**：RAII 自动管理动态资源，彻底解决内存泄漏和悬垂指针。

---

## 2. 并发库

| 特性 | 说明 |
|------|------|
| `std::thread` | 跨平台线程管理 |
| `std::mutex` / `std::recursive_mutex` / `std::timed_mutex` | 互斥锁 |
| `std::lock_guard` / `std::unique_lock` | RAII 锁管理 |
| `std::condition_variable` | 条件变量 |
| `std::atomic` | 原子类型（支持整型、指针、自定义类型） |
| `std::future` / `std::promise` | 异步任务结果传递 |
| `std::shared_future` | 可多线程等待的 future |
| `std::async` | 异步执行函数 |
| `std::packaged_task` | 包装可调用对象为异步任务 |
| `std::once_flag` / `std::call_once` | 单次初始化 |
| `std::this_thread` 命名空间 | `yield`、`sleep_for`、`sleep_until`、`get_id` |

**核心价值**：标准化的多线程支持，跨平台且类型安全。

---

## 3. 元编程与类型特征

| 特性 | 说明 |
|------|------|
| `<type_traits>` | 编译期类型查询和变换（`is_integral`、`remove_const`、`enable_if` 等 100+ 特征） |
| `std::integral_constant` | 编译期常量包装 |
| `std::true_type` / `std::false_type` | 布尔常量类型 |
| `std::conditional` | 编译期条件类型选择 |
| `std::decay` | 模拟传值时的类型退化 |
| `std::declval` | 获得类型右值引用，用于 decltype 表达式 |

**核心价值**：支持模板元编程、SFINAE、概念模拟（C++20 前），标准库自身实现的基础。

---

## 4. 元组与变参模板相关

| 特性 | 说明 |
|------|------|
| `std::tuple` | 固定大小异构值集合 |
| `std::make_tuple` / `std::tie` | 创建元组和引用元组 |
| `std::tuple_cat` | 连接多个元组 |
| `std::tuple_size` / `std::tuple_element` | 查询元组大小和元素类型 |
| `std::get`（按索引/按类型） | 访问元组元素 |
| `std::ignore` | 占位符，用于 `tie` 忽略元素 |

**核心价值**：泛化 `std::pair`，支持多返回值、编译期列表操作。

---

## 5. 正则表达式

| 特性 | 说明 |
|------|------|
| `std::regex` | 正则表达式对象 |
| `std::smatch` / `std::cmatch` | 匹配结果（string/char 数组） |
| `std::regex_match` | 全文匹配 |
| `std::regex_search` | 搜索子串 |
| `std::regex_replace` | 替换 |
| `std::regex_iterator` / `std::regex_token_iterator` | 迭代器遍历所有匹配 |

**核心价值**：内置正则引擎，避免依赖 Boost.Regex。

---

## 6. 随机数生成器

| 特性 | 说明 |
|------|------|
| 随机数引擎：`std::mt19937`（梅森旋转）、`std::linear_congruential_engine`、`std::subtract_with_carry_engine` | 伪随机数生成 |
| 适配器：`std::shuffle_order_engine`、`std::independent_bits_engine` | 增强引擎 |
| 分布器：`std::uniform_int_distribution`、`std::normal_distribution`、`std::bernoulli_distribution` 等 20+ 种 | 将引擎输出映射到特定分布 |
| `std::random_device` | 非确定性随机数（如果可用） |
| `std::seed_seq` | 种子序列生成器 |

**核心价值**：替代 C 标准库的 `rand()`，提供可预测、高质量、分布可控的随机数。

---

## 7. 时间库（`<chrono>`）

| 特性 | 说明 |
|------|------|
| `std::chrono::duration` | 时长（如 `seconds`、`milliseconds`） |
| `std::chrono::time_point` | 时间点 |
| 时钟：`system_clock`、`steady_clock`、`high_resolution_clock` | 获取当前时间 |
| `std::chrono::duration_cast` / `time_point_cast` | 单位转换 |
| 用户定义字面量：`10ms`、`5s`、`100us` | C++14 支持 |

**核心价值**：类型安全的时间运算，跨平台精度可控，用于超时、性能测量等。

---

## 8. 容器改进

| 特性 | 说明 |
|------|------|
| `std::array<T, N>` | 固定大小数组，STL 容器接口，零开销 |
| `std::forward_list` | 单向链表 |
| `std::unordered_set` / `std::unordered_map` | 哈希表（无序关联容器） |
| `std::unordered_multiset` / `std::unordered_multimap` | 允许重复键的哈希表 |
| `emplace` / `emplace_back` / `emplace_front` / `emplace_hint` | 原地构造元素，避免临时对象拷贝 |
| `std::vector::shrink_to_fit` | 请求释放多余容量 |
| `std::map::at` | 带边界检查的访问 |
| 移动语义支持 | 容器移动构造、移动赋值，性能提升 |
| `std::begin` / `std::end` 非成员函数 | 支持数组和容器的统一迭代器获取 |
| `std::cbegin` / `std::cend`（C++14） | 获取 const 迭代器 |

**核心价值**：补充了 C++98 缺失的常用容器，性能关键操作支持移动语义。

---

## 9. 算法改进

| 特性 | 说明 |
|------|------|
| `std::move` / `std::move_backward` | 移动元素 |
| `std::copy_if` | 条件拷贝 |
| `std::iota` | 填充递增序列 |
| `std::shuffle` | 随机重排（替代 C++98 的 `random_shuffle`） |
| `std::is_partitioned` / `std::partition_copy` / `std::partition_point` | 分区操作 |
| `std::all_of` / `std::any_of` / `std::none_of` | 范围条件检查 |
| `std::find_if_not` | 反向查找 |
| `std::minmax` / `std::minmax_element` | 同时返回最小最大值 |
| `std::is_sorted` / `std::is_sorted_until` | 排序检查 |
| `std::is_heap` / `std::is_heap_until` | 堆检查 |

**核心价值**：补齐了常用算法，使标准算法库更完整。

---

## 10. 函数包装与绑定

| 特性 | 说明 |
|------|------|
| `std::function` | 可调用对象包装器（函数、函数指针、lambda、仿函数） |
| `std::bind` | 绑定参数（部分求值），支持占位符 `_1`、`_2` 等 |
| `std::ref` / `std::cref` | 将引用包装为可拷贝对象，用于 `std::bind` |

**核心价值**：类型擦除的可调用对象，支持回调、策略模式等。注意 C++11 后 lambda 更常用，但 `std::function` 仍有不可替代性。

---

## 11. 字符串与字符转换

| 特性 | 说明 |
|------|------|
| `std::to_string` | 数值转字符串（int、long、double 等） |
| `std::stoi` / `std::stol` / `std::stod` 等 | 字符串转数值 |
| `std::to_wstring` | 宽字符串转换 |

**核心价值**：避免使用 `sprintf` 或 `stringstream` 的繁琐，提供简单转换。

## 总结

C++11 的库特性围绕以下核心目标设计：
- **资源安全**：智能指针、RAII 锁
- **并发支持**：线程、原子、future
- **泛型增强**：tuple、type_traits、正则、随机数
- **性能优化**：移动语义、emplace、unordered 容器
- **表达力提升**：lambda（虽为语言特性，但配合库）、initializer_list

以上列表涵盖了 C++11 标准库中所有主要且常见的组件，是面试和日常开发的核心知识。对于每个具体特性，可参考此前生成的深度文档进行深入学习。
