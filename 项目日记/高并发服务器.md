# 问题：一
```cpp
#include <iostream>

#include <cstring>

#include <unistd.h>

#include <sys/socket.h>

#include <netinet/in.h>

#include <arpa/inet.h>

  
  
  

int main(){

    std::cout << "Server starting..." << std::endl;

    int listen_fd=socket(AF_INET,SOCK_STREAM,0);

    if(listen_fd<0){

        std::cerr<<"Failed to create socket"<<std::endl;

        return 1;

    }

    std::cout << "Socket created successfully, fd = " << listen_fd << std::endl;

    close(listen_fd);

    return 0;

}
```
问题：
```bash
ubuntu_user@codeubuntu:~/shared_files/code/CPP$ ./tcp_server 
Server starting...
Socket created successfully, fd = 3
```
**为什么fd=3**
原因：
因为文件描述符 0、1、2 已经被系统预先占用：
- **0**：标准输入（stdin）
- **1**：标准输出（stdout）
- **2**：标准错误（stderr）
当程序调用 `socket()` 创建第一个套接字时，系统会分配当前可用的最小未使用文件描述符，即 **3**。
