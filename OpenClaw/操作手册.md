## 📚 第一部分：部署前必读

  

### 1.1 OpenClaw 是什么？

  

OpenClaw（曾用名 Clawdbot/Moltbot）是一个**开源的个人 AI 助理**，可以部署在你自己的设备上。

  

**它能帮你做什么？**

- ✅ 通过自然语言理解指令

- ✅ 处理文件、编写代码

- ✅ 控制浏览器自动操作

- ✅ 对接微信/Telegram/Discord 等聊天软件

- ✅ 定时任务自动化

- ✅ 数据完全本地，隐私可控

  

**核心优势**：数据隐私可控 + 执行能力强 + 完全开源

  

### 1.2 部署方案怎么选？

  

| 方案             | 适用人群                 | 优势                    | 劣势                | 费用      |
| -------------- | -------------------- | --------------------- | ----------------- | ------- |
| **Windows 本地** | 个人使用，有 Windows 电脑    | 数据本地，无需额外费用           | 电脑需开机，关机服务停止      | 免费      |
| **macOS 本地**   | Mac 用户               | 体验流畅，与系统集成好           | 依赖较多，需安装 Homebrew | 免费      |
| **Linux 本地**   | 熟悉 Linux 的用户/开发者     | 兼容性最好，性能最优            | 需熟悉终端操作           | 免费      |
| **阿里云部署**      | ⭐新手首选，部署完之后可 24 小时在线 | 无需维护，7×24 小时运行，支持远程访问 | 需支付服务器费用          | 38 元/年起 |

## 🪟 第二部分：Windows 11 本地部署

  

### 2.1 前期准备

  

| 项目  | 要求                        | 检查方法                     |
| --- | ------------------------- | ------------------------ |
| 系统  | Windows 11 (build 26200+) | 按 `Win+R` 输入 `winver` 回车 |
| 内存  | ≥8GB（推荐 16GB）             | 任务管理器 → 性能 → 内存          |
| 磁盘  | 至少 5GB 可用空间               | 此电脑 → 查看剩余空间             |
| 权限  | 管理员账户                     | 能运行"管理员：PowerShell"      |

  

### 2.2 步骤 1：解锁 PowerShell 执行权限

  

**⚠️ 必须用管理员身份运行！**

  

1. 按下键盘 `Win + X` 键

2. 选择 **"Windows PowerShell（管理员）"** 或 **"终端（管理员）"**

3. 确认标题栏显示 **"管理员：Windows PowerShell"**

  

```powershell

# 复制粘贴以下命令，按回车执行

Set-ExecutionPolicy RemoteSigned -Scope CurrentUser

```

  

4. 提示时输入 `Y` 确认

  

**✅ 验证**：看到 `执行策略已成功更改为 RemoteSigned` 即成功

  

### 2.3 步骤 2：安装 Node.js 和 Git

  

```powershell

# === 1. 下载 Node.js 安装包（国内镜像，速度更快）===

iwr -useb https://npmmirror.com/mirrors/node/v22.10.0/node-v22.10.0-x64.msi -OutFile node-install.msi

  

# === 2. 安装 Node.js（会弹出安装窗口）===

# ⚠️ 重要：安装时务必勾选 "Add to PATH"（添加到环境变量）

Start-Process .\node-install.msi -Wait

  

# === 3. 安装 Git ===

winget install Git.Git

  

# === 4. 配置 npm 国内镜像（加速下载）===

npm config set registry https://registry.npmmirror.com

```

  

**安装完成后验证**：

  

```powershell

node --version    # 应显示 v22.x.x

git --version     # 应显示 2.40.x 及以上

npm --version     # 应显示 v10.x.x 及以上

```

  

**❌ 如果报错"不是内部或外部命令"**：

1. 关闭 PowerShell

2. 重新打开 PowerShell（管理员）

3. 再次运行验证命令

  

### 2.4 步骤 3：一键安装 OpenClaw

  

```powershell

# 官方安装脚本（推荐）

iwr -useb https://openclaw.ai/install.ps1 | iex

```

  

**等待提示**：

- 安装过程约 5-10 分钟

- 看到 `Installation complete` 即完成

- 如遇到红色错误，见第九部分排查

  

**验证安装**：

  

```powershell

openclaw --version    # 应显示 2026.x.x 版本号

```

  

### 2.5 步骤 4：初始化配置向导

  

```powershell

# === 1. 创建工作目录（建议非系统盘）===

mkdir C:\OpenClaw-Workspace

cd C:\OpenClaw-Workspace

  

# === 2. 启动初始化向导 ===

openclaw onboard --install-daemon

```

  

**按提示选择（新手照抄）**：

  
| 提示                                                            | 操作                    |
| ------------------------------------------------------------- | --------------------- |
| I understand this is powerful and inherently risky. Continue? | 输入 `Y` 回车             |
| Onboarding mode                                               | 直接回车（选 QuickStart）    |
| Model/auth provider                                           | 直接回车（选 Skip for now）  |
| Select channel                                                | 直接回车（选 Skip for now）  |
| Configure skills now?                                         | 输入 `N` 回车             |
| Enable hooks?                                                 | 按空格选中，回车              |
| How do you want to hatch your bot?                            | 直接回车（选 Do this later） |

  

### 2.6 步骤 5：配置网关服务并启动

  

```powershell

# 设置网关模式为本地

openclaw config set gateway.mode local

  

# 安装为系统服务（开机自动启动）

openclaw gateway install

  

# 启动网关服务

openclaw gateway start

```

  

**验证服务状态**：

  

```powershell

openclaw gateway status    # 应显示 Running

```

  

### 2.7 步骤 6：访问 Web 控制台

  

1. 打开浏览器（Chrome/Edge 推荐）

2. 输入地址：`http://127.0.0.1:18789`

3. 看到 OpenClaw 登录界面 = 成功！🎉

  

**❌ 如果页面打不开**：

```powershell

# 检查服务状态

openclaw gateway status

  

# 如未运行，重新启动

openclaw gateway start

```

## 🍎 第三部分：macOS 本地部署

  

### 3.1 前期准备

  

| 项目  | 要求                 | 检查方法           |
| --- | ------------------ | -------------- |
| 系统  | macOS 12 Monterey+ | 左上角苹果菜单 → 关于本机 |
| 内存  | ≥8GB               | 关于本机 → 内存      |
| 磁盘  | 至少 5GB 可用空间        | 关于本机 → 存储空间    |

  

### 3.2 步骤 1：安装 Homebrew

  

打开 **终端**（Terminal），粘贴以下命令：

  

```bash

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

```

  

**按提示操作**：

1. 输入电脑开机密码（输入时不显示，正常）

2. 等待安装完成（约 3-5 分钟）

  

**验证**：

  

```bash

brew --version    # 应显示 Homebrew 4.x.x

```

  

### 3.3 步骤 2：安装 Node.js 和 Git

  

```bash

# 安装 Node.js 22.x 和 Git

brew install node@22 git

  

# 配置环境变量（让终端能找到 node 命令）

echo 'export PATH="/opt/homebrew/opt/node@22/bin:$PATH"' >> ~/.zshrc

source ~/.zshrc

  

# 配置 npm 国内镜像

npm config set registry https://registry.npmmirror.com

```

  

**验证**：

  

```bash

node --version    # v22.x.x

git --version     # 2.40.x+

npm --version     # 10.x.x+

```

  

### 3.4 步骤 3：一键安装 OpenClaw

  

```bash

curl -fsSL https://openclaw.ai/install.sh | bash -s -- -Tag beta

```

  

**验证**：

  

```bash

openclaw --version

```

  

### 3.5 步骤 4：初始化配置向导

  

```bash

# 创建工作目录

mkdir ~/OpenClaw-Workspace

cd ~/OpenClaw-Workspace

  

# 启动初始化向导

openclaw onboard --install-daemon

```

  

**选项选择**：与 Windows 部分相同，全部默认跳过

  

### 3.6 步骤 5：配置网关并启动

  

```bash

# 设置网关模式

openclaw config set gateway.mode local

  

# 安装为服务（可选，开机自启）

sudo openclaw gateway install

  

# 启动网关

openclaw gateway start

```

  

### 3.7 步骤 6：访问控制台

  

浏览器打开：`http://127.0.0.1:18789`

### 5.1 步骤 1：购买阿里云轻量应用服务器

  

**🔗 访问地址**：https://www.aliyun.com/activity/ecs/clawdbot

  

**操作步骤**：

  

1. 登录阿里云账号（没有先注册）

2. 点击 **"一键购买并部署"**

3. 配置服务器参数（照抄）：

  

| 配置项 | 选择                           |
| --- | ---------------------------- |
| 镜像  | 应用镜像 → 搜索 "OpenClaw" → 选最新版本 |
| 地域  | 中国香港（内地联网受限）或 美国弗吉尼亚         |
| 规格  | 2 核 2G（新用户 38 元/年起）          |
| 时长  | 1 个月（体验）或 1 年（划算）            |

  

4. 点击 **立即购买**，完成支付

  

### 5.2 步骤 2：等待自动部署

  

- 支付完成后等待 3-5 分钟

- 进入 **轻量应用服务器控制台**

- 看到实例状态为 **"运行中"** 即可

  

### 5.3 步骤 3：获取阿里云百炼 API Key

  

1. 访问：https://bailian.console.aliyun.com/

2. 左侧菜单：**密钥管理** → **创建 API-Key**

3. 复制生成的 API Key（格式：`sk-xxxxxxxx`）

4. **⚠️ 务必保存好**，后续要用

  

### 5.4 步骤 4：配置 OpenClaw（纯点击）

  

回到 **轻量应用服务器控制台** → 找到实例 → 点击 **"应用详情"**：

  

| 操作         | 步骤                                 |
| ---------- | ---------------------------------- |
| 放行端口       | 找到"端口放通" → 点击"执行命令"                |
| 配置 API Key | 找到"配置百炼 API-Key" → 粘贴 API Key → 确认 |
| 生成 Token   | 找到"生成访问 Token" → 复制 Token          |

  

### 5.5 步骤 5：登录使用

  

1. 复制服务器的 **公网 IP**

2. 浏览器打开：`http://你的公网IP:18789/?token=你复制的Token`

3. 看到聊天界面 = 成功！🎉

## 🔧 第六部分：配置阿里云百炼大模型

  

### 6.1 获取 API Key（如已获取可跳过）

  

1. 登录：https://bailian.console.aliyun.com/

2. 左侧：**密钥管理** → **创建 API-Key**

### 6.2 本地部署用户配置

  

```bash

# 编辑配置文件

vim ~/.openclaw/openclaw.json

```

  

**添加/修改以下内容**：

  

```json

{

  "models": {

    "mode": "merge",

    "providers": {

      "bailian": {

        "baseUrl": "https://dashscope.aliyuncs.com/compatible-mode/v1",

        "apiKey": "你的 API-KEY",

        "api": "openai-completions",

        "models": [

          {

            "id": "qwen3.5-plus",

            "name": "qwen3.5-plus",

            "reasoning": false,

            "input": ["text", "image"],

            "contextWindow": 1000000,

            "maxTokens": 65536

          }

        ]

      }

    }

  },

  "agents": {

    "defaults": {

      "model": {

        "primary": "bailian/qwen3.5-plus"

      }

    }

  }

}

```

  

**地域选择**：

  

| 服务器地域 | baseUrl                                                  |
| ----- | -------------------------------------------------------- |
| 中国内地  | `https://dashscope.aliyuncs.com/compatible-mode/v1`      |
| 新加坡   | `https://dashscope-intl.aliyuncs.com/compatible-mode/v1` |
| 美国    | `https://dashscope-us.aliyuncs.com/compatible-mode/v1`   |

  

**保存后重启**：

  

```bash

openclaw gateway restart

```

## 🗑️ 第八部分：完全卸载指南

  

### 8.1 Windows 完全卸载

  

```powershell

# === 1. 停止并删除服务 ===

openclaw gateway stop

openclaw gateway uninstall

  

# === 2. 卸载 OpenClaw ===

npm uninstall -g openclaw

  

# === 3. 删除配置和数据目录 ===

Remove-Item -Recurse -Force $env:USERPROFILE\.openclaw

Remove-Item -Recurse -Force C:\OpenClaw-Workspace

  

# === 4. 删除 Node.js（可选）===

# 控制面板 → 程序和功能 → 卸载 Node.js

  

# === 5. 删除 Git（可选）===

# 控制面板 → 程序和功能 → 卸载 Git

  

# === 6. 清理环境变量 ===

# 系统属性 → 高级 → 环境变量

# 删除 Path 中的 Node.js 和 Git 相关条目

  

# === 7. 验证卸载 ===

openclaw --version    # 应显示"命令未找到"

```

  

### 8.2 macOS 完全卸载

  

```bash

# === 1. 停止并删除服务 ===

openclaw gateway stop

openclaw gateway uninstall

  

# === 2. 卸载 OpenClaw ===

npm uninstall -g openclaw

# === 4. 删除 Node.js（可选）===

# === 5. 删除 Git（可选）===

brew uninstall git

  

# === 6. 清理 Homebrew ===

brew cleanup

  

# === 7. 验证卸载 ===

openclaw --version    # 应显示"command not found"

```

## ❓ 第九部分：常见问题排查

  

### Q1：网页打不开 / 显示无法访问

  

**症状**：浏览器访问 `http://127.0.0.1:18789` 显示无法连接

  

**排查步骤**：

  

```powershell

# 1. 检查服务状态

openclaw gateway status

  

# 2. 如未运行，启动服务

openclaw gateway start

  

# 3. 查看日志

openclaw logs

  

# 4. 检查端口占用

netstat -ano | findstr 18789

```

  

**解决方案**：

  

| 原因 | 解决方法 |

|------|----------|

| 服务未启动 | `openclaw gateway start` |

| 端口被占用 | 修改配置文件换端口 |

| 防火墙拦截 | 关闭防火墙或添加规则 |

| 配置错误 | 检查 `~/.openclaw/openclaw.json` |

  

### Q2：AI 不回复 / 报错

  

**症状**：发送消息后无响应或报错

  

**排查步骤**：

  

1. 检查 API Key 是否正确配置

2. 检查阿里云账户余额

3. 查看日志：`openclaw logs`

  

**解决方案**：

  

```bash

# 重新配置 API Key

openclaw config set models.providers.bailian.apiKey "你的新 Key"

  

# 重启服务

openclaw gateway restart

```

  

### Q3：联网搜索失败

  

**症状**：搜索功能报错或无结果

  

**原因**：服务器在中国内地（联网功能受限）

  

**解决方案**：

- 更换服务器地域至香港或海外

- 或使用本地部署 + 代理

  

### Q4：命令找不到（command not found）

  

**症状**：运行 `openclaw` 提示命令不存在

  

**解决方案**：

  

**Windows**：

```powershell

# 重启 PowerShell

# 如仍不行，重新安装

npm install -g openclaw

```

  

**Mac/Linux**：

```bash

# 重新加载配置

source ~/.zshrc    # 或 source ~/.bashrc

  

# 如仍不行，重新安装

npm install -g openclaw

```

  

### Q5：服务启动后立即退出

  

**症状**：`openclaw gateway start` 后服务马上停止

  

**排查步骤**：

  

```bash

# 1. 查看日志

openclaw logs

  

# 2. 检查配置文件

cat ~/.openclaw/openclaw.json

  

# 3. 前台运行看错误

openclaw gateway --port 18789

```

  

**常见原因**：

- JSON 格式错误（缺少逗号、括号不匹配）

- 端口被占用

- API Key 配置错误

  

### Q6：安装过程卡住/超时

  

**症状**：安装脚本运行到一半卡住

  

**解决方案**：

  

```powershell

# Windows：使用国内镜像

npm config set registry https://registry.npmmirror.com

iwr -useb https://openclaw.ai/install.ps1 | iex

  

# Mac/Linux：使用国内镜像

npm config set registry https://registry.npmmirror.com

curl -fsSL https://openclaw.ai/install.sh | bash

```

  

### Q7：权限不足错误

  

**症状**：提示 `Permission denied` 或 `EACCES`

  

**解决方案**：

  

**Windows**：

- 确保用 **管理员身份** 运行 PowerShell

  

**Mac/Linux**：

```bash

# 使用 sudo

sudo npm install -g openclaw

  

# 或修复权限

sudo chown -R $(whoami) /usr/local/lib/node_modules

```
