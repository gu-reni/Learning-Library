## 🧠 各模块说明

### 1. AI / OpenClaw
OpenClaw 是一个 AI 工具，这里记录了部署和使用手册，包括如何抓取网页内容等实践案例。

### 2. CPP / 头文件
这是核心知识库，系统整理了 C/C++ 编程中涉及的各种头文件及其功能分类：

- **C 标准库**：按功能模块（输入输出、字符串、数学、时间、错误处理等）分别介绍，并提供“总介绍”概括。
- **C++ STL**：涵盖容器、算法、迭代器、字符串、输入输出、并发、智能指针等，每个模块都有独立文档。
- **Linux 环境**：
  - **POSIX 系统编程**：通用接口，包括文件 I/O、网络编程、进程线程、信号处理等。
  - **Linux 特有接口**：epoll、signalfd/eventfd/timerfd、cgroups、命名空间等高性能或容器相关接口。
- **Windows 环境**：Windows API 核心、Winsock、文件与注册表、同步机制、图形界面等。

所有分类都附有“总介绍”文档，便于快速了解该模块的全貌。

### 3. Leetcode
LeetCode 经典题目的题解，每道题一个 `.md` 文件，包含思路、代码和复杂度分析。

### 4. LinuxStudy
Linux 系统学习笔记，分为基础、C/C++ 开发入门、高级全栈开发三个子目录（具体内容待后续补充）。

### 5. Windows / Windows基础详解
Windows 系统知识手册，涵盖操作系统概述、文件系统、注册表、系统管理工具、安全机制、维护优化、故障排除等，并附有快捷键和常用命令附录。
