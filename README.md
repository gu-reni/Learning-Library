## 🧠 各模块说明

### 1. AI / OpenClaw
OpenClaw 是一个 AI 工具，这里记录了部署和使用手册，包括如何抓取网页内容等实践案例。

### 2. CPP
#### 2.1 头文件
系统整理了 C/C++ 编程中涉及的各种头文件及其功能分类：

- **C++ 标准库**：全面文档，包含 C 标准库、STL 核心组件、扩展库，并提供总介绍。
  - **标准库**：C 标准库各模块（输入输出、字符串、数学、时间、内存管理、错误处理等）。
  - **STL 核心组件**：容器、迭代器、算法、函数对象、适配器、分配器。
  - **扩展库**：字符串、输入输出、并发、数值、时间、文件系统等现代 C++ 组件。
- **Linux 环境**：
  - **POSIX 系统编程**：通用标准接口，包括文件 I/O、网络编程、进程线程、信号处理等。
  - **Linux 特有接口**：epoll、signalfd/eventfd/timerfd、cgroups、命名空间等高性能或容器相关接口。
- **Windows 环境**：Windows API 核心、Winsock、文件与注册表、同步机制、图形界面等。

所有分类均附有“总介绍”文档，便于快速了解该模块的全貌。

#### 2.2 C++ 新特性
按 C++ 标准版本（C++11 到 C++26）整理了各版本引入的核心语言与标准库新特性。每个特性文档包含语法示例、典型场景、与旧版本的对比及注意事项，适合快速回顾或面试准备。

- **C++11**：移动语义、lambda、智能指针、并发库、`auto`、范围 for、`constexpr` 等（必须掌握）。
- **C++14**：泛型 lambda、变量模板、二进制字面量等（C++11 的完善）。
- **C++17**：结构化绑定、`if`/`switch` 初始化、折叠表达式、文件系统库、`std::optional`/`variant`/`any`、`std::string_view`、并行算法等（企业主流）。
- **C++20**：概念、协程、范围、三路比较、模块、`std::format`、`std::span` 等（前沿项目逐渐采用）。
- **C++23**：`std::print`、`std::expected`、`std::mdspan`、`deducing this` 等（新特性预览）。
- **C++26**：编译时反射、契约、`std::simd`、模式匹配、`std::execution` 等（未来趋势）。
