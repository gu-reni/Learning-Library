## 🚀 核心项目亮点

### 1. 高并发 TCP 服务器

- **位置**：`LinuxStudy/Linux C++开发编程入门/网络编程/高并发服务器.md`
- **技术栈**：C、epoll（边缘触发）、非阻塞 I/O、多端口轮询、系统调优
- **成果**：在虚拟机环境下实现 **7 万长连接稳定运行**，深入分析了文件描述符上限、端口范围、TIME_WAIT 等系统瓶颈

### 2. OpenClaw 智能助手实践
- **位置**：`AI/OpenClaw/`
- **内容**：从零部署 OpenClaw 服务，配置 Nginx 反向代理与 HTTPS，实现公网访问；开发网页抓取技能，探索 AI 工程化落地

### 3. 网络编程系列
- 包含 **DNS 请求器（UDP）**、**HTTP 客户端**、**多线程 TCP 服务器** 以及 **epoll 版 TCP 服务器**，覆盖了网络编程的主要模型

### 4. Linux 系统知识体系
- 从命令分类到内核编译，形成了完整的 Linux 知识图谱，每章均包含原理、实践与常见问题解决

- 夯实 C++ 与 Linux 系统编程基础，深入理解操作系统底层机制

- 积累项目实战经验，为后端开发实习及全职岗位做好准备
- 探索 AI 工程化方向，尝试将 AI 能力与传统后端结合
