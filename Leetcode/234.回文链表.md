# 题目

给你一个单链表的头节点 `head` ，请你判断该链表是否为回文链表。如果是，返回 `true`；否则，返回 `false`。

**示例 1：**

**输入：** `head = [1,2,2,1]`
**输出：** `true`

**示例 2：**

**输入：** `head = [1,2]`
**输出：** `false`

**提示：**

- 链表中节点数目在范围 `[1, 10^5]` 内
- `0 <= Node.val <= 9`

**进阶：** 你能否用 `O(n)` 时间复杂度和 `O(1)` 空间复杂度解决此题？

# 解题思路与代码实现

## 方法一：数组 + 双指针（直观法）
将链表节点值依次复制到数组中，然后使用双指针判断数组是否为回文。

*   **思路**：
    1.  遍历链表，将每个节点的值存入 `vector<int>`。
    2.  使用左右指针 `left` 和 `right` 分别指向数组首尾，向中间移动并比较值是否相等。
    3.  若所有对应值相等，返回 `true`；否则返回 `false`。
*   **复杂度**：时间复杂度 O(n)，空间复杂度 O(n)。
*   **缺点**：需要额外 O(n) 空间，不满足进阶要求。

```cpp
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */
class Solution {
public:
    bool isPalindrome(ListNode* head) {
        vector<int> vals;
        ListNode* cur = head;
        while (cur) {
            vals.push_back(cur->val);
            cur = cur->next;
        }
        int left = 0, right = vals.size() - 1;
        while (left < right) {
            if (vals[left] != vals[right]) return false;
            ++left;
            --right;
        }
        return true;
    }
};
```

## 方法二：递归（隐式栈）
利用递归调用栈的后进先出特性，将链表节点值压入栈，在回溯时与正向遍历比较。

*   **思路**：
    1.  定义递归函数 `check(ListNode* cur)`，其参数为当前节点，同时维护一个外部指针 `front` 指向链表头。
    2.  递归深入直到链表末尾，然后回溯时比较 `front->val` 与当前节点 `cur->val`，并移动 `front`。
    3.  若所有比较相等则返回 `true`，否则返回 `false`。
*   **复杂度**：时间复杂度 O(n)，空间复杂度 O(n)（递归栈深度）。
*   **缺点**：链表过长可能栈溢出，且空间复杂度不满足进阶要求。

```cpp
class Solution {
public:
    ListNode* front;
    bool check(ListNode* cur) {
        if (cur == nullptr) return true;
        if (!check(cur->next)) return false; // 递归深入
        if (front->val != cur->val) return false;
        front = front->next;
        return true;
    }
    bool isPalindrome(ListNode* head) {
        front = head;
        return check(head);
    }
};
```

## 方法三：快慢指针 + 反转链表（最优解）
先找到链表的中点，反转后半部分链表，然后比较前后两部分是否相同。

*   **思路**：
    1.  使用快慢指针找到链表的中点（慢指针每次走一步，快指针每次走两步）。当快指针到达末尾时，慢指针指向中间节点（若链表长度为奇数，慢指针指向正中间；为偶数，指向后半部分的第一个节点）。
    2.  反转后半部分链表（从慢指针开始）。
    3.  用两个指针分别指向链表头 `head` 和反转后的后半部分头 `mid`，逐个比较节点值。若全部相同，则是回文。
    4.  （可选）恢复链表原状：再次反转后半部分并拼接回去。题目未要求，但若需要保持原结构可恢复。
*   **复杂度**：时间复杂度 O(n)，空间复杂度 O(1)。
*   **优点**：满足进阶要求，是最优解法。

```cpp
class Solution {
public:
    // 反转链表的辅助函数（迭代法）
    ListNode* reverseList(ListNode* head) {
        ListNode* prev = nullptr;
        ListNode* curr = head;
        while (curr) {
            ListNode* nextTemp = curr->next;
            curr->next = prev;
            prev = curr;
            curr = nextTemp;
        }
        return prev;
    }

    bool isPalindrome(ListNode* head) {
        if (head == nullptr || head->next == nullptr) return true;

        // 1. 快慢指针找中点
        ListNode* slow = head;
        ListNode* fast = head;
        while (fast->next && fast->next->next) {
            slow = slow->next;
            fast = fast->next->next;
        }
        // 此时 slow 指向中间节点（奇数长度时为正中间，偶数时为前半部分最后一个节点）

        // 2. 反转后半部分
        ListNode* mid = slow->next; // 后半部分的头
        ListNode* secondHalf = reverseList(mid);

        // 3. 比较前后两部分
        ListNode* p1 = head;
        ListNode* p2 = secondHalf;
        bool result = true;
        while (p2) { // 后半部分可能更短（奇数长度时前半部分多一个节点，但比较到后半部分结束即可）
            if (p1->val != p2->val) {
                result = false;
                break;
            }
            p1 = p1->next;
            p2 = p2->next;
        }

        // 4. （可选）恢复链表原状：再次反转后半部分并接回
        slow->next = reverseList(secondHalf);

        return result;
    }
};
```

## 方法四：栈（辅助空间）
利用栈存储链表前半部分的值，然后与后半部分比较。

*   **思路**：
    1.  遍历链表得到长度 `n`。
    2.  将前 `n/2` 个节点的值压入栈中。
    3.  若链表长度为奇数，跳过中间节点。
    4.  继续遍历剩余节点，依次与栈顶元素比较，若全部相等则为回文。
*   **复杂度**：时间复杂度 O(n)，空间复杂度 O(n/2) = O(n)。
*   **缺点**：需要额外空间，不满足进阶要求。

```cpp
class Solution {
public:
    bool isPalindrome(ListNode* head) {
        stack<int> st;
        ListNode* cur = head;
        int len = 0;
        while (cur) { ++len; cur = cur->next; }
        cur = head;
        int half = len / 2;
        for (int i = 0; i < half; ++i) {
            st.push(cur->val);
            cur = cur->next;
        }
        if (len % 2 == 1) cur = cur->next; // 跳过中间节点
        while (cur) {
            if (st.top() != cur->val) return false;
            st.pop();
            cur = cur->next;
        }
        return true;
    }
};
```

## 方法总结
| 方法                     | 核心思想                         | 时间复杂度 | 空间复杂度 | 适用性                               |
|--------------------------|----------------------------------|------------|------------|--------------------------------------|
| 数组 + 双指针            | 复制到数组后用双指针判断         | O(n)       | O(n)       | 简单直观，但空间大                   |
| 递归（隐式栈）           | 利用递归栈反向比较               | O(n)       | O(n)       | 代码简洁，但递归深度限制             |
| 快慢指针 + 反转链表      | 反转后半部分，逐个比较           | O(n)       | O(1)       | **最优解，满足进阶要求**             |
| 栈（显式栈）             | 前半部分入栈，与后半部分比较     | O(n)       | O(n)       | 较易理解，但空间大                   |

# 知识点与延伸

## 1. 核心知识点
- **链表的中点寻找**：快慢指针技巧，`fast` 每次走两步，`slow` 每次走一步，循环条件 `fast->next && fast->next->next` 可让 `slow` 停在中间偏左位置。
- **链表反转**：迭代法反转链表是基础操作，需熟练掌握。
- **回文判断**：将问题转化为比较前半部分与反转后的后半部分。
- **原地算法**：在 O(1) 额外空间内完成判断，通过修改链表结构实现。

## 2. 面试考察重点
- **能否想到 O(1) 空间的解法**：快慢指针 + 反转链表是标准答案。
- **对指针操作的准确性**：找中点时边界条件（奇偶长度），反转链表时不丢失节点。
- **是否恢复链表**：题目未明确要求，但有的面试官会考察是否考虑恢复原链表结构。实现中可恢复以体现完整性。

## 3. 算法正确性证明
- **快慢指针找中点**：设链表长度为 `n`，当 `fast` 走到末尾时，`slow` 恰好位于 `floor((n-1)/2)` 处（即中间偏左）。这样反转 `slow->next` 得到的后半部分长度 ≤ 前半部分，比较时只需遍历后半部分即可。
- **比较过程**：若原链表为回文，则反转后的后半部分与前半部分对应节点值相等；否则不等。

## 4. 代码优化技巧
- **使用辅助函数**：将反转链表单独封装，提高代码可读性。
- **避免多次遍历**：快慢指针一次遍历即可找到中点，无需先计算长度。
- **恢复链表**：在返回前将后半部分再次反转并接回，保持链表原始结构（本题不要求，但良好实践）。

## 5. 拓展与应用
- 类似题目：**回文数组**（双指针）、**回文字符串**（双指针或栈）。
- 链表问题中，**反转链表**常与**快慢指针**结合，用于解决“回文”、“重排链表”等问题。
- 若链表不允许修改（如只读），则无法使用反转法，只能采用数组或栈方法。
