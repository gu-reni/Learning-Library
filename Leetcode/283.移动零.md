# 题目

给定一个数组 `nums`，编写一个函数将所有 `0` 移动到数组的末尾，同时保持非零元素的相对顺序。

**请注意**，必须在不复制数组的情况下原地对数组进行操作。

**示例 1：**

**输入：** `nums = [0,1,0,3,12]`
**输出：** `[1,3,12,0,0]`

**示例 2：**

**输入：** `nums = [0]`
**输出：** `[0]`

**提示：**

- `1 <= nums.length <= 10^4`
- `-2^31 <= nums[i] <= 2^31 - 1`

**进阶：** 你能尽量减少完成的操作次数吗？

# 解题思路与代码实现

## 方法一：双指针（交换法，最优解）
使用两个指针 `left` 和 `right`，`left` 指向已处理序列的尾部（即下一个非零元素应放置的位置），`right` 遍历数组。当 `right` 遇到非零元素时，交换 `nums[left]` 与 `nums[right]`，然后 `left` 右移。

*   **思路**：
    1.  初始化 `left = 0`。
    2.  遍历数组，`right` 从 0 到 `n-1`：
        *   若 `nums[right] != 0`，则交换 `nums[left]` 与 `nums[right]`，并将 `left++`。
    3.  遍历结束后，所有非零元素按原序排在数组前部，零元素被交换至尾部。
*   **复杂度**：时间复杂度 O(n)，每个元素访问一次；空间复杂度 O(1)，仅使用常数个指针。
*   **优点**：一次遍历，原地修改，保持非零元素相对顺序，操作次数最少（仅对非零元素执行交换）。

```cpp
class Solution {
public:
    void moveZeroes(vector<int>& nums) {
        int left = 0; // 指向下一个非零元素应放置的位置
        for (int right = 0; right < nums.size(); ++right) {
            if (nums[right] != 0) {
                swap(nums[left], nums[right]);
                ++left;
            }
        }
    }
};
```

## 方法二：双指针（覆盖法）
先遍历一次将所有非零元素前移，再从末尾将剩余位置填充为零。

*   **思路**：
    1.  初始化 `index = 0`，表示当前已放置的非零元素个数。
    2.  遍历数组，若 `nums[i] != 0`，则将其赋值给 `nums[index]`，然后 `index++`。
    3.  遍历结束后，从 `index` 到 `n-1` 的所有位置赋值为 0。
*   **复杂度**：时间复杂度 O(n)，遍历两次；空间复杂度 O(1)。
*   **缺点**：需要两次遍历，且对非零元素执行一次赋值，对零元素执行一次赋值，总操作次数略多于交换法。

```cpp
class Solution {
public:
    void moveZeroes(vector<int>& nums) {
        int index = 0;
        // 将所有非零元素按序前移
        for (int i = 0; i < nums.size(); ++i) {
            if (nums[i] != 0) {
                nums[index++] = nums[i];
            }
        }
        // 剩余位置补零
        for (int i = index; i < nums.size(); ++i) {
            nums[i] = 0;
        }
    }
};
```

## 方法三：暴力法（使用额外数组，不推荐）
统计零的个数，然后将非零元素按序放入临时数组，最后拷贝回原数组。

*   **思路**：
    1.  创建临时数组 `nonZero`。
    2.  遍历原数组，将非零元素依次加入 `nonZero`。
    3.  将 `nonZero` 中的元素按序覆盖原数组的前 `nonZero.size()` 个位置。
    4.  将剩余位置填充为 0。
*   **复杂度**：时间复杂度 O(n)，空间复杂度 O(n)。
*   **缺点**：需要额外 O(n) 空间，不符合原地操作的要求，仅用于理解题意。

```cpp
class Solution {
public:
    void moveZeroes(vector<int>& nums) {
        vector<int> nonZero;
        for (int num : nums) {
            if (num != 0) nonZero.push_back(num);
        }
        for (int i = 0; i < nonZero.size(); ++i) {
            nums[i] = nonZero[i];
        }
        for (int i = nonZero.size(); i < nums.size(); ++i) {
            nums[i] = 0;
        }
    }
};
```

## 方法总结
| 方法         | 核心思想                         | 时间复杂度 | 空间复杂度 | 适用性                               |
|--------------|----------------------------------|------------|------------|--------------------------------------|
| 双指针交换法 | 遍历时交换非零元素到左侧，零元素自然右移 | O(n)       | O(1)       | **最优解，一次遍历，无额外空间**     |
| 双指针覆盖法 | 先覆盖非零元素，再统一补零       | O(n)       | O(1)       | 直观易懂，需两次遍历                 |
| 暴力法       | 使用额外数组存储非零元素再拷贝   | O(n)       | O(n)       | 仅用于理解，空间效率低               |

# 知识点与延伸

## 1. 核心知识点
- **双指针技巧**：利用快慢指针在同一数组上操作，实现原地修改，是数组类问题的常用优化手段。
- **稳定性保持**：双指针交换法在移动非零元素时保持了它们的原始相对顺序，符合题目要求。
- **原地算法**：不借助额外数组，仅通过交换或覆盖完成操作，节省内存。
- **边界处理**：空数组、全零数组、无非零元素等情况的正确处理。

## 2. 面试考察重点
- **是否能想到 O(n) 且 O(1) 的解法**：双指针交换法是标准答案。
- **对指针移动逻辑的理解**：何时交换、何时移动指针，需确保不丢失元素。
- **代码简洁性与鲁棒性**：能否正确处理边界，避免数组越界。

## 3. 算法证明与细节
- **双指针交换法正确性证明**：循环不变量 `[0, left)` 区间内全部为非零元素，且保持原序；`[left, right]` 区间内可能包含零或未处理元素。每次遇到非零元素时，将其与 `nums[left]` 交换，扩展了非零区间，零元素则被交换到右侧。最终所有非零元素位于 `[0, left)`，零元素位于 `[left, n)`。
- **交换与赋值的效率**：交换操作需要三次赋值，而覆盖法在非零元素较多时可能减少赋值次数（仅一次赋值加后续补零）。实际性能差异微小，通常优先选择交换法因其单次遍历。

## 4. 拓展与应用
- 本题思想可用于解决类似“将特定元素移动到数组末尾”的问题，只需修改交换条件即可。
- 变体：将零元素移动到数组头部，可反向双指针从右向左遍历。
- 与“删除数组中的指定元素”（LeetCode 27）解法相似，区别在于本题需保留零元素并移动至尾部，而删除题则直接覆盖。
