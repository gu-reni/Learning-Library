# 题目

给你两个单链表的头节点 `headA` 和 `headB`，请你找出并返回两个单链表相交的起始节点。如果两个链表不存在相交节点，返回 `null`。

[题目中通常配图，此处省略]

题目数据 **保证** 整个链式结构中不存在环。

注意，函数返回结果后，链表必须 **保持其原始结构**。

**示例 1：**

**输入：** `intersectVal = 8, listA = [4,1,8,4,5], listB = [5,6,1,8,4,5], skipA = 2, skipB = 3`  
**输出：** `Intersected at '8'`  
**解释：** 相交节点的值为 8 （注意，如果两个链表相交则不能为 0）。从各自的表头开始算起，链表 A 为 [4,1,8,4,5]，链表 B 为 [5,6,1,8,4,5]。在 A 中，相交节点前有 2 个节点；在 B 中，相交节点前有 3 个节点。

**示例 2：**

**输入：** `intersectVal = 2, listA = [1,9,1,2,4], listB = [3,2,4], skipA = 3, skipB = 1`  
**输出：** `Intersected at '2'`

**示例 3：**

**输入：** `intersectVal = 0, listA = [2,6,4], listB = [1,5], skipA = 3, skipB = 2`  
**输出：** `null`  
**解释：** 两个链表不相交。

**提示：**

- `listA` 中节点数目为 `m`
- `listB` 中节点数目为 `n`
- `1 <= m, n <= 3 * 10^4`
- `1 <= Node.val <= 10^5`
- `0 <= skipA <= m`
- `0 <= skipB <= n`
- 如果 `listA` 和 `listB` 没有交点，`intersectVal` 为 `0`
- 如果 `listA` 和 `listB` 有交点，`intersectVal == listA[skipA] == listB[skipB]`

**进阶：** 你能否设计一个时间复杂度 `O(m + n)`、仅用 `O(1)` 内存的解决方案？

# 解题思路与代码实现

## 方法一：哈希表法（辅助空间）
遍历链表 A，将每个节点的地址存入哈希集合。然后遍历链表 B，检查每个节点是否在哈希集合中，第一个出现的即为相交节点。

*   **思路**：
    1.  创建 `unordered_set<ListNode*>` 存储链表 A 的所有节点。
    2.  遍历链表 B，若当前节点在集合中，则返回该节点；否则继续。
    3.  若遍历结束未找到，返回 `nullptr`。
*   **复杂度**：时间复杂度 O(m + n)，空间复杂度 O(m) 或 O(n)（选择存储较短的链表可优化）。
*   **缺点**：需要额外 O(m) 空间，不满足进阶要求的 O(1) 空间。

```cpp
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode(int x) : val(x), next(NULL) {}
 * };
 */
class Solution {
public:
    ListNode *getIntersectionNode(ListNode *headA, ListNode *headB) {
        unordered_set<ListNode*> visited;
        ListNode* cur = headA;
        while (cur) {
            visited.insert(cur);
            cur = cur->next;
        }
        cur = headB;
        while (cur) {
            if (visited.count(cur)) return cur;
            cur = cur->next;
        }
        return nullptr;
    }
};
```

## 方法二：双指针法（最优解）
使用两个指针 `pA` 和 `pB` 分别指向两个链表的头节点，同时向后遍历。当某一指针到达链表末尾时，将其重定向到另一个链表的头节点。若两链表相交，则两指针会在相交节点相遇；若不相交，则最终同时变为 `nullptr`。

*   **思路**：
    1.  初始化 `pA = headA`，`pB = headB`。
    2.  当 `pA != pB` 时循环：
        *   `pA` 若为 `nullptr` 则指向 `headB`，否则移向下一个节点。
        *   `pB` 若为 `nullptr` 则指向 `headA`，否则移向下一个节点。
    3.  循环结束时，`pA`（或 `pB`）即为相交节点或 `nullptr`。
*   **正确性证明**：设链表 A 不相交部分长度为 `a`，链表 B 不相交部分长度为 `b`，公共部分长度为 `c`。指针 `pA` 走过的路径为 `a + c + b`，指针 `pB` 走过的路径为 `b + c + a`，两者长度相等。若相交，两指针会在走过 `a + c + b` 步后同时到达相交节点；若不相交（`c = 0`），则两指针会同时到达 `nullptr`（`a + b` 步）。
*   **复杂度**：时间复杂度 O(m + n)，空间复杂度 O(1)。
*   **优点**：满足进阶要求，是最优解。

```cpp
class Solution {
public:
    ListNode *getIntersectionNode(ListNode *headA, ListNode *headB) {
        if (headA == nullptr || headB == nullptr) return nullptr;
        ListNode *pA = headA, *pB = headB;
        while (pA != pB) {
            pA = (pA == nullptr) ? headB : pA->next;
            pB = (pB == nullptr) ? headA : pB->next;
        }
        return pA;
    }
};
```

## 方法三：长度对齐法
先分别计算两个链表的长度，然后让较长的链表先走长度差步，使得两个链表剩余部分长度相等，再同时向后遍历，第一个相同的节点即为相交点。

*   **思路**：
    1.  遍历链表 A 和 B，分别计算长度 `lenA` 和 `lenB`。
    2.  计算长度差 `diff = abs(lenA - lenB)`。
    3.  将较长链表的指针先向前移动 `diff` 步。
    4.  同时移动两个指针，比较是否相等，相等则返回该节点；否则继续。
    5.  若未找到，返回 `nullptr`。
*   **复杂度**：时间复杂度 O(m + n)，空间复杂度 O(1)。
*   **优点**：直观易懂，同样满足 O(1) 空间。
*   **缺点**：需要两次遍历计算长度（双指针法只需一次遍历，但实际也是两次遍历的变体）。

```cpp
class Solution {
public:
    ListNode *getIntersectionNode(ListNode *headA, ListNode *headB) {
        int lenA = 0, lenB = 0;
        ListNode *curA = headA, *curB = headB;
        while (curA) { curA = curA->next; ++lenA; }
        while (curB) { curB = curB->next; ++lenB; }
        
        curA = headA, curB = headB;
        if (lenA > lenB) {
            int diff = lenA - lenB;
            while (diff--) curA = curA->next;
        } else {
            int diff = lenB - lenA;
            while (diff--) curB = curB->next;
        }
        while (curA && curB) {
            if (curA == curB) return curA;
            curA = curA->next;
            curB = curB->next;
        }
        return nullptr;
    }
};
```

## 方法四：暴力法（不推荐）
对于链表 A 的每个节点，遍历链表 B 检查是否有相同节点。

*   **思路**：两层循环，外层遍历链表 A，内层遍历链表 B，比较节点地址。
*   **复杂度**：时间复杂度 O(m * n)，空间复杂度 O(1)。对于 `3*10^4` 的规模会超时，仅用于理解。
*   **缺点**：效率极低，无法通过大数据测试。

```cpp
class Solution {
public:
    ListNode *getIntersectionNode(ListNode *headA, ListNode *headB) {
        ListNode *curA = headA;
        while (curA) {
            ListNode *curB = headB;
            while (curB) {
                if (curA == curB) return curA;
                curB = curB->next;
            }
            curA = curA->next;
        }
        return nullptr;
    }
};
```

## 方法总结
| 方法         | 核心思想                         | 时间复杂度 | 空间复杂度 | 适用性                               |
|--------------|----------------------------------|------------|------------|--------------------------------------|
| 哈希表法     | 存储链表 A 的节点，在 B 中查找   | O(m + n)   | O(m)       | 空间换时间，不满足进阶要求           |
| 双指针法     | 两指针遍历不同链表，消除长度差   | O(m + n)   | O(1)       | **最优解，满足进阶 O(1) 空间**       |
| 长度对齐法   | 先对齐尾部，再同步遍历           | O(m + n)   | O(1)       | 直观，同样满足 O(1) 空间             |
| 暴力法       | 双重循环枚举                     | O(m * n)   | O(1)       | 仅理论，实际超时                     |

# 知识点与延伸

## 1. 核心知识点
- **链表相交的性质**：相交后所有节点均相同（因为节点是同一个对象，而不是值相同）。
- **双指针技巧**：通过交换遍历路径消除长度差，是解决链表对齐问题的经典方法。
- **空间复杂度优化**：从 O(m) 哈希表优化到 O(1) 双指针，体现空间换时间的反向思考。
- **边界条件**：空链表、不相交、一个链表是另一个的子集等情况。

## 2. 面试考察重点
- **能否想到 O(1) 空间解法**：双指针法或长度对齐法是标准答案。
- **理解指针比较的是地址而非值**：题目要求返回节点（地址），而非节点值。
- **证明能力**：能够解释双指针法为什么能正确找到相交节点（路径长度相等）。

## 3. 算法证明与推导
- **双指针法正确性证明**：
  - 设链表 A 不相交部分长度为 `a`，链表 B 不相交部分长度为 `b`，公共部分长度为 `c`。
  - 指针 `pA` 走过的路径：`a → c → b`（从 A 头到 A 尾，然后从 B 头到相交点）
  - 指针 `pB` 走过的路径：`b → c → a`（从 B 头到 B 尾，然后从 A 头到相交点）
  - 两者到达相交点时的步数均为 `a + c + b = b + c + a`，因此同时到达。
  - 若不相交（`c=0`），则 `pA` 走 `a + b` 步到达 `nullptr`，`pB` 走 `b + a` 步到达 `nullptr`，同时为 `nullptr`，循环结束返回 `nullptr`。

## 4. 代码优化技巧
- **使用三元运算符简化重定向**：`pA = pA ? pA->next : headB;` 简洁高效。
- **提前判断空链表**：虽然算法本身能处理，但提前返回可避免不必要的计算。
- **注意 `ListNode` 的构造函数**：题目给出的定义中构造函数参数为 `int x`，无需修改。

## 5. 拓展与应用
- 本题是链表双指针技巧的典型应用，类似思路可用于：
  - 链表中环的检测（快慢指针）
  - 寻找链表的中间节点
  - 删除倒数第 N 个节点
- 若链表可能有环，则问题更复杂（需要先判断是否有环），但本题保证无环。
