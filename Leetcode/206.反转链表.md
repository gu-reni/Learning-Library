# 题目

给你单链表的头节点 `head` ，请你反转链表，并返回反转后的链表。

**示例 1：**

**输入：** `head = [1,2,3,4,5]`
**输出：** `[5,4,3,2,1]`

**示例 2：**

**输入：** `head = [1,2]`
**输出：** `[2,1]`

**示例 3：**

**输入：** `head = []`
**输出：** `[]`

**提示：**

- 链表中节点的数目范围是 `[0, 5000]`
- `-5000 <= Node.val <= 5000`

**进阶：** 链表可以选用迭代或递归方式完成反转。你能否用两种方法解决这道题？

# 解题思路与代码实现

## 方法一：迭代法（双指针，最优解）
通过遍历链表，逐个改变节点的指针方向，实现原地反转。

*   **思路**：
    1.  初始化两个指针：`prev` 指向 `nullptr`，`curr` 指向头节点 `head`。
    2.  遍历链表，在每次循环中：
        *   先用 `next` 临时保存 `curr->next`，防止丢失后续节点。
        *   将 `curr->next` 指向 `prev`，完成当前节点的反转。
        *   将 `prev` 移动到 `curr`，`curr` 移动到 `next`。
    3.  遍历结束后，`prev` 成为新链表的头节点，返回 `prev`。
*   **复杂度**：时间复杂度 O(n)，每个节点访问一次；空间复杂度 O(1)，仅使用常数个额外指针。
*   **优点**：效率高，无额外空间开销，是面试中最推荐的解法。

```cpp
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */
class Solution {
public:
    ListNode* reverseList(ListNode* head) {
        ListNode* prev = nullptr;
        ListNode* curr = head;
        while (curr != nullptr) {
            ListNode* next = curr->next; // 暂存下一个节点
            curr->next = prev;            // 反转当前节点的指针
            prev = curr;                  // 移动prev
            curr = next;                  // 移动curr
        }
        return prev; // prev即为新头节点
    }
};
```

## 方法二：递归法
利用递归调用栈回溯时修改指针方向，实现链表的反转。

*   **思路**：
    1.  递归终止条件：当前节点为空或下一个节点为空（即链表为空或只有一个节点），直接返回当前节点。
    2.  递归调用 `reverseList(head->next)`，得到反转后的新头节点 `newHead`。
    3.  在回溯阶段，将当前节点的下一个节点的 `next` 指针指向当前节点（即 `head->next->next = head`）。
    4.  将当前节点的 `next` 置为 `nullptr`，避免形成环。
    5.  返回 `newHead`。
*   **复杂度**：时间复杂度 O(n)，每个节点处理一次；空间复杂度 O(n)，递归调用栈的深度等于链表长度。
*   **缺点**：当链表很长时，可能导致栈溢出，且递归本身有一定开销。

```cpp
class Solution {
public:
    ListNode* reverseList(ListNode* head) {
        // 终止条件：空链表或只有一个节点
        if (head == nullptr || head->next == nullptr) {
            return head;
        }
        ListNode* newHead = reverseList(head->next); // 递归反转后续链表
        head->next->next = head; // 将当前节点接到反转后的尾部
        head->next = nullptr;     // 防止环
        return newHead;
    }
};
```

## 方法三：借助栈（辅助数据结构）
利用栈的后进先出特性，重新构造链表。

*   **思路**：
    1.  遍历链表，将所有节点指针压入栈中。
    2.  从栈中依次弹出节点，重新连接成新链表。
    3.  返回新链表的头节点。
*   **复杂度**：时间复杂度 O(n)，遍历一次，出栈一次；空间复杂度 O(n)，需要栈存储所有节点。
*   **缺点**：需要额外 O(n) 空间，且不如迭代法简洁高效。

```cpp
class Solution {
public:
    ListNode* reverseList(ListNode* head) {
        if (head == nullptr) return nullptr;
        stack<ListNode*> st;
        ListNode* curr = head;
        while (curr != nullptr) {
            st.push(curr);
            curr = curr->next;
        }
        ListNode* newHead = st.top();
        st.pop();
        curr = newHead;
        while (!st.empty()) {
            curr->next = st.top();
            st.pop();
            curr = curr->next;
        }
        curr->next = nullptr; // 将最后一个节点的next置空
        return newHead;
    }
};
```

## 方法总结
| 方法         | 核心思想                         | 时间复杂度 | 空间复杂度 | 适用性                               |
|--------------|----------------------------------|------------|------------|--------------------------------------|
| 迭代法       | 双指针原地修改指针方向           | O(n)       | O(1)       | **最优解，适用于所有情况**           |
| 递归法       | 递归回溯时反转指针               | O(n)       | O(n)       | 代码简洁，但链表过长可能栈溢出       |
| 辅助栈法     | 利用栈后进先出重新连接节点       | O(n)       | O(n)       | 提供另一种思路，但空间效率低         |

# 知识点与延伸

## 1. 核心知识点
- **链表基础操作**：掌握链表节点的结构、指针操作、遍历方法。
- **指针引用与修改**：迭代法中 `prev`、`curr`、`next` 指针的更新顺序，防止断链。
- **递归思想**：将大问题分解为相同子问题（反转后续链表），并利用递归栈保存现场，在回溯阶段完成操作。
- **边界条件处理**：空链表、单节点链表需单独处理，确保代码鲁棒性。

## 2. 面试考察重点
- **对指针操作的理解**：能否正确反转指针，避免丢失节点或形成环。
- **代码的简洁性与健壮性**：是否包含必要的边界判断，循环条件是否正确。
- **多解能力**：能否给出迭代和递归两种解法，并比较优劣。
- **递归的思维方式**：能否理解递归过程，特别是回溯阶段的指针修改。

## 3. 算法优化技巧
- **原地反转**：迭代法利用有限指针完成反转，无需额外空间。
- **递归的尾调用优化**：在某些语言中，递归可优化为迭代，但 C++ 不支持尾递归优化，因此递归仍可能栈溢出。

## 4. 拓展与应用
- 本题是链表操作的基础题，其思想可用于解决其他链表问题，如：
    - 反转链表 II（反转部分链表）
    - K 个一组翻转链表
    - 回文链表（常结合反转链表判断）
- 迭代法中的“三指针”技巧是处理链表问题的通用模板，需熟练掌握。
