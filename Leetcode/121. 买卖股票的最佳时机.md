给定一个数组 `prices` ，它的第 `i` 个元素 `prices[i]` 表示一支给定股票第 `i` 天的价格。

你只能选择 **某一天** 买入这只股票，并选择在 **未来的某一个不同的日子** 卖出该股票。设计一个算法来计算你所能获取的最大利润。

返回你可以从这笔交易中获取的最大利润。如果你不能获取任何利润，返回 `0` 。

**示例 1：**

**输入：**[7,1,5,3,6,4]
**输出：**5
**解释：**在第 2 天（股票价格 = 1）的时候买入，在第 5 天（股票价格 = 6）的时候卖出，最大利润 = 6-1 = 5 。
     注意利润不能是 7-1 = 6, 因为卖出价格需要大于买入价格；同时，你不能在买入前卖出股票。

**示例 2：**

**输入：**prices = [7,6,4,3,1]
**输出：**0
**解释：**在这种情况下, 没有交易完成, 所以最大利润为 0。

**提示：**

- `1 <= prices.length <= 105`
- `0 <= prices[i] <= 104`

# 解题思路与代码实现

## **方法一：暴力求解法（不推荐）**
这是最直观的解法，即枚举所有可能的买入和卖出组合，计算利润并找出最大值。
*   **思路**：使用两层循环，对于每一天`i`作为买入点，遍历此后的每一天`j`作为卖出点，计算`prices[j] - prices[i]`，并更新最大利润。
*   **缺点**：时间复杂度为 O(n²)，对于题目中给出的`prices.length`最大可达 `10^5` 的规模，这种方法会超时，因此**仅作了解，不适用于实际解题** 。

```cpp
// C++ 暴力解法示例（仅用于理解思路，提交会超时）
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int maxprofit = 0;
        int n = prices.size();
        for (int i = 0; i < n - 1; ++i) {
            for (int j = i + 1; j < n; ++j) {
                int profit = prices[j] - prices[i];
                if (profit > maxprofit) {
                    maxprofit = profit;
                }
            }
        }
        return maxprofit;
    }
};
```

## **方法二：一次遍历法（最优解）**
这是解决本题的标准解法，核心思想是在遍历过程中动态更新“历史最低点”，并假设在当天卖出，计算潜在利润。
*   **思路**：
    1.  初始化`minprice`为一个很大的数（如 `INT_MAX`），`maxprofit`为0。
    2.  遍历价格数组。对于每一天的价格`prices[i]`：
        *   如果`prices[i]`比当前的`minprice`还小，说明找到了一个更低的买入点，更新`minprice`。
        *   否则，计算如果在这一天卖出能获得的利润（`prices[i] - minprice`），如果这个利润大于当前的`maxprofit`，则更新`maxprofit` 。
*   **复杂度**：时间复杂度 O(n)，空间复杂度 O(1)。

```cpp
// C++ 一次遍历解法
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int minprice = INT_MAX;
        int maxprofit = 0;
        for (int price : prices) {
            if (price < minprice) {
                minprice = price;
            } else if (price - minprice > maxprofit) {
                maxprofit = price - minprice;
            }
        }
        return maxprofit;
    }
};
```

## **方法三：动态规划（通用解法）**
动态规划提供了一种更具普适性的思考方式，虽然对于本题来说不如方法二简洁，但它能帮助解决更复杂的股票交易问题（如交易多次的情况）。
*   **思路**：
    1.  **定义状态**：可以用一个二维数组 `dp[i][j]` 表示在第 `i` 天结束时，持有状态为 `j` 时的现金数。
        *   `dp[i][0]`：第 `i` 天**不持有**股票的最大利润。
        *   `dp[i][1]`：第 `i` 天**持有**股票的最大利润。
    2.  **状态转移**：
        *   第 `i` 天不持有股票，可能是昨天就不持有，或者是今天将持有的股票卖出。即：`dp[i][0] = max(dp[i-1][0], dp[i-1][1] + prices[i])`
        *   第 `i` 天持有股票，可能是昨天就持有，或者是今天买入（买入后现金减少，且只能交易一次，所以买入时的现金为 `-prices[i]`）。即：`dp[i][1] = max(dp[i-1][1], -prices[i])`
    3.  **初始化**：第一天 `dp[0][0] = 0`（不持有），`dp[0][1] = -prices[0]`（持有，即买入）。
    4.  **结果**：最后一天不持有股票时的利润 `dp[n-1][0]` 就是最大利润 。
*   **复杂度**：时间复杂度 O(n)，空间复杂度 O(n)，可通过滚动数组优化为 O(1)。

```cpp
// C++ 动态规划解法
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int n = prices.size();
        if (n == 0) return 0;
        vector<vector<int>> dp(n, vector<int>(2));
        dp[0][0] = 0;
        dp[0][1] = -prices[0];
        for (int i = 1; i < n; ++i) {
            dp[i][0] = max(dp[i-1][0], dp[i-1][1] + prices[i]);
            dp[i][1] = max(dp[i-1][1], -prices[i]);
        }
        return dp[n-1][0];
    }
};
// 空间优化版
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int n = prices.size();
        int dp0 = 0;          // 表示不持有股票的最大利润
        int dp1 = -prices[0]; // 表示持有股票的最大利润
        for (int i = 1; i < n; ++i) {
            dp0 = max(dp0, dp1 + prices[i]);
            dp1 = max(dp1, -prices[i]);
        }
        return dp0;
    }
};
```

## 方法总结
| 方法 | 核心思想 | 时间复杂度 | 空间复杂度 | 适用性 |
| :--- | :--- | :--- | :--- | :--- |
| **暴力法** | 枚举所有买卖组合 | O(n²) | O(1) | 仅理论，实际超时 |
| **一次遍历** | 记录历史最低点，计算每天卖出利润 | O(n) | O(1) | **本题最佳，最简洁** |
| **动态规划** | 定义状态，推导状态转移方程 | O(n) | O(n) / O(1) | 通用性强，可解决复杂变体 |
## 本题涉及知识点

- **数组的线性扫描**：通过一次遍历同时追踪历史最低价格和当前最大利润，体现了“边走边算”的高效思维，这是处理序列问题的常用技巧。
- **贪心算法**：每次都试图以当前遇到的最低价格买入，并在之后卖出，这种局部最优选择能推导出全局最大利润（因为只需一次交易）。
- **动态规划（状态机模型）**：将问题抽象为“持有股票”和“不持有股票”两种状态，通过状态转移方程求解。该方法具有普适性，可以扩展到允许多次交易（如122题）或含冷冻期（如309题）等复杂场景。
- **差分思想**：将原始价格数组转化为相邻两天的价格差，则原问题等价于求差分数组的**最大子数组和**（即最大连续子段和），这可以用Kadane算法在线性时间和常数空间内解决，为问题提供了另一种数学视角。
- **边界条件处理**：理解空数组、单元素数组等特殊情况，确保算法鲁棒性（例如，最小价格初始化为极大值，最大利润初始化为0）。
