# 题目
给定一个数组 `prices` ，它的第 `i` 个元素 `prices[i]` 表示一支给定股票第 `i` 天的价格。

你只能选择 **某一天** 买入这只股票，并选择在 **未来的某一个不同的日子** 卖出该股票。设计一个算法来计算你所能获取的最大利润。

返回你可以从这笔交易中获取的最大利润。如果你不能获取任何利润，返回 `0` 。

**示例 1：**

**输入：**[7,1,5,3,6,4]
**输出：**5
**解释：**在第 2 天（股票价格 = 1）的时候买入，在第 5 天（股票价格 = 6）的时候卖出，最大利润 = 6-1 = 5 。
     注意利润不能是 7-1 = 6, 因为卖出价格需要大于买入价格；同时，你不能在买入前卖出股票。

**示例 2：**

**输入：**prices = [7,6,4,3,1]
**输出：**0
**解释：**在这种情况下, 没有交易完成, 所以最大利润为 0。

**提示：**

- `1 <= prices.length <= 105`
- `0 <= prices[i] <= 104`

# 解题思路与代码实现

## 方法一：暴力求解法（不推荐）
最直观的解法，枚举所有可能的买入和卖出组合，计算利润并找出最大值。

*   **思路**：两层循环，对于每一天 `i` 作为买入点，遍历此后的每一天 `j` 作为卖出点，计算 `prices[j] - prices[i]`，更新最大利润。
*   **复杂度**：时间复杂度 O(n²)，空间复杂度 O(1)。对于 `prices.length` 可达 `10^5` 的规模，此方法会超时，因此仅作理解，不适用于实际解题。

```cpp
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int maxprofit = 0;
        int n = prices.size();
        for (int i = 0; i < n - 1; ++i) {
            for (int j = i + 1; j < n; ++j) {
                int profit = prices[j] - prices[i];
                if (profit > maxprofit) {
                    maxprofit = profit;
                }
            }
        }
        return maxprofit;
    }
};
```

## 方法二：一次遍历法（最优解）
在遍历过程中动态更新“历史最低点”，并假设在当天卖出，计算潜在利润。

*   **思路**：
    1.  初始化 `minprice` 为一个极大值（如 `INT_MAX`），`maxprofit` 为 0。
    2.  遍历价格数组。对于每一天的价格 `prices[i]`：
        *   如果 `prices[i]` 小于 `minprice`，则更新 `minprice`。
        *   否则，计算当天卖出能获得的利润 `prices[i] - minprice`，若大于 `maxprofit` 则更新 `maxprofit`。
*   **正确性证明**：对于任意一天 `i`，若存在一个最优解是在第 `j` 天买入、第 `k` 天卖出（`j < k`），则当遍历到 `k` 时，`minprice` 必然 ≤ `prices[j]`，因此 `prices[k] - minprice ≥ prices[k] - prices[j]`，且 `maxprofit` 会更新为至少该值，故算法能捕获到全局最大利润。
*   **复杂度**：时间复杂度 O(n)，空间复杂度 O(1)。

```cpp
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int minprice = INT_MAX;
        int maxprofit = 0;
        for (int price : prices) {
            if (price < minprice) {
                minprice = price;
            } else if (price - minprice > maxprofit) {
                maxprofit = price - minprice;
            }
        }
        return maxprofit;
    }
};
```

## 方法三：动态规划（通用解法）
定义状态表示持有与不持有股票时的最大利润，通过状态转移方程求解。该模型可扩展至更复杂的股票交易问题。

*   **思路**：
    1.  **状态定义**：`dp[i][0]` 表示第 `i` 天结束后不持有股票的最大利润；`dp[i][1]` 表示第 `i` 天结束后持有股票的最大利润。
    2.  **状态转移**：
        *   `dp[i][0] = max(dp[i-1][0], dp[i-1][1] + prices[i])` （前一天不持有，或前一天持有并在今天卖出）
        *   `dp[i][1] = max(dp[i-1][1], -prices[i])` （前一天持有，或今天买入；因为只能交易一次，买入时的利润为 `-prices[i]`）
    3.  **初始化**：`dp[0][0] = 0`，`dp[0][1] = -prices[0]`。
    4.  **结果**：最后一天不持有股票时的利润 `dp[n-1][0]`。
*   **空间优化**：由于状态只依赖于前一天，可用两个变量滚动更新，空间复杂度降为 O(1)。

```cpp
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int n = prices.size();
        if (n == 0) return 0;
        int dp0 = 0;          // 不持有股票的最大利润
        int dp1 = -prices[0]; // 持有股票的最大利润
        for (int i = 1; i < n; ++i) {
            dp0 = max(dp0, dp1 + prices[i]);
            dp1 = max(dp1, -prices[i]);
        }
        return dp0;
    }
};
```

## 方法四：Kadane算法（差分思想）
将价格数组转化为差分数组 `diff[i] = prices[i] - prices[i-1]`，则原问题等价于求差分数组的**最大子数组和**（买入到卖出的收益等于这段时间每日差分的累加）。利用Kadane算法求解。

*   **思路**：遍历差分数组，用 `cur` 记录当前累加和，若 `cur` 变为负数则重置为 0，否则更新最大和 `maxSoFar`。
*   **注意**：差分数组长度比原数组少 1，需处理边界情况（数组长度 ≤ 1 时返回 0）。
*   **复杂度**：时间复杂度 O(n)，空间复杂度 O(1)。

```cpp
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int maxCur = 0, maxSoFar = 0;
        for (int i = 1; i < prices.size(); ++i) {
            maxCur = max(0, maxCur + prices[i] - prices[i-1]);
            maxSoFar = max(maxSoFar, maxCur);
        }
        return maxSoFar;
    }
};
```

## 方法总结
| 方法         | 核心思想                         | 时间复杂度 | 空间复杂度 | 适用性                               |
|--------------|----------------------------------|------------|------------|--------------------------------------|
| 暴力法       | 枚举所有买卖组合                 | O(n²)      | O(1)       | 仅理论，实际超时                     |
| 一次遍历     | 记录历史最低点，计算每天卖出利润 | O(n)       | O(1)       | **本题最优，最简洁**                 |
| 动态规划     | 状态机模型，持有与不持有两种状态 | O(n)       | O(1)       | 通用性强，可解决多种股票交易变体     |
| Kadane算法   | 差分 + 最大子数组和              | O(n)       | O(1)       | 提供数学转化视角，代码简洁           |

# 知识点与延伸

## 1. 核心知识点
- **线性扫描**：通过一次遍历同时追踪历史最低点和当前最大利润，体现了“动态更新”的优化思想。
- **贪心思想**：每次以当前最低价买入，在后续卖出，局部最优导致全局最优（因只能交易一次）。
- **动态规划（状态机模型）**：将问题抽象为持有与不持有两种状态，适用于带约束的交易问题（如交易次数限制、冷冻期、手续费等）。
- **差分与最大子数组和**：将问题转化为求差分数组的最大子段和，可利用Kadane算法，是数学建模的典型例子。
- **边界条件处理**：空数组、单元素数组、价格单调下降等情况，确保算法鲁棒性。

## 2. 面试考察重点
- **优化意识**：能否从暴力法逐步优化到 O(n) 解法。
- **代码实现能力**：边界条件处理、变量初始化、循环逻辑的准确性。
- **多解能力**：能否给出多种解法并比较优劣。
- **拓展能力**：能否将本题解法迁移到股票系列的其他题目。

## 3. 算法证明与数学推导
- **一次遍历法的正确性**：可采用归纳法或反证法证明。归纳基础：第一天 `maxprofit = 0`，`minprice = prices[0]`；假设前 i 天算法正确，第 i+1 天时，若 `prices[i+1] < minprice` 则更新，否则计算利润并可能更新 `maxprofit`，任何在第 i+1 天卖出的最优解必定在之前的某个最低点买入，而该最低点已被记录，因此算法保持最优性。
- **Kadane算法的本质**：最大子数组和问题具有最优子结构，即 `maxEndingHere = max(0, maxEndingHere + diff[i])`，保证了不会在负收益段开始新的子数组。

## 4. 代码优化技巧
- **使用 INT_MAX 初始化最小值**：避免硬编码，适应所有价格范围。
- **空间压缩**：动态规划中仅保留前一天的变量，节省内存。
- **提前终止**：若某天价格低于历史最低，则当天不可能卖出获得更大利润，但无需特殊处理，算法自然处理。
