题目：
给定一个二叉树 `root` ，返回其最大深度。

二叉树的 **最大深度** 是指从根节点到最远叶子节点的最长路径上的节点数。

**示例 1：**
![](https://assets.leetcode.com/uploads/2020/11/26/tmp-tree.jpg)
**输入：**root = [3,9,20,null,null,15,7]
**输出：**3

**示例 2：**

**输入：**root = [1,null,2]
**输出：**2

**提示：**

- 树中节点的数量在 `[0, 104]` 区间内。
- `-100 <= Node.val <= 100`
- 
### 方法一：深度优先搜索（递归）

#### 核心思路
递归是解决树相关问题的常用方法。对于每个节点，其最大深度等于左子树的最大深度与右子树的最大深度中的较大值加 1（当前节点）。递归终止条件为节点为空，深度为 0。

#### 复杂度分析
- **时间复杂度**：O(n)，其中 n 为二叉树的节点个数。每个节点恰好被访问一次。
- **空间复杂度**：O(height)，其中 height 为树的高度。递归调用的栈空间取决于树的深度，最坏情况下树退化为链表，空间复杂度 O(n)；平均情况下为 O(log n)。

#### C++ 代码实现
```cpp
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    int maxDepth(TreeNode* root) {
        if (root == nullptr) return 0;                     // 空节点深度为0
        int leftDepth = maxDepth(root->left);              // 左子树深度
        int rightDepth = maxDepth(root->right);            // 右子树深度
        return max(leftDepth, rightDepth) + 1;             // 当前节点深度 = 子树最大深度 + 1
    }
};
```

#### 说明
该方法实现简洁直观，是求解二叉树深度最经典的方法。当树深度较大时，递归可能导致栈溢出，但一般情况下性能良好。

### 方法二：广度优先搜索（迭代）

#### 核心思路
利用队列进行层序遍历（BFS）。每遍历完一层，深度加 1。通过记录当前层的节点个数，可以准确控制每一层的处理。

#### 复杂度分析
- **时间复杂度**：O(n)，每个节点入队出队一次。
- **空间复杂度**：O(n)，队列中最多同时存储一层的节点。最坏情况（完全二叉树的最后一层）约有 n/2 个节点，空间复杂度仍为 O(n)。

#### C++ 代码实现
```cpp
class Solution {
public:
    int maxDepth(TreeNode* root) {
        if (root == nullptr) return 0;
        queue<TreeNode*> q;
        q.push(root);
        int depth = 0;
        while (!q.empty()) {
            int levelSize = q.size();          // 当前层的节点个数
            for (int i = 0; i < levelSize; ++i) {
                TreeNode* node = q.front();
                q.pop();
                if (node->left) q.push(node->left);
                if (node->right) q.push(node->right);
            }
            depth++;                            // 每层处理完深度+1
        }
        return depth;
    }
};
```

#### 说明
BFS 方法避免了递归可能带来的栈溢出问题，尤其适合处理深度极大的树。同时，该方法也适用于需要按层处理的其他问题。

### 方法三：深度优先搜索（迭代，显式栈）

#### 核心思路
使用栈模拟递归过程。栈中每个元素存储一个节点及其当前深度。每遇到一个节点，更新最大深度，并将左右子节点（若存在）压入栈中，同时深度加 1。

#### 复杂度分析
- **时间复杂度**：O(n)，每个节点入栈出栈一次。
- **空间复杂度**：O(n)，栈存储所有节点，最坏情况（链表）为 O(n)。

#### C++ 代码实现
```cpp
class Solution {
public:
    int maxDepth(TreeNode* root) {
        if (root == nullptr) return 0;
        stack<pair<TreeNode*, int>> stk;        // 栈元素为 (节点, 当前深度)
        stk.push({root, 1});
        int maxDepth = 0;
        while (!stk.empty()) {
            auto [node, depth] = stk.top();
            stk.pop();
            maxDepth = max(maxDepth, depth);    // 更新最大深度
            if (node->left) stk.push({node->left, depth + 1});
            if (node->right) stk.push({node->right, depth + 1});
        }
        return maxDepth;
    }
};
```

#### 说明
该方法与递归本质相同，但使用显式栈避免了递归调用的系统开销，且更易控制栈空间。实际应用中不如递归简洁，但为理解 DFS 的迭代实现提供了思路。

---

### 方法总结

| 方法 | 核心思想 | 时间复杂度 | 空间复杂度 | 适用性 |
|------|----------|------------|------------|--------|
| 递归 DFS | 利用递归公式 depth = max(leftDepth, rightDepth) + 1 | O(n) | O(height) | 代码简洁，适合递归思维；树深度过大时可能栈溢出 |
| 迭代 BFS | 层序遍历，每层深度加 1 | O(n) | O(n) | 避免递归栈溢出，适合深度极大的树，可扩展至层相关问题 |
| 迭代 DFS（显式栈） | 用栈模拟递归，记录节点及当前深度 | O(n) | O(n) | 递归的迭代实现，思路直观，但代码稍复杂 |

### 知识点与延伸

- **树的基本遍历**：深度优先搜索（DFS）与广度优先搜索（BFS）是解决树问题的两大基石。
- **递归与迭代**：递归能简洁表达树的自相似结构，但需注意递归深度；迭代通过显式数据结构（栈/队列）控制流程，可避免系统栈溢出。
- **时间复杂度分析**：所有方法均需遍历每个节点一次，故时间复杂度为 O(n)。空间复杂度取决于树的形态（高度或宽度）。
- **边界处理**：空树时深度为 0，代码中需正确处理根节点为空的情况。
- **拓展**：该题解法可直接推广至 N 叉树的最大深度（递归或 BFS 同样适用）。
