# 题目

给定一个二叉树，找出其最大深度。

二叉树的深度为根节点到最远叶子节点的最长路径上的节点数。

**说明：** 叶子节点是指没有子节点的节点。

**示例：**  
给定二叉树 `[3,9,20,null,null,15,7]`，

```
    3
   / \
  9  20
     / \
    15  7
```

返回它的最大深度 3。

**提示：**

- 树中节点的数量范围是 `[0, 10^4]`
- `-100 <= Node.val <= 100`

# 解题思路与代码实现

## 方法一：深度优先搜索（递归，最优解）
递归是解决树深度问题最直观的方法。每个节点的深度等于左子树深度与右子树深度的最大值加 1。

*   **思路**：
    1.  递归终止条件：若当前节点为空，返回 0。
    2.  分别递归计算左子树和右子树的深度。
    3.  返回 `max(leftDepth, rightDepth) + 1`。
*   **复杂度**：时间复杂度 O(n)，每个节点访问一次；空间复杂度 O(height)，递归调用栈的深度等于树的高度，最坏情况（链表）为 O(n)，平均为 O(log n)。
*   **优点**：代码简洁，符合树的递归定义，是本题的标准解法。

```cpp
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    int maxDepth(TreeNode* root) {
        if (root == nullptr) return 0;
        int leftDepth = maxDepth(root->left);
        int rightDepth = maxDepth(root->right);
        return max(leftDepth, rightDepth) + 1;
    }
};
```

## 方法二：广度优先搜索（层序遍历，迭代）
利用队列进行层序遍历，每遍历完一层，深度加 1。

*   **思路**：
    1.  若根节点为空，返回 0。
    2.  初始化队列，将根节点入队，深度 `depth = 0`。
    3.  循环处理队列：记录当前层节点数 `levelSize`，依次弹出这些节点，并将其左右非空子节点入队。每处理完一层，`depth++`。
    4.  返回 `depth`。
*   **复杂度**：时间复杂度 O(n)，每个节点入队出队一次；空间复杂度 O(n)，队列中最多存储一层的节点数，最坏情况（完全二叉树最后一层）约为 n/2。
*   **优点**：避免递归栈溢出，适合树深度很大的情况，且可自然扩展到按层处理的问题。

```cpp
class Solution {
public:
    int maxDepth(TreeNode* root) {
        if (root == nullptr) return 0;
        queue<TreeNode*> q;
        q.push(root);
        int depth = 0;
        while (!q.empty()) {
            int levelSize = q.size();
            for (int i = 0; i < levelSize; ++i) {
                TreeNode* node = q.front();
                q.pop();
                if (node->left) q.push(node->left);
                if (node->right) q.push(node->right);
            }
            ++depth;
        }
        return depth;
    }
};
```

## 方法三：深度优先搜索（迭代，显式栈）
使用栈模拟递归过程，栈中元素存储节点及其当前深度。

*   **思路**：
    1.  若根节点为空，返回 0。
    2.  初始化栈，将 `(root, 1)` 入栈，`maxDepth = 0`。
    3.  循环弹出栈顶，更新 `maxDepth`，并将左右子节点（若存在）以其深度 +1 入栈。
    4.  返回 `maxDepth`。
*   **复杂度**：时间复杂度 O(n)，每个节点入栈出栈一次；空间复杂度 O(n)，栈最大深度等于树的高度。
*   **缺点**：相比递归实现更繁琐，但避免了系统递归栈限制。

```cpp
class Solution {
public:
    int maxDepth(TreeNode* root) {
        if (root == nullptr) return 0;
        stack<pair<TreeNode*, int>> stk;
        stk.push({root, 1});
        int maxDepth = 0;
        while (!stk.empty()) {
            auto [node, depth] = stk.top();
            stk.pop();
            maxDepth = max(maxDepth, depth);
            if (node->left) stk.push({node->left, depth + 1});
            if (node->right) stk.push({node->right, depth + 1});
        }
        return maxDepth;
    }
};
```

## 方法总结
| 方法                 | 核心思想                         | 时间复杂度 | 空间复杂度 | 适用性                               |
|----------------------|----------------------------------|------------|------------|--------------------------------------|
| 递归 DFS             | 深度 = 1 + max(左深度, 右深度)   | O(n)       | O(height)  | **最优解，最简洁，适用于大多数情况** |
| 迭代 BFS（层序）     | 层序遍历，每层深度加 1           | O(n)       | O(n)       | 避免递归栈溢出，适合深度极大树       |
| 迭代 DFS（显式栈）   | 用栈模拟递归，记录节点与深度     | O(n)       | O(n)       | 递归的替代实现，可控栈空间           |

# 知识点与延伸

## 1. 核心知识点
- **树的递归定义**：二叉树本身是递归结构，最大深度问题天然适合递归求解。
- **深度优先搜索（DFS）**：递归和显式栈都是 DFS 的实现方式，先访问子节点再回溯。
- **广度优先搜索（BFS）**：层序遍历使用队列，按层处理节点，可直接计算深度。
- **复杂度分析**：区分时间复杂度（节点数）与空间复杂度（递归栈/队列/显式栈的最大大小）。
- **边界处理**：空树返回 0，单节点树返回 1。

## 2. 面试考察重点
- **递归思维**：能否正确写出递归终止条件和递归表达式。
- **非递归实现**：是否掌握用栈/队列模拟递归或层序遍历的能力。
- **对比分析**：能够说明递归与迭代各自的优缺点，以及适用场景。

## 3. 算法证明与推导
- **递归正确性**：对于任意节点，其最大深度等于左右子树最大深度的最大值加 1。空树深度为 0，归纳可得全局正确。
- **BFS 正确性**：每处理完一层，深度加 1，队列中始终存储当前层所有节点，最终层数即为树的高度。

## 4. 拓展与应用
- 本题解法可直接推广到 N 叉树的最大深度（递归或 BFS，只需遍历所有子节点）。
- 相关题目：平衡二叉树（利用深度递归判断）、二叉树的最小深度（注意叶子节点条件）、二叉树的直径（结合深度计算）。
- 在工程中，树的深度常用于评估递归风险（如决策树剪枝）或设计序列化格式。
