## 📚 第一部分：部署前必读

  

### 1.1 OpenClaw 是什么？

  

OpenClaw（曾用名 Clawdbot/Moltbot）是一个**开源的个人 AI 助理**，可以部署在你自己的设备上。

  

**它能帮你做什么？**

- ✅ 通过自然语言理解指令

- ✅ 处理文件、编写代码

- ✅ 控制浏览器自动操作

- ✅ 对接微信/Telegram/Discord 等聊天软件

- ✅ 定时任务自动化

- ✅ 数据完全本地，隐私可控

  

**核心优势**：数据隐私可控 + 执行能力强 + 完全开源

  

### 1.2 部署方案怎么选？

  

| 方案             | 适用人群                 | 优势                    | 劣势                | 费用      |
| -------------- | -------------------- | --------------------- | ----------------- | ------- |
| **Windows 本地** | 个人使用，有 Windows 电脑    | 数据本地，无需额外费用           | 电脑需开机，关机服务停止      | 免费      |
| **macOS 本地**   | Mac 用户               | 体验流畅，与系统集成好           | 依赖较多，需安装 Homebrew | 免费      |
| **Linux 本地**   | 熟悉 Linux 的用户/开发者     | 兼容性最好，性能最优            | 需熟悉终端操作           | 免费      |
| **阿里云部署**      | ⭐新手首选，部署完之后可 24 小时在线 | 无需维护，7×24 小时运行，支持远程访问 | 需支付服务器费用          | 38 元/年起 |

## 🪟 第二部分：Windows 11 本地部署

  

### 2.1 前期准备

  

| 项目  | 要求                        | 检查方法                     |
| --- | ------------------------- | ------------------------ |
| 系统  | Windows 11 (build 26200+) | 按 `Win+R` 输入 `winver` 回车 |
| 内存  | ≥8GB（推荐 16GB）             | 任务管理器 → 性能 → 内存          |
| 磁盘  | 至少 5GB 可用空间               | 此电脑 → 查看剩余空间             |
| 权限  | 管理员账户                     | 能运行"管理员：PowerShell"      |

  

### 2.2 步骤 1：解锁 PowerShell 执行权限

  

**⚠️ 必须用管理员身份运行！**

  

1. 按下键盘 `Win + X` 键

2. 选择 **"Windows PowerShell（管理员）"** 或 **"终端（管理员）"**

3. 确认标题栏显示 **"管理员：Windows PowerShell"**

  

```powershell

# 复制粘贴以下命令，按回车执行

Set-ExecutionPolicy RemoteSigned -Scope CurrentUser

```

  

**📺 预期输出**：

```

执行策略已成功更改为 RemoteSigned。

```

  

4. 提示时输入 `Y` 确认

  

**✅ 验证成功标志**：看到 `执行策略已成功更改为 RemoteSigned` 即成功

## 🌐 第六部分：域名访问配置（进阶）

  

### 6.1 为什么需要域名？

  

| 对比项   | IP 访问             | 域名访问                |
| ----- | ----------------- | ------------------- |
| 记忆难度  | 难记（8.219.xxx.xxx） | 易记（ai.yourname.com） |
| 专业性   | 低                 | 高                   |
| HTTPS | 不支持               | 支持（更安全）             |
| IP 变更 | 需重新告知用户           | 无需变更                |

  

### 6.2 方案一：阿里云域名 + 免费 SSL（推荐）

  

#### 步骤 1：购买域名

  

1. 访问：https://wanwang.aliyun.com/domain/

2. 搜索想要的域名（如：`myaiclaw.com`）

3. 加入购物车，完成支付

#### 步骤 4：在服务器上配置 Nginx 反向代理

  

**通过 SSH 连接服务器**（Windows 用 PowerShell，Mac/Linux 用终端）：

  

```bash

# 连接服务器（替换为你的服务器 IP）

# 输入服务器密码（购买时设置的）
```

**📺 预期输出**：

```

root@OpenClaw:~#

```

  

**上传 SSL 证书文件**（在本地电脑操作）：

  

```bash

# Windows PowerShell（替换为你的 IP 和证书路径）

scp C:\Downloads\证书文件 root@8.219.xxx.xxx:/etc/nginx/ssl/

scp C:\Downloads\证书私钥 root@8.219.xxx.xxx:/etc/nginx/ssl/

```

  

**在服务器上创建 Nginx 配置**：

  

```bash

# 创建 SSL 目录

mkdir -p /etc/nginx/ssl

  

# 编辑 Nginx 配置

nano /etc/nginx/sites-available/openclaw

```

  

**粘贴以下配置**（替换域名）：

  

```nginx

server {

    listen 80;

    server_name ai.yourdomain.com;

    return 301 https://$server_name$request_uri;

}

  

server {

    listen 443 ssl http2;

    server_name ai.yourdomain.com;

  

    ssl_certificate /etc/nginx/ssl/证书文件.crt;

    ssl_certificate_key /etc/nginx/ssl/证书私钥.key;

    ssl_protocols TLSv1.2 TLSv1.3;

    ssl_ciphers HIGH:!aNULL:!MD5;

  

    location / {

        proxy_pass http://127.0.0.1:18789;

        proxy_http_version 1.1;

        proxy_set_header Upgrade $http_upgrade;

        proxy_set_header Connection 'upgrade';

        proxy_set_header Host $host;

        proxy_cache_bypass $http_upgrade;

        proxy_set_header X-Real-IP $remote_addr;

        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;

    }

}

```

  

**保存退出**：按 `Ctrl+O` → 回车 → `Ctrl+X`

  

**启用配置并重启 Nginx**：

  

```bash

# 创建软链接启用配置

ln -s /etc/nginx/sites-available/openclaw /etc/nginx/sites-enabled/

  

# 测试配置是否正确

nginx -t

```

  

**📺 预期输出**：

```

nginx: the configuration file /etc/nginx/nginx.conf syntax is ok

nginx: configuration file /etc/nginx/nginx.conf test is successful

```

  

```bash

# 重启 Nginx

systemctl restart nginx

```

  

**📺 预期输出**：

```

```

### 6.3 方案二：Cloudflare 免费域名 + SSL（完全免费）

3. 开启 **"Always Use HTTPS"**

## ❓ 第十部分：常见问题排查

  

### Q1：网页打不开 / 显示无法访问

  

**症状**：浏览器访问 `http://127.0.0.1:18789` 显示无法连接

  

**排查步骤**：

  

```powershell

# 1. 检查服务状态

openclaw gateway status

```

  

**📺 预期输出（正常）**：

```

Status: Running ✓

```

  

**📺 预期输出（异常）**：

```

Status: Stopped ✗

```

  

```powershell

# 2. 如未运行，启动服务

openclaw gateway start

```

  

**📺 预期输出**：

```

✓ Gateway started successfully!

```

  

```powershell

# 3. 查看日志

openclaw logs

```

  

**📺 预期输出**：

```

2026-03-12 12:00:00 INFO  Gateway starting...

2026-03-12 12:00:01 INFO  Listening on http://127.0.0.1:18789

2026-03-12 12:00:02 INFO  Gateway ready

```

  

```powershell

# 4. 检查端口占用

netstat -ano | findstr 18789

```

  

**📺 预期输出（端口空闲）**：

```

（无输出）

```

  

**📺 预期输出（端口被占用）**：

```

TCP    127.0.0.1:18789    0.0.0.0:0    LISTENING    12345

```

  

**解决方案**：

  

| 原因    | 解决方法                           |
| ----- | ------------------------------ |
| 服务未启动 | `openclaw gateway start`       |
| 端口被占用 | 修改配置文件换端口                      |
| 防火墙拦截 | 关闭防火墙或添加规则                     |
| 配置错误  | 检查 `~/.openclaw/openclaw.json` |

  

### Q2：AI 不回复 / 报错

  

**症状**：发送消息后无响应或报错

  

**排查步骤**：

  

1. 检查 API Key 是否正确配置

2. 检查阿里云账户余额

3. 查看日志：`openclaw logs`

  

**解决方案**：

  

```bash

# 重新配置 API Key

openclaw config set models.providers.bailian.apiKey "你的新 Key"

  

# 重启服务

openclaw gateway restart

```

  

**📺 预期输出**：

```

✓ Configuration updated

✓ Service restarted

```

  

### Q3：联网搜索失败

  

**症状**：搜索功能报错或无结果

  

**原因**：服务器在中国内地（联网功能受限）

  

**解决方案**：

- 更换服务器地域至香港或海外

- 或使用本地部署 + 代理

  

### Q4：命令找不到（command not found）

  

**症状**：运行 `openclaw` 提示命令不存在

  

**解决方案**：

  

**Windows**：

```powershell

# 重启 PowerShell

# 如仍不行，重新安装

npm install -g openclaw

```

  

**📺 预期输出**：

```

added 1 package in 5s

```

  

**Mac/Linux**：

```bash

# 重新加载配置

source ~/.zshrc    # 或 source ~/.bashrc

  

# 如仍不行，重新安装

npm install -g openclaw

```

  

**📺 预期输出**：

```

added 1 package in 5s

```

  

### Q5：服务启动后立即退出

  

**症状**：`openclaw gateway start` 后服务马上停止

  

**排查步骤**：

  

```bash

# 1. 查看日志

openclaw logs

```

  

**📺 预期输出（错误示例）**：

```

2026-03-12 12:00:00 ERROR Configuration error: Invalid JSON

2026-03-12 12:00:01 ERROR Failed to parse config file

```

  

```bash

# 2. 检查配置文件

cat ~/.openclaw/openclaw.json

```

  

**📺 预期输出（正确）**：

```json

{

  "gateway": { "mode": "local" },

  "models": { ... }

}

```

  

```bash

# 3. 前台运行看错误

openclaw gateway --port 18789

```

  

**📺 预期输出**：

```

Starting gateway in foreground...

Error: Port 18789 is already in use

```

  

**常见原因**：

- JSON 格式错误（缺少逗号、括号不匹配）

- 端口被占用

- API Key 配置错误

  

### Q6：安装过程卡住/超时

  

**症状**：安装脚本运行到一半卡住

  

**解决方案**：

```powershell
npm config set registry https://registry.npmmirror.com

iwr -useb https://openclaw.ai/install.ps1 | iex
```

**📺 预期输出**：

```

Using mirror: https://registry.npmmirror.com

Downloading... 100%

Installation complete!

```

  

```bash

# Mac/Linux：使用国内镜像

npm config set registry https://registry.npmmirror.com

curl -fsSL https://openclaw.ai/install.sh | bash

```

  

**📺 预期输出**：

```

Using mirror: https://registry.npmmirror.com

Downloading... 100%

Installation complete!

```

  

### Q7：权限不足错误

  

**症状**：提示 `Permission denied` 或 `EACCES`

  

**解决方案**：


```

（无输出，表示成功）
```
